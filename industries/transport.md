# 航空/运输行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于航空公司、机场、铁路、航运、快递物流、货代。共性：网络型资产 + 强周期运价 + 高经营杠杆，**细分之间的估值框架差异极大，不可混用**。机场与铁路的受监管部分优先参考 `industries/utilities.md` 的监管资产框架。

## 1. 使用原则

- **先分辨细分行业**，估值框架完全不同：
  - **航空公司**：**史上毁灭资本最多的行业之一**。看单位收益（RASK/PRASK）− 单位成本（CASK，剔油）、客座率、机队计划。低成本航司与全服务航司必须分开对标。
  - **机场/铁路**：受监管的基础设施，用监管资产框架 + 非航/多元收入（免税、地产）分部估值。
  - **航运**：纯运价周期（BDI、SCFI、TCE），看订单簿/运力交付周期 + 船队价值（NAV）。
  - **快递/物流**：单量 × 单价 − 单位成本，规模网络效应显著。电商件与时效件竞争格局分开。
  - **货代**：轻资产周期利润（运价价差），**运价暴涨期的利润不可持续化**。
- **供给侧是这个行业超额收益的主要来源**。订单簿、退役/拆解、监管约束（航权/时刻/牌照）比需求预测更可研究、更可预测。
- **周期顶部禁用 P/E**。在盈利峰值时，低 P/E 是卖出信号而非买入信号。
- 高经营杠杆意味着需求或运价的小幅变化会带来利润的大幅波动。必须给出盈亏平衡点（载运率或运价）。
- 租赁负债、售后回租和订单承诺是这个行业最常见的表外/半表外负担，必须还原。

## 2. 信息来源与公允机制

### 来源优先级

1. **运营数据（高频可得）**：IATA 与各航司月度运营数据、港口吞吐量、Clarksons（航运运价与订单簿）、国家邮政局（快递单量）、铁路运量统计。**这是本行业最大的优势——高频运营数据公开可得。**
2. **监管申报与公司披露**：10-K/20-F、机队/船队明细、订单与交付时间表、租赁附注、监管定价文件。
3. **运价指数**：BDI、SCFI、CCFI、TCE、航空货运运价指数；机票价格监测。
4. **监管与政策**：航权、时刻分配、排放法规（如 CORSIA、EU ETS）、监管定价周期文件。
5. **行业协会与咨询**：IATA、ICAO、各国物流协会统计，需标注口径。

### 公允机制

- **单位指标口径**：RASK/CASK 需写明是否含货运、是否剔燃油、按可用座公里还是收入座公里。跨公司横比前先统一。
- **运价来源标注**：现货运价、长协价、TCE 的差异极大，必须写明使用的是哪一个及其时点。
- **供给数据优先**：订单簿/现有运力比、交付时间表、拆解量是可验证的硬数据，优先于需求预测。
- **反证优先写入**：例如"运价将维持高位"必须绑定订单簿、交付节奏和拆解量，而不是只引用当期现货价。
- **区分周期与结构**：单位收益下滑可能是运力投放周期，也可能是竞争格局恶化。必须用供给数据和份额区分。
- **避免幸存者偏差**：航空与航运的 peer set 必须纳入破产重整过的公司——这是行业常态而非异常。

## 3. 运输价值驱动树

```text
航空价值 = ASK（运力）× 客座率 × 单位收益(RASK) − 单位成本(CASK) − 燃油 − 租赁
航运价值 = 船队运力 × 利用率 × TCE − 运营成本 − 融资成本 ；下限为船队 NAV
快递价值 = 单量 × 单票收入 − 单票成本（规模摊薄）
机场价值 = 旅客量 × 航空性收费（受监管）+ 非航收入（免税/地产/广告）

企业价值 =
  运量/运力增长
  × 单位收益与单位成本的价差
  × 周期位置调整（运价历史分位）
  × 供给约束强度（订单簿、时刻、航权）
  ÷ 风险折现率
  − 租赁与订单表外承诺
  − 燃油/汇率敞口
  − 周期顶部扩张造成的资本错配
```

报告中至少回答：

- 当前运价/单位收益处于历史什么分位？
- 供给侧未来 2–3 年的运力增量是多少（订单簿/现有运力比）？会否压垮运价？
- 盈亏平衡的载运率或运价是多少？当前的安全边际有多大？
- 单位成本（剔油）相对同业处于什么位置？成本优势是结构性的吗？
- 还原租赁和订单承诺后的真实杠杆是多少？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 适用细分 | 常见陷阱 |
|---|---|---|---|
| ASK / ATK | 可用座公里 / 可用吨公里 | 航空 | 运力投放指标 |
| RPK | 收入客公里 | 航空 | 与 ASK 比得客座率 |
| 客座率 | RPK / ASK | 航空 | 高客座率若靠降价则无意义 |
| RASK / PRASK | 单位可用座公里收入 | 航空 | 需与客座率同看 |
| CASK ex-fuel | 剔燃油单位成本 | 航空 | **核心竞争力指标** |
| 单位价差 | RASK − CASK | 航空 | 决定盈利能力 |
| 机队与订单 | 现有机队、在手订单、交付时间 | 航空 | 订单是刚性资本承诺 |
| 燃油套保比例 | 已套保燃油占比 | 航空 | 套保会延迟油价影响 |
| 辅营收入占比 | 行李费等辅助收入 | 航空 | **依赖度骤升是红旗** |
| TCE | 等价期租租金 | 航运 | 现货运价的净化指标 |
| 订单簿/运力比 | 在建运力 / 现有运力 | 航运 | **供给端最重要的先行指标** |
| 船龄 / 拆解量 | 船队年龄与拆船规模 | 航运 | 老船拆解是供给出清信号 |
| 船队 NAV | 二手船价值 − 净债务 | 航运 | 周期底部的估值下限 |
| 单量增速 | 快递业务量 | 快递 | 与行业增速比可看份额 |
| 单票收入（ASP） | 收入 / 单量 | 快递 | 价格战期间持续下滑 |
| 单票成本 | 成本 / 单量 | 快递 | 规模摊薄是核心逻辑 |
| 产能利用率 | 分拣/运输产能利用 | 快递 | 决定单位成本 |
| Operating ratio (OR) | 营业费用 / 营业收入 | 铁路 | **改善若靠砍 capex 是透支** |
| 运量 mix | 煤炭/化工/联运等结构 | 铁路 | 不同货类价格与周期不同 |
| 旅客量 | 机场吞吐 | 机场 | 国际线旅客的非航贡献远高于国内 |
| 非航收入占比 | 免税/广告/地产收入 | 机场 | **免税协议重签是重大风险** |
| 租赁负债 | 经营租赁资本化 | 全细分 | 常被低估，需还原至 EV |
| 盈亏平衡载运率/运价 | 保本所需水平 | 航空、航运 | 高经营杠杆的核心指标 |

必须优先披露的 8 个指标：单位收益与单位成本（剔油）、载运率/客座率、供给端订单簿与交付计划、运价历史分位、盈亏平衡点、租赁与订单承诺、燃油/汇率敞口、单位经济趋势。

## 5. 财务模型结构

### 收入模型

按细分选择驱动：

1. **航空**：`ASK × 客座率 × RASK`，按航线网络（国内/国际/区域）分层，货运单列。
2. **航运**：`船队运力 × 利用率 × TCE`，按船型和航线分层；长协与现货分列。
3. **快递**：`单量 × 单票收入`，按产品（电商件/时效件/国际件）分层。
4. **机场**：`旅客量 × 人均航空性收费`（受监管）+ `旅客量 × 人均非航消费 × 扣点率`。
5. **铁路**：`运量 × 平均运价`，按货类分层，OR 单独建模。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5 年显性预测，**必须显式给出供给端运力投放假设**（来自订单簿和交付时间表）。
- 运价假设一律给三档情景：现货价、中周期价、长期成本支撑价。
- 单位收益与单位成本必须分别预测，不得只预测利润率。

### 成本、资产与负债模型

- **单位成本拆分**：燃油、人工、起降/港口费、维修、折旧、租赁分别建模。**CASK ex-fuel 是竞争力的核心读数**。
- **燃油与汇率**：给出敞口规模、套保比例与期限、每单位价格变动对利润的弹性。
- **租赁还原**：经营租赁必须资本化计入 EV 和杠杆。航空与航运公司的表观净债务常严重低估真实负担。
- **订单承诺**：在手飞机/船舶订单是刚性资本承诺，必须列出金额和交付时间表，在周期下行时会成为致命负担。
- **维护与折旧**：飞机大修、船舶特检（drydocking）是周期性大额支出，不得平滑。
- **盈亏平衡测算**：明确固定成本，计算保本所需的载运率或运价水平。

### 稳态假设边界

- **禁止把现货运价永续化**。终值使用有供需、成本与竞争证据的长期价格；跨周期均值仅作参照。
- 若订单簿/运力比高企（大量新船/新机将交付），不能同时假设运价维持高位。
- 航空与航运的长期 ROIC 历史上普遍低于 WACC，给出高于资本成本的永续回报需要极强的结构性理由。
- 快递的"以量补价"有极限：单票成本下降速度必须能覆盖单票收入下滑，否则规模扩张是价值毁灭。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **航空/航运：有恢复证据的可持续盈利 × 口径匹配倍数，必要时辅以 NAV**。倍数给可核验同行和历史依据；NAV 需扣债务、处置成本与其他义务，不保证是股价下限。
2. **周期定位**：明确当前运价/单位收益在历史分位。**周期顶部禁用 P/E**——低 P/E 意味着盈利在峰值。
3. **反向 DCF**：由现价倒推隐含的长期运价、单位价差和运量假设。
4. **供给端情景**：基于订单簿和交付时间表，给出运力增速情景及其对运价的压制。

### 可选

- **机场/铁路：EV/EBITDA + 监管资产回报框架**，现金流稳定可用较长显性期 DCF。
- **快递：单位经济 DCF + EV/EBITDA**，规模领先者给网络壁垒溢价。
- **货代：正常化盈利**，剔除运价暴涨期的超额利润。
- **重置价值**：将运力重置成本作为资产参照，同时评估过剩运力、处置成本及负债，不将其视为股价下限。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 细分：航空、航运、快递、机场、铁路、货代，**绝不可混装**。
- 商业模式：低成本 vs 全服务航司；电商件 vs 时效件快递。
- 资产结构：自有 vs 租赁比例，影响杠杆和成本结构。
- 航线/航路网络：国内、国际、区域的周期不同步。
- 周期位置与资产负债韧性。

剔除项必须说明：若某公司看似同业但资产结构或网络定位明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

| 模块 | 必看问题 |
|---|---|
| 预期差 | 收入、单位收益、单位成本、EPS、运力指引相对一致预期差在哪里？ |
| 单位经济 | RASK/单票收入 与 CASK/单票成本 的环比变化？价差扩大还是收窄？ |
| 载运率 | 客座率/舱位利用率变化？是否靠降价换取？ |
| 运力指引 | 公司运力增速指引 vs 需求增速？行业整体运力投放如何？ |
| 供给端 | 订单簿、交付计划、退役/拆解是否变化？ |
| 燃油与汇率 | 敞口与套保变化？对下期成本的影响？ |
| 租赁与承诺 | 表外租赁、售后回租、订单承诺是否增加？ |
| 辅营/非航 | 辅营收入占比是否骤升（掩盖主业疲弱）？免税协议是否临近重签？ |
| 周期定位 | 当前运价在历史分位的位置是否变化？ |
| 电话会 | 对需求能见度、定价环境、运力纪律、成本压力的措辞是否转弱？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易运价、运力投放、成本改善还是需求复苏？ |

财报后价格反应要扣除市场和同业表现：若公司上涨 8%，但运输板块同日上涨 5%，公司特异反应约为 +3%。

## 8. 护城河与竞争判断

运输业多为同质化服务，**护城河主要来自监管稀缺性和网络密度**。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 监管稀缺资源 | 时刻、航权、码头、路权等稀缺且难以复制 | 自由竞争航线/航路，无准入壁垒 |
| 网络密度 | 枢纽网络或末端网络密度带来成本与时效优势 | 网络稀疏，依赖第三方转运 |
| 单位成本优势 | CASK ex-fuel 或单票成本结构性低于同业 | 成本优势来自暂时的燃油套保或补贴 |
| 资产质量 | 年轻高效机队/船队，油耗与维护成本低 | 老旧资产，维护成本高且面临排放限制 |
| 客户黏性 | 常旅客计划、企业协议、合同物流锁定 | 纯价格竞争，客户无切换成本 |
| 定价纪律 | 行业集中度高且历史上未打价格战 | 频繁价格战，产能过剩 |
| 非航/增值业务 | 免税、地产、供应链服务提供稳定高毛利 | 单一运输收入，周期敞口全开 |
| 资本纪律 | 历史上在运价高点未盲目订购运力 | 周期顶部大额订船/订机 |

定性护城河必须与财务证据交叉：若声称"成本领先"，但 CASK ex-fuel 高于同业中位数，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- **在周期顶部大额订船/订机**——这是行业最经典的价值毁灭行为。
- 售后回租（sale-leaseback）频繁使用以美化资产负债表，实际负担未减。
- 辅营收入（行李费类）占比骤升，掩盖主业单位收益下滑。
- 货代或航运公司在运价高位扩张固定成本或收购。
- 客座率/载运率上升但单位收益下滑（以价换量）。
- 铁路 OR 改善主要靠削减维护 capex，属于透支未来。
- 机场免税协议临近重签且议价能力下降。
- 燃油套保在低油价时比例低、高油价时比例高（择时失败）。
- 订单簿/运力比处于历史高位但管理层仍看多运价。
- 租赁负债和订单承诺占市值比例过高，周期下行时无法承受。

### 反证清单

每份运输报告至少列出 3 个能推翻主结论的证据阈值：

- 单位收益（RASK/单票收入）连续 N 个季度下滑超过某幅度。
- CASK ex-fuel 或单票成本上升超过某阈值。
- 客座率/载运率跌破盈亏平衡水平。
- 行业订单簿/运力比超过某历史分位。
- 运价跌破长期成本支撑价。
- 还原租赁后的净债务/EBITDA 超过某阈值。

### 常见误判

- **周期顶部用低 P/E 判断便宜**——盈利在峰值时低 P/E 是危险信号。
- 把现货运价永续化，忽略订单簿带来的供给冲击。
- 只看客座率不看单位收益，忽略以价换量。
- 忽略经营租赁，严重低估真实杠杆。
- 忽略在手订单的刚性资本承诺。
- 把货代在运价暴涨期的利润当经营能力。
- 把铁路 OR 改善当效率提升，忽略是削减维护支出。
- 对航空业给出高于资本成本的长期 ROIC 假设，而无结构性理由。
