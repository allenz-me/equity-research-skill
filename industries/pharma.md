# 医药行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于创新药、生物技术、成熟制药、仿制药、生物类似药及以药品研发商业化为核心的公司。器械、医院、CRO/CDMO 可借用部分框架，但必须另行调整订单、利用率和监管指标。若公司同时有大额消费健康或器械业务，先按分部拆分，再对药品部分使用本附录。

## 1. 使用原则

- **先做资产分解，再谈公司**。医药公司的价值是一组资产的加总，不是一条收入曲线。先按在售产品、已申报资产、临床 III/II/I 期、临床前、合作权益和平台技术拆分。
- 每个资产必须记录：适应症、地区、机制、阶段、权益比例、里程碑、专利/独占期和下一个催化剂时点。
- 区分创新药、成熟药企、仿制药和生物类似药。四者的驱动、毛利结构、专利风险和估值方法完全不同。
- **成功概率必须显式化**。任何管线估值都要写明用的阶段基准率、资产特异修正和修正理由，不得凭管理层措辞设定。
- 临床数据的解读优先级永远是：主要终点 > 次要终点 > 亚组 > 探索性分析。顺序不可颠倒。
- 专利悬崖（LOE）不是风险提示，是必须进入终值的确定性事件。

## 2. 信息来源与公允机制

### 来源优先级

1. **监管审批与审评文件**：美国用 FDA Drugs@FDA、Orange Book（小分子专利与独占期）、Purple Book（生物制品）、Advisory Committee 材料、审评意见和标签；其他地区用 EMA、NMPA/CDE、PMDA 等当地监管原文。
2. **临床试验注册与结果**：ClinicalTrials.gov、EU CTR、各地注册库。**注册信息由申办方提交，不等于监管机构验证疗效。**
3. **同行评审论文与会议原始摘要**：ASCO、ESMO、AHA、ADA 等的原始摘要和 presentation，优先于新闻稿。
4. **公司申报与演示**：10-K/10-Q/20-F、投资者演示、里程碑披露。
5. **专业数据库与媒体**：只作补充和线索，必须回溯原始来源。

### 公允机制

- **区分提交、受理与批准**：submission ≠ acceptance ≠ approval。把提交或受理当批准是最常见的事实错误。
- **绝对效应优先**：疗效必须写绝对效应（如中位 PFS 延长月数、绝对风险下降），而不只是相对效应（HR、RRR）。相对改善在低基线下会严重夸大临床意义。
- **跨试验比较必须标注不可比性**：不同人群、不同终点、不同时代的标准治疗，单臂试验之间不可直接横比。
- **反证优先写入**：例如"该资产将成为标准治疗"必须绑定头对头数据、指南更新或竞争资产的读出时点，而不是只引用 KOL 观点。
- **失败相关性**：同一机制或同一适应症的多个资产，其失败**不是独立事件**。组合概率不能简单相乘。
- **避免幸存者偏差**：基准率必须来自完整的阶段转化统计，而不是只看成功案例。

## 3. 医药价值驱动树

医药公司内在价值可以拆成：

```text
普通股权益价值 =
  Σ（在售产品 DCF）
  + Σ（管线资产 rNPV = 各期概率加权资产净现金流的折现之和）
  + 未在产品/管线中计价的平台、合作及其他资产价值
  + 可用现金 − 债务 − 优先股及少数股东等其他权益
  − 未分摊且尚未计入资产现金流的总部费用现值及其他义务
```

资产现金流逐年包含收入爬坡、专利到期侵蚀、研发与商业化投入、税和再投资，不能用峰值销售额直接代替 rNPV。成本按实际发生阶段的概率加权，近期确定支出不能统一乘最终上市成功率。已在产品/管线模型计入的现金消耗不再从净现金扣一次；融资需求与新增股数另行桥接到每股价值。

单个资产的销售驱动：

```text
销售额 = 可治疗患者 × 诊断率 × 符合标签比例 × 渗透率
       × 疗程/依从性 × 净价格 × 权益比例
```

报告中至少回答：

- 收入集中在几个产品上？最大产品的 LOE 时点是什么时候？
- 管线中有几个资产能实质改变公司价值？它们的下一个读出时点是什么？
- 现金能否支撑到下一个价值拐点？如果不能，稀释幅度多大？
- 峰值销售假设对应的患者渗透率是多少？这个渗透率相对同类药物的历史实现值是激进还是保守？
- 净价格假设是否考虑了 gross-to-net、医保谈判和上市后的价格侵蚀？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| 峰值销售（peak sales） | 产品生命周期最高年销售 | 资产估值核心输入 | 常被系统性高估，需对照同类药物实际实现值 |
| PoS（成功概率） | 阶段转化概率 | rNPV 风险调整 | 不得凭管理层信心调整；需用阶段基准率 |
| 患者漏斗各层转化率 | 流行病学→诊断→标签→渗透 | 销售预测基础 | 每层高估 20% 会导致最终高估数倍 |
| 渗透率 | 用药患者 / 可治疗患者 | 商业化实现程度 | 需与同类药物上市后曲线对照 |
| Gross-to-net | 净价 / 标价 | 真实价格实现 | 美国 rebate、340B、Medicaid 折扣可达标价的 50%+ |
| 净价格年变动 | 净价同比 | 定价环境 | 标价上涨可能伴随净价下跌 |
| TRx / NRx | 总处方 / 新处方 | 需求趋势先行指标 | 渠道备货会使发货量领先真实处方 |
| 依从性 / 持续用药率 | 患者持续治疗比例 | 疗程价值 | 慢病药物依从性差异极大 |
| LOE 时点 | 专利/独占期到期 | 收入断崖时点 | 需区分化合物专利、制剂专利、数据独占期 |
| 独占期类型 | NCE/Orphan/BLA 独占 | 保护强度 | 生物药与小分子的仿制侵蚀速度完全不同 |
| 侵蚀曲线 | LOE 后收入下降路径 | 终值假设 | 小分子首年可跌 80%+；生物类似药侵蚀较慢 |
| 现金 runway | 现金 / 季度净消耗 | 融资风险 | 需扣除里程碑付款和债务到期 |
| 研发费用 / 项目 | 按阶段的项目预算 | 费用预测 | **不能按收入比例外推** |
| 入组速度 | 实际 vs 计划入组 | 试验执行风险 | 延迟常是竞争或设计问题的早期信号 |
| 里程碑与分成 | 合作条款 | 权益归属 | 需区分已收到、有条件和理论最大值 |
| 毛利率 | 产品毛利 | 生产经济性 | 生物药、细胞治疗的 COGS 显著高于小分子 |

必须优先披露的 8 个指标：产品收入结构与集中度、各资产 LOE 时点、峰值销售假设与依据、成功概率与基准率来源、患者漏斗各层假设、gross-to-net、现金 runway、下一催化剂时点。

## 5. 财务模型结构

### 收入模型

在售/待上市产品按患者漏斗建模，至少拆解：

1. **流行病学**：患病率、发病率、可治疗人群定义。
2. **治疗线**：一线/二线/后线，各线人群规模不同。
3. **竞争格局**：现有标准治疗、在研竞争资产及其读出时点。
4. **标签范围**：批准适应症、人群限制、黑框警告。
5. **渠道与报销**：医保覆盖、处方集地位、事前授权门槛。
6. **Gross-to-net**：美国考虑 rebates、340B/Medicaid、Part D 重构、IRA 谈判和渠道费用；其他市场考虑医保谈判、集采和价格联动。
7. **剂量/疗程与停药**：治疗时长、依从性、停药率。
8. **产能与地区权益**：自有商业化 vs 合作分成。

创新 biotech 模型另外拆：现金 runway、研发项目预算、里程碑收付和融资稀释。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来预测必须延伸至主要产品 LOE 之后，显式给出侵蚀曲线。
- **研发费用不能简单按收入比例外推**，需按试验阶段、试验数量和单试验预算自下而上建立。

### 管线与临床概率模型

| 维度 | 必查内容 | 常见误判 |
|---|---|---|
| 临床设计 | 随机/盲法/对照、样本量、入排标准、主要/次要终点、统计方案 | 用次要或探索终点替代失败的主要终点 |
| 疗效 | 绝对效应、相对效应、置信区间、数据成熟度、亚组一致性 | 只看 p 值，不看临床意义和多重性校正 |
| 安全 | AE/SAE、停药率、死亡、剂量依赖、随访时长 | 小样本和短随访低估罕见与迟发风险 |
| 可比性 | 标准治疗、竞争管线、跨试验人群差异 | 直接横比不同人群和终点的单臂试验 |
| 执行 | 入组速度、中心数量、方案修订、终点变更、数据截止 | 延迟和改终点可能是风险信号 |
| 监管 | 加速审批、确证性试验要求、CMC、标签范围 | 把提交或受理当批准 |
| 知识产权 | 化合物/制剂/用途专利、数据独占、专利挑战 | 只看最长专利，忽略核心专利到期 |

**概率调整必须显式列出：阶段基准率 + 资产特异修正 + 修正证据。** 不得因管理层措辞将成功概率直接设高。

### 稳态假设边界

- 峰值销售假设必须对照同适应症、同机制药物的实际历史实现值，超出基准需给结构性理由。
- 若竞争资产读出更强、标签更窄、报销受限，不能同时给高渗透率、高净价和长生命周期。
- 成熟药企的终值必须显式包含专利悬崖后的收入水平，不得用悬崖前利润做永续。
- 平台价值只在**重复验证、第三方合作对价或独立资产**支持时计入；避免把每个早期项目都赋正值。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **逐资产 rNPV**：峰值销售、上市时间、毛利率、销售/研发后续投入、专利期、成功概率和折现率**逐资产建模**，不做整体打包。
2. **在售产品 DCF**：按产品/适应症/地区建模，显式包含 LOE 与侵蚀曲线。
3. **SOTP**：成熟药企用 在售产品 DCF + 管线 rNPV + 净现金 加总。
4. **反向估值**：回答现价需要几个资产成功、何种峰值销售和成功概率组合。**专利悬崖必须显式进入终值。**

### 可选

- **正常化 P/E / P/FCF**：成熟药企可用，但必须说明分母是否已扣除即将到期产品的贡献。
- **交易可比**：并购对价（首付+里程碑）可作为管线资产的市场校准，但需区分首付与或有对价。
- **平台估值**：仅在有多个已验证资产或重大合作对价时使用。

净现金处理：从估值日可用现金扣债务及尚未在资产模型中计价的应付里程碑、租赁等义务。到下一价值拐点的研发及其他现金消耗用于核查 runway；已经进入 DCF/rNPV 的消耗不再扣一次，未纳入的总部开支等另扣现值。未来融资用概率或情景体现募集资金、融资成本及股数变化，不得只减稀释而漏计相应资金，也不得默认零稀释。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 阶段：临床前/早期 biotech、后期 biotech、商业化初期、成熟药企。
- 治疗领域：肿瘤、免疫、神经、代谢、罕见病的成功率、定价和竞争强度差异极大。
- 模态：小分子、抗体、ADC、细胞/基因治疗、疫苗、寡核苷酸——COGS 与壁垒不同。
- 收入结构：单产品依赖 vs 多产品分散。
- LOE 暴露：未来 5 年到期收入占比。

剔除项必须说明：若某公司看似同业但阶段、模态或 LOE 暴露明显不同，不应强行放入同一倍数表。

## 7. 财报与事件模式重点

除常规财报外，**临床读出、监管决定、标签扩展、专利诉讼和医保定价都进入深度事件模式**。

建立"旧假设 → 新证据 → 成功概率/上市时间/峰值销售 → rNPV"的变动桥。

| 模块 | 必看问题 |
|---|---|
| 预期差 | 产品收入、研发费用、EPS、指引相对一致预期差在哪里？ |
| 产品量价 | 增长来自处方量、净价、渠道备货还是新适应症？ |
| Gross-to-net | 净价实现是否恶化？rebate 或医保结构是否变化？ |
| 处方趋势 | TRx/NRx 与发货量是否背离？渠道库存变化多大？ |
| 临床进展 | 试验入组、数据截止、读出时点是否按计划？有无方案修订？ |
| 监管事件 | 审评时点、AdCom 结论、标签范围、确证性试验要求？ |
| 竞争 | 竞争资产读出是否改变本品的市场定位和峰值假设？ |
| 现金 | Runway 是否覆盖下一个关键读出？是否需要融资？ |
| 合作款 | 里程碑确认是一次性还是可持续？分成比例如何？ |
| 电话会 | 对上市进度、报销准入、竞争、定价的措辞是否转弱？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易临床读出、监管决定、LOE 还是定价政策？ |

发布会后必须**区分真实终端需求与渠道备货**——发货量与处方量的背离是最常见的误导来源。

财报后价格反应要扣除市场和同业表现：若公司上涨 9%，但生物科技指数同日上涨 5%，公司特异反应约为 +4%。

## 8. 护城河与竞争判断

医药护城河的核心是**排他性**，但排他性有时限。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 知识产权强度 | 核心化合物专利期长，制剂/用途专利形成组合防御 | 只有次要专利，核心专利临近到期或被挑战 |
| 数据与监管独占 | 生物制品独占期、孤儿药独占、儿科延长 | 独占期即将结束，仿制/类似药已申报 |
| 临床差异化 | 头对头优效数据，或进入指南一线推荐 | 仅非劣效，或依赖亚组叙事 |
| 制造复杂度 | 生物药、细胞治疗的工艺壁垒使仿制困难 | 小分子且合成路线公开 |
| 商业化网络 | 专科处方网络、KOL 关系、报销准入能力 | 依赖合作方商业化，无自主渠道 |
| 适应症扩展能力 | 同一分子持续获批新适应症，生命周期延长 | 单一适应症，扩展试验失败 |
| 平台可重复性 | 平台已产出多个进入后期的资产 | 平台叙事强但只有一个资产验证 |

定性护城河必须与财务证据交叉：若声称"强专利保护"，但仿制药已获批或核心专利在 3 年内到期，必须在终值中体现断崖。

## 9. 红旗、反证与常见误判

### 红旗

- 主要终点未达标，但用次要或探索性终点重新叙事。
- 只披露相对改善（HR、RRR），回避绝对效应和置信区间。
- 亚组结果驱动整体叙事，且该亚组非预设。
- 竞争试验读出更强，但公司未相应更新峰值销售假设。
- 批准前确认渠道收入，或发货量显著领先处方量。
- 专利/独占期表述含糊，未明确区分化合物专利与次要专利。
- 现金不足以支撑到下一个关键读出，但管理层未提融资计划。
- 频繁"平台化"叙事扩张，但无新增资产进入后期。
- 关键证据来自关联方研究或低影响因子期刊。
- 安全信号被埋在补充材料或未在新闻稿中提及。
- 临床试验终点或统计方案在数据揭盲前后被调整。

### 反证清单

每份医药报告至少列出 3 个能推翻主结论的证据阈值：

- 关键试验主要终点未达统计学显著，或效应量低于临床意义阈值。
- 安全性事件（SAE、停药率、死亡）超过某阈值或高于对照组。
- 入组速度显著落后计划，导致读出时点后移超过某时长。
- 监管要求额外确证性试验或大幅限制标签。
- 净价格年降幅超过某阈值，或医保谈判结果低于预期。
- 现金 runway 不足以覆盖下一读出，被迫在低位融资。

### 常见误判

- **系统性高估峰值销售**——患者漏斗每层乐观 20%，最终结果会高估数倍。
- 把提交或受理当批准，把加速审批当确定成功。
- 忽略 gross-to-net，用标价推算收入（美国市场可能高估一倍）。
- 把发货量当真实需求，忽略渠道备货。
- 用管理层信心替代阶段基准率设定成功概率。
- 把同机制多个资产的成功当独立事件，低估相关性风险。
- 忽略专利悬崖，用悬崖前利润做永续假设。
- 把平台叙事当价值，为每个早期项目都赋正值。
