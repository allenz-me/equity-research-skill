# 金属/矿业行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于基本金属、贵金属、电池金属、铁矿、煤炭矿商及冶炼加工。特征：**价格接受者 + 资源枯竭性资产**。核心公式：价值 = 商品价格假设 × 成本曲线位置 × 储量寿命。油气资源公司请使用 `industries/energy.md`。

## 1. 使用原则

- **矿商没有定价权**。研究的一半是研究商品本身：供需平衡表、成本曲线（需核验品种、覆盖样本与成本口径）、库存周期和替代品。
- **NAV 是主框架**：逐矿山 DCF 加总 − 净债务 − 关闭/复垦负债。**矿山寿命有限，绝不允许无限永续假设**——这是矿业与制造业最根本的区别。
- **成本曲线位置决定生死**：一/二分位成本的矿商可以穿越周期，四分位矿商本质是商品价格的看涨期权，估值框架完全不同。
- 贵金属矿商另看 AISC 与储量替代率；**勘探型公司是期权组合，不是现金流资产**，不得用 DCF 主估值。
- 品位（grade）下滑是矿业的自然规律。产量维持但品位下滑意味着单位成本必然上升，必须显式建模。
- 政治与税收风险是矿业的一级变量，按矿山所在国单独折价。

## 2. 信息来源与公允机制

### 来源优先级

1. **技术报告**：NI 43-101（加拿大）、JORC（澳洲）、SK-1300（美国）是储量、品位、成本和矿山计划的**一手权威来源**。年报储量表需逐年对账。
2. **监管申报与公司披露**：年报、季报、生产报告、储量更新公告、矿山现场考察材料。
3. **商品市场数据**：LME/COMEX/SHFE 的库存与价格、上期所仓单、交易所持仓。
4. **成本曲线数据**：Wood Mackenzie、CRU（多为付费）的全球成本曲线；公开替代来源包括同业 AISC 披露的横向汇总。
5. **官方统计**：USGS 矿产年鉴、各国海关进出口、行业协会产量统计。

### 公允机制

- **储量口径必须写明**：Proven & Probable（P&P，储量）与 Measured/Indicated/Inferred（M&I&I，资源量）是完全不同的概念。**资源量不等于可开采储量**。
- **储量价格假设**：储量的计算依赖商品价格假设。**抬高价格假设即可"创造"储量**，必须检查历年储量报告使用的价格。
- **成本口径统一**：C1 现金成本、AISC（全维持成本）、总成本的定义差异极大，**副产品抵扣（by-product credit）口径尤其不一致**。跨公司横比前先统一。
- **反证优先写入**：例如"低成本生产者"必须绑定 AISC 的行业分位、品位趋势和维持性 capex，而不是只引用公司口径的 C1 成本。
- **区分周期与结构**：单位成本上升可能是通胀周期，也可能是品位下滑或矿深增加的结构性因素。必须用品位和剥采比数据区分。
- **避免幸存者偏差**：peer set 需纳入高成本矿商和已因价格下跌停产的矿山。

## 3. 矿业价值驱动树

```text
NAV = Σ 各矿山[ 产量 × (实现价格 − AISC) × 剩余寿命，逐年折现 ]
      + 勘探/未开发资源期权（风险折价后）
      − 净债务
      − 复垦与关闭负债
      − 公司层级费用

每股价值增长 =
  储量替代率（勘探或收购）
  × 资源质量（品位、剥采比、冶金回收率）
  × 成本曲线分位维持能力
  − 股本稀释
  − 周期顶部并购损耗
```

报告中至少回答：

- 公司 AISC 处于全球成本曲线的第几分位？该分位在价格下跌时能否维持正现金流？
- 各矿山的剩余寿命是多少？加权平均寿命结束后还剩什么？
- 品位趋势如何？维持当前产量需要处理多少额外矿石（对应多少额外成本）？
- 维持性 capex 是多少？扣除后的真实自由现金流是多少？
- 储量替代率如何？新增储量的品位和成本相对现有资产是更好还是更差？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| 产量指引 | 分矿山、分金属 | 收入基础 | **品位下滑常被总产量掩盖** |
| 品位（grade） | 单位矿石含金属量 | 成本与产量的根本驱动 | 高品位区先采（high-grading）会透支未来 |
| 剥采比 | 废石 / 矿石 | 露天矿成本驱动 | 随开采深度上升 |
| 回收率 | 冶金回收比例 | 实际产出 | 矿石性质变化会降低回收率 |
| **C1 现金成本** | 直接现金操作成本 | 短期停产判断 | **副产品抵扣口径差异大** |
| **AISC** | 全维持成本（含维持 capex、复垦、公司费用） | **核心竞争力指标** | 各家定义仍有差异，需核对 |
| 成本曲线分位 | AISC 在全球曲线的位置 | 周期生存能力 | 一/二分位可穿越周期 |
| P&P 储量 | 证实+概略储量 | 可开采资源 | **依赖价格假设** |
| M&I&I 资源量 | 探明/控制/推断资源 | 潜在资源 | **不等于可开采储量** |
| 储量寿命 | 储量 / 年产量 | 资产久期 | 决定 DCF 的显性期长度 |
| 储量替代率 | 新增储量 / 消耗储量 | 可持续性 | 靠收购替代与靠勘探替代价值不同 |
| 维持性 capex | 维持当前产能的投入 | 真实 FCF 的扣减项 | **连年低于折旧是危险信号** |
| 增长性 capex | 扩产/新建投入 | 未来产能 | 需单独评估回报 |
| 实现价格 | 实际售价 | 收入 | 与基准价的差（品位罚扣、运费、加工费） |
| TC/RC | 加工与精炼费 | 冶炼、精矿销售 | 影响精矿生产商的净收入 |
| 套保头寸 | 已锁定产量与价格 | 价格敞口 | **牛市中被套保封顶上行** |
| 复垦/关闭负债 | 矿山关闭义务 | 隐性负债 | **折现率激进会低估负债** |
| 国别风险 | 资源国有化、暴利税历史 | 折价因子 | 需按矿山所在国分别评估 |
| 社区/环保冲突 | ESG 与许可风险 | 停产风险 | 升级可导致长期停产 |

必须优先披露的 8 个指标：分矿山产量与品位、AISC 及成本曲线分位、P&P 储量与寿命、储量替代率、维持性 capex、实现价格与基准价差、复垦负债、国别风险敞口。

## 5. 财务模型结构

### 产量与收入模型

**必须逐矿山建模**，不得合并：

1. **产量**：`矿石处理量 × 品位 × 回收率 = 金属产量`。品位按矿山计划逐年变化，不得取固定值。
2. **收入**：`产量 × 实现价格`。实现价格从基准价扣除品位罚扣、运费、TC/RC 和套保影响。
3. **矿山寿命**：按 P&P 储量和年产能计算剩余年限。**DCF 显性期到矿山寿命结束为止，之后无终值**（或仅剩残值/复垦支出）。
4. **未开发项目**：按开发概率、建设周期、资本开支和投产后现金流建模，风险折价后计入。
5. **勘探资产**：作为期权处理，不进入基准 DCF。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 显性期覆盖主要矿山的完整寿命。
- 品位趋势必须显式给出，并与单位成本联动。
- 商品价格假设必须写明来源（远期曲线、长期激励价格、机构预测）。

### 成本、资本与负债模型

- **成本结构**：按矿山拆现金操作成本、特许权使用费、运输、TC/RC、维持性 capex、公司费用，汇总为 AISC。
- **成本与品位联动**：品位下降时，维持相同金属产量需处理更多矿石，单位成本必然上升。这个联动必须建模，不能假设成本恒定。
- **维持性 capex**：单独估算。**维持经营现金流代理 = 经营现金流 − 维持性 capex**；总 FCF 仍扣全部 capex，增长路径需承担成长投入。连年低于折旧是产能透支的信号。
- **复垦与关闭负债**：检查计提充分性、折现率假设和现金支出时间表。**激进折现率会系统性低估负债**。
- **套保**：列出头寸、价格、期限和覆盖比例。套保在牛市中会封顶上行空间。
- **国别税收**：特许权使用费、暴利税、出口限制按矿山所在国分别建模。

### 稳态假设边界

- **禁止用现货价格永续化**。长期价格应锚定**激励价格（incentive price）**——即支撑新增供给所需的价格，结合可核验边际项目成本、供给弹性与所需回报估计，不机械指定成本曲线某个分位。
- 矿山寿命结束即现金流结束，**不允许假设无限永续**。若假设储量持续替代，必须给出替代成本和品位假设。
- 若品位下滑、剥采比上升、维持性 capex 增加，不能同时假设成本持平和产量增长。
- 四分位成本矿商不得给予与低成本矿商相同的估值倍数——前者在价格下行时会停产。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **NAV / P/NAV（主方法）**：逐矿山 DCF 加总。商品价格用**远期曲线 + 长期激励价格双锚**，**禁止用现货永续化**。
2. **成本曲线定位**：明确公司 AISC 在全球成本曲线的分位，这决定周期生存能力和估值中枢。
3. **商品价格敏感性（必做）**：商品价格 ±20% 对 FCF 与 NAV 的弹性。**高杠杆矿商的弹性可达 3–5 倍**。
4. **中周期盈利 × EV/EBITDA 中枢**：作为 NAV 的交叉验证，现货情景与长期价格情景分列。

### 可选

- **P/NAV 历史区间**：对照公司和同业的历史 P/NAV 溢价/折价区间。
- **重置价值**：新建同等产能的资本开支，作为极端低估时的下限参考。
- **期权定价**：勘探型公司和未开发项目用期权框架，不用 DCF。
- **每单位资源价值**：`EV / 资源量` 作为粗略横向对比，不作主估值。

**政治/税收风险按矿山所在国单独折价**——资源国有化、暴利税、出口禁令的历史记录是重要输入。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 金属类型：贵金属、基本金属、电池金属、铁矿、煤炭的周期驱动完全不同。
- 成本曲线分位：低成本与高成本矿商估值框架不同。
- 资产阶段：生产型、建设型、勘探型。
- 矿山寿命与储量质量：长寿命优质矿与短寿命边际矿。
- 国别风险：OECD 国家资产与高风险辖区资产。

剔除项必须说明：若某公司看似同业但成本分位或国别风险明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

| 模块 | 必看问题 |
|---|---|
| 预期差 | 产量、AISC、实现价格、EPS、FCF 相对一致预期和指引差在哪里？ |
| 产量与品位 | 产量变化来自处理量、品位还是回收率？品位是否按计划下滑？ |
| 是否 high-grading | 是否在优先开采高品位区以美化短期成本？ |
| AISC 环比 | 成本变化来自品位、剥采比、通胀、汇率还是产量摊薄？ |
| 实现价格 | 相对基准价的差如何变化？套保影响多少？ |
| 维持性 capex | 是否被压低以美化 FCF？相对折旧的比例如何？ |
| 项目进度 | 在建项目是否超支或延期？资本强度是否上升？ |
| 储量更新 | 储量变化来自勘探、重估还是价格假设调整？ |
| 复垦负债 | 计提和折现率假设是否变化？ |
| 资本配置 | 是否在价格高点分红顶点或进行大额并购？ |
| ESG/社区 | 是否有停产、许可或社区冲突风险升级？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易商品价格、成本控制、项目进度还是资本回报？ |

财报后价格反应要扣除市场和商品价格影响：若公司上涨 7%，但同期金属价格上涨带动板块上涨 5%，公司特异反应约为 +2%。

## 8. 护城河与竞争判断

矿业是纯商品行业，护城河只来自**资源禀赋和成本位置**。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 成本曲线分位 | AISC 处于全球一/二分位，价格低谷仍产生现金 | 四分位成本，低价时被迫停产 |
| 资源品位与规模 | 高品位、大规模、低剥采比 | 低品位、深部、高剥采比 |
| 矿山寿命 | 加权平均寿命长，无近期枯竭风险 | 主力矿山剩余寿命短且无接续 |
| 基础设施 | 自有铁路、港口、电力降低运输成本 | 依赖第三方物流，成本高且不稳定 |
| 国别与许可稳定性 | OECD 辖区，许可稳定，税制可预期 | 高风险辖区，国有化或暴利税历史 |
| 副产品结构 | 副产品抵扣显著降低主金属成本 | 单一金属，无成本缓冲 |
| 项目执行 | 历史项目按预算按时投产 | 反复超支延期 |
| 资本纪律 | 未在价格高点高价并购或过度扩张 | 顺周期扩张，周期顶部收购 |

定性判断必须与财务证据交叉：若声称"低成本生产者"，但 AISC 高于同业中位数或品位持续下滑，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- **储量的价格假设逐年抬高**——用价格而非勘探"创造"储量。
- **维持性 capex 连年低于折旧**，产能在被透支。
- 优先开采高品位区（high-grading）以压低短期 AISC，牺牲矿山整体经济性。
- 在商品价格高点进行大额并购或大幅提高分红。
- 复垦与关闭负债的折现率假设激进，或计提明显低于同业。
- 社区、环保或原住民冲突升级，可能导致许可撤销或长期停产。
- 产量指引维持但品位指引下调，未同步上调成本指引。
- 套保比例在低价时低、高价时高（择时失败）。
- 频繁修改矿山计划或推迟技术报告更新。
- 资源量（M&I&I）被用来支撑估值，而非储量（P&P）。

### 反证清单

每份矿业报告至少列出 3 个能推翻主结论的证据阈值：

- AISC 上升超过某阈值，或成本曲线分位下移。
- 品位下滑超过矿山计划某比例。
- 储量替代率连续低于 100%。
- 商品价格跌破公司 AISC 或有来源的边际供给成本参照。
- 关键矿山出现停产、许可或社区冲突事件。
- 净债务/EBITDA 在低价情景下突破契约阈值。

### 常见误判

- **用现货价格永续化做 NAV**，在周期顶部系统性高估。
- **给矿山假设无限寿命**——资源是枯竭性的，必须有终点。
- 把资源量（M&I&I）当储量（P&P）计入价值。
- 用 C1 现金成本而非 AISC 判断竞争力，低估真实成本。
- 忽略品位下滑与成本上升的联动关系。
- 忽略维持性 capex，把经营现金流当自由现金流。
- 在周期顶部用低 P/E 判断便宜（与所有周期股同理）。
- 对高风险辖区资产不做国别折价。

## 10. 报告输出要求

本节表名、字段和必写结论句按报告语言完整翻译；不得中英混用。

矿业公司报告除主模板外，必须增加以下表格或段落：

### 成本曲线定位（必备）

给出本公司 AISC、定义与来源，并与可核验同业样本对照；只有完整样本或可靠研究支持时才写全球分位，否则明确覆盖范围和缺口。

| 公司 | AISC | 成本曲线分位 | 主要矿山所在国 |
