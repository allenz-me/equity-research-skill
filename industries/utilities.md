# 公用事业行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于受监管电力/燃气/水务、公用事业控股公司、独立发电商及具有长期合同的电力基础设施。先区分受监管 rate base、竞争性发电、开发项目和非公用业务；四者的风险、回报机制和估值方法完全不同，不可混用同一套倍数。

## 1. 使用原则

- **先分辨监管属性**：受监管业务的回报由监管裁决决定，竞争性发电由市场电价决定。把 merchant 发电套用 rate-base 估值是根本性错误。
- 公用事业的价值主线是 **rate base 增长 × 实际赚取的回报**，不是收入增长。收入增长若不带来 rate base 扩张和及时回收，不创造价值。
- **"批准回报率"不等于实际 earned ROE**；**监管资产不等于自动可回收**。必须阅读 rate case 最终裁决原文。
- 高 capex 不等于高每股价值。若资本开支靠增发股权融资，每股增长会被稀释吞噬。
- 天气是重大扰动项，所有负荷和盈利比较必须做天气正常化。
- 可负担性（customer bill）是政治约束。账单增速过高会限制未来的费率上调空间，这是长期回报的隐性上限。

## 2. 信息来源与公允机制

### 来源优先级

1. **监管裁决与申报**：州/国家公用事业监管委员会（PUC/PSC）裁决、FERC 申报。美国用 FERC eLibrary/Data（Form 1、2、3-Q、714、EQR）、州 PUC rate case 文档。这是唯一能确认 allowed ROE、equity layer、成本分摊和回收机制的来源。
2. **公司法定与财务披露**：10-K/10-Q、监管会计报表、资本计划演示。
3. **系统与行业数据**：EIA 发电/负荷/燃料/零售电价数据、NERC 可靠性评估、系统运营商（ISO/RTO）的容量与出清价格。
4. **其他市场**：使用当地能源监管机构、系统运营商和许可文件原文。
5. **专业数据库与卖方**：只作补充，不得替代 rate case 原文。

### 公允机制

- **必读 rate case 最终裁决**：成本分摊、监管滞后（regulatory lag）、燃料调整条款、绩效激励与处罚条款都在裁决里，摘要和新闻稿不足。
- **allowed vs earned 必须并列**：只写 allowed ROE 是不完整的。必须给出实际 earned ROE 及差距原因（滞后、超支、天气、成本不予回收）。
- **按辖区披露**：多辖区公司的集团平均值会掩盖弱辖区。必须分辖区列示 rate base、allowed ROE 和监管环境。
- **反证优先写入**：例如"数据中心负荷将驱动增长"必须绑定并网排队位置、已签合同、客户信用和建设时点，而不是只引用意向书。
- **区分会计口径**：GAAP EPS、调整后 EPS 和监管会计收益是三套数，跨期比较必须一致。
- **避免幸存者偏差**：peer set 需纳入监管环境友好和不友好的辖区公司。

## 3. 公用事业价值驱动树

受监管公用事业的价值可以拆成：

```text
监管收入需求 ≈ 运营成本 + 折旧 + 税 + 获准 rate base × allowed return

每股价值增长 =
  rate base 增长率
  × 实际赚取回报（earned ROE）
  × 回收及时性（1 − 监管滞后损失）
  − 股权融资稀释
  − 项目超支与不予回收部分
  − 监管处罚与可负担性约束
```

报告中至少回答：

- rate base 增长计划是否已获监管批准？还是仅为公司规划？
- earned ROE 与 allowed ROE 的差距有多大？差距是结构性的还是周期性的？
- 资本计划的融资结构是什么？增发比例会稀释多少每股收益？
- 客户账单增速相对通胀和收入增长处于什么位置？可负担性是否已成为政治议题？
- 大型项目（核电、输电、海上风电）的超支和延期风险由谁承担？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| Rate base | 获准计入回报的净资产 | 价值增长的基础 | 各辖区口径不同，需分辖区 |
| Rate base 增长率 | rate base 同比 | 长期 EPS 增长主驱动 | 需区分已批准与规划中 |
| Allowed ROE | 监管批准的权益回报率 | 理论上限 | **不等于实际赚到的回报** |
| Earned ROE | 实际权益回报率 | 真实盈利能力 | 长期低于 allowed 说明存在结构性问题 |
| Equity layer | 监管认可的权益比例 | 决定权益回报基数 | 实际资本结构可能偏离监管假设 |
| Regulatory lag | 成本发生到费率回收的时滞 | 回报侵蚀来源 | 高通胀期滞后损失显著放大 |
| Customer bill | 户均账单 | 可负担性与政治风险 | 账单增速过快会限制未来费率上调 |
| Weather-normalized load | 天气正常化用电量 | 真实需求趋势 | 未正常化的负荷比较无意义 |
| Sales / load growth | 售电量增长 | 需求驱动 | 需拆数据中心、电气化、人口和天气 |
| SAIDI / SAIFI | 停电时长/频次 | 可靠性 | 可靠性差会触发绩效处罚 |
| Capacity factor | 机组利用率 | 发电资产效率 | 不同技术不可直接横比 |
| Heat rate | 热耗率 | 火电效率 | 决定燃料成本与调度优先级 |
| Capex | 资本开支 | rate base 增长来源 | 需拆维护、可靠性、增长和环境项目 |
| CWIP | 在建工程 | 未来 rate base | 是否计入 rate base 影响现金流时点 |
| AFUDC | 建设期资金成本资本化 | 账面利润构成 | **AFUDC 推高利润但不产生现金** |
| FFO / Debt | 运营现金流 / 债务 | 评级核心指标 | 评级下调会推高资本成本 |
| Interest coverage | 利息保障倍数 | 偿债能力 | 利率上行期压力显著 |
| Merchant exposure | 未签约发电占比 | 电价波动风险 | 与受监管业务需分开估值 |
| PPA / hedge 覆盖率 | 已锁定电量占比 | 现金流可见度 | 到期后重签价格风险 |
| 退役与环境负债 | 核退役、煤灰、野火准备 | 隐性负债 | 计提不足是重大风险 |

必须优先披露的 8 个指标：分辖区 rate base 与增长、allowed vs earned ROE、监管滞后、资本计划与融资结构、天气正常化负荷、客户账单增速、FFO/Debt、股息覆盖率。

## 5. 财务模型结构

### 收入与 rate base 模型

按辖区分别建模，**集团平均值会掩盖弱辖区**：

1. 每个辖区建立：rate base、capex、折旧、allowed ROE、equity layer 和 regulatory lag。
2. 资本计划拆维护、可靠性、输配电、发电、环境合规与增长项目。
3. **项目逐项记录**：监管批准状态、预算、在建金额、预计投产时点和回收机制。
4. 竞争性发电单独建模：容量 × 利用率 × （电价 − 燃料成本 − 变动成本），含 PPA/套保覆盖和现货敞口。
5. 负荷预测拆分：数据中心、电气化（EV/热泵）、人口/经济增长、天气和能效损失。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5 年显性预测，含各辖区 rate case 时间表和预期结果。
- 天气影响必须做正常化，并单列天气对 EPS 的贡献。
- **数据中心/电气化负荷需核验**：并网排队位置、已签合同、并网时点、建设进度和客户信用。仅有意向的负荷不得计入基准情景。

### 融资、资本与负债模型

- **融资模型必须联动**：债务发行、利率、评级阈值（FFO/Debt）、股权发行和股息政策。**高 capex 增长不等于高每股价值**——若融资以增发为主，每股增长会被稀释。
- **AFUDC 与监管资产**：建设期资本化利息会推高账面 EPS 但不产生现金。必须单列，并说明现金转化时点。
- **评级压力**：FFO/Debt 接近下调阈值时，公司往往被迫增发或削减 capex，两者都损害每股价值。
- **环境与退役负债**：核退役、煤灰处置、野火赔付准备必须检查计提充分性和回收机制。
- **股息覆盖**：股息 / 经营现金流扣除维护性 capex，判断股息是否由经营现金支撑还是靠融资。

### 稳态假设边界

- 长期 earned ROE 不应假设持续高于 allowed ROE；持续低于 allowed 的辖区需在模型中反映。
- 若客户账单增速持续高于居民收入增长，未来费率上调空间必须下调。
- 大型项目的超支概率和不予回收风险需进入 bear 情景，不能假设全额回收。
- 竞争性发电不得使用 rate-base 逻辑做永续，需用长期均衡电价和容量价格。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **股利折现 / DCF**：受监管业务用 rate-base 增长、allowed/earned ROE、资本结构和融资稀释驱动。
2. **P/B 与 earned ROE 交叉**：`合理 P/B ≈ (earned ROE − g) / (COE − g)`，与 P/E 交叉验证。
3. **SOTP**：综合集团必须把受监管业务、竞争性发电、可再生开发和非核心资产分别估值。
4. **反向估值**：回答现价隐含的 rate-base 增长、earned ROE、终端 P/E 和股权融资规模。

### 可选

- **正常化 P/E**：天气和一次性因素正常化后的盈利。
- **资产重置价值**：竞争性发电可用重置成本或容量价值交叉验证。
- **可再生项目 NPV**：开发管线按项目 NPV 加总，需扣除开发失败率。

**股息率不能替代内在价值分析**——高股息率可能反映的是增长停滞或股息不可持续。

必须对以下变量做敏感性：利率、信用利差、allowed ROE、项目超支幅度和监管滞后时长。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 监管属性：纯受监管、混合、以竞争性发电为主。
- 辖区质量：监管环境友好度、历史 rate case 结果、滞后程度。
- 业务类型：电力、燃气、水务的资本强度和增长路径不同。
- 增长阶段：高 capex 增长期 vs 成熟低增长现金牛。
- 资产负债状态：FFO/Debt 水平与评级。

剔除项必须说明：若某公司看似同业但监管属性或辖区质量明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

财报后必须建立：**EPS 桥**（天气、费率、rate base、融资、一次性）、**资本计划桥**、**项目里程碑**、**监管案件进展**、**负荷与客户账单**、**FFO/Debt 和股息覆盖**。

| 模块 | 必看问题 |
|---|---|
| 预期差 | EPS、负荷、capex、指引相对一致预期差在哪里？ |
| EPS 桥 | 增长来自费率上调、rate base 增长、天气、成本控制还是一次性项目？ |
| 天气正常化 | 剔除天气后的真实盈利与负荷趋势如何？ |
| 监管案件 | 进行中的 rate case 进展、和解方案、预期裁决时点与结果？ |
| Earned vs allowed | 实际 ROE 为何偏离 allowed？是滞后、超支还是成本不予回收？ |
| 资本计划 | capex 是否上修？上修部分是否已获监管批准？ |
| 项目进度 | 大型项目是否延期或超支？由谁承担？ |
| 负荷 | 数据中心/电气化负荷是合同化的还是意向性的？并网时点？ |
| 融资 | 是否需要增发？稀释幅度多大？评级指标是否承压？ |
| 可负担性 | 客户账单增速与政治舆论是否恶化？ |
| 电话会 | 对监管环境、项目回收、融资计划的措辞是否转弱？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易利率、rate case 结果、负荷增长还是融资稀释？ |

必须区分 **GAAP EPS、调整后 EPS 和监管会计收益**——三者差异往往就是问题所在。

财报后价格反应要扣除市场和同业表现：若公司上涨 5%，但公用事业指数同日上涨 3%，公司特异反应约为 +2%。

## 8. 护城河与竞争判断

公用事业是受监管的自然垄断，护城河来自**特许经营权与监管关系**，而非市场竞争。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 服务区特许 | 独家服务区，无竞争进入 | 存在市政化（municipalization）压力或竞争零售 |
| 监管环境质量 | 历史 rate case 结果良好，滞后短，有前瞻性测试年 | 频繁削减、滞后长、政治干预强 |
| 服务区经济 | 人口/负荷增长，客户信用好，可负担性充裕 | 人口流失，账单占收入比高 |
| 回收机制 | 燃料/资本自动调整条款，CWIP 计入 rate base | 需逐案申请，回收不确定 |
| 资本部署能力 | 大型项目按预算按时交付的历史记录 | 项目反复超支延期 |
| 资产负债韧性 | 评级充裕，融资成本低于同业 | 接近下调阈值，依赖股权融资 |
| 能源转型定位 | 转型资本开支可获监管支持并计入 rate base | 搁浅资产风险高，退役成本回收不明 |

定性判断必须与财务证据交叉：若声称"监管环境友好"，但 earned ROE 长期低于 allowed 超过 150bp，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- Capex 计划上修但监管批准滞后，投资先于回收确定性。
- Earned ROE 长期显著低于 allowed ROE，且管理层无明确改善路径。
- AFUDC 和监管资产推动账面利润上升，但经营现金流同时恶化。
- 股息增长依赖持续发股融资，而非经营现金流。
- 客户账单增速显著高于通胀和居民收入增长。
- 大型项目（核电、海上风电、输电）反复延期超支。
- FFO/Debt 接近评级下调阈值但资本计划未调整。
- 野火、环境、核退役负债计提不足或回收机制不明。
- 数据中心负荷只有意向协议，没有并网合同、时点和客户信用支持。
- 频繁使用"调整后 EPS"剔除经常性发生的项目。

### 反证清单

每份公用事业报告至少列出 3 个能推翻主结论的证据阈值：

- Earned ROE 低于 allowed ROE 超过某 bp 且持续 N 个季度。
- 主要 rate case 裁决结果低于申请值某比例。
- 大型项目超支超过预算某比例，或延期超过某时长。
- FFO/Debt 跌破评级机构下调阈值。
- 年度股权融资规模超过某金额，稀释超过某比例。
- 客户账单同比增速超过某阈值，触发监管或政治反弹。

### 常见误判

- **把 allowed ROE 当实际回报**，忽略滞后和成本不予回收造成的差距。
- 把高 capex 当高增长，忽略股权融资稀释后每股价值可能不增反减。
- 把 AFUDC 推动的账面利润当真实盈利，忽略无现金流入。
- 用高股息率判断低估，忽略股息可持续性和增长停滞。
- 把数据中心负荷意向当已锁定需求。
- 把集团平均 allowed ROE 当全部辖区状况，忽略弱辖区拖累。
- 对 merchant 发电套用受监管业务的稳定倍数。

## 10. 报告输出要求

本节表名、字段和必写结论句按报告语言完整翻译；不得中英混用。

公用事业公司报告除主模板外，必须增加以下表格或段落：

### 辖区监管地图

| 辖区 | Rate base | 占比 | Allowed ROE | Earned ROE | Equity layer | 监管滞后 | 下次 rate case |
|---|---:|---:|---:|---:|---:|---|---|

### Rate-base / ROE 桥

| 项目 | 期初 | 变动 | 期末 | 说明 |
|---|---:|---|---:|---|
| Rate base | | capex − 折旧 + 其他 | | |
| Earned ROE | | 滞后 / 超支 / 天气 / 成本 | | |
| EPS | | 费率 / rate base / 融资 / 天气 / 一次性 | | |

### 资本项目时间表

| 项目 | 预算 | 已投入 | 监管批准状态 | 投产时点 | 回收机制 | 超支风险 |
