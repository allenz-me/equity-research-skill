# 能源行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于油气上游、综合能源、炼化、油服、中游管道/LNG 及煤炭等资源公司。可再生电力公用事业优先使用 `industries/utilities.md`；金属矿业使用 `industries/metals-mining.md`。若公司横跨多个环节，先按分部拆分产量、成本和资本开支，再分别应用对应框架。

## 1. 使用原则

- **能源公司的价值是资产的加总，不是利润的倍数**。上游必须逐资产建 NAV，用 P/E 估上游是方法论错误。
- 商品价格是外生变量，公司无法控制。研究重点应放在**公司能控制的部分**：单位成本、资本效率、储量替代、资产质量和资本配置。
- **产量增长本身没有价值**。有价值的是每股储量、每股产量和每股自由现金流的增长。靠增发或举债并购换来的产量增长可能是价值毁灭。
- 现货、期货、realized price、benchmark differential 和套保价格**不得混用**。收入必须从基准价逐层桥接到实际实现价。
- 储量口径必须注明：proved/probable/possible、SEC 还是 PRMS 标准、使用的基准价格和有效日期。不同口径的储量不可比。
- **维持性资本开支（maintenance capex）是能源行业最容易被低估的项目**。必须单独估算维持当前产量所需的投入。

## 2. 信息来源与公允机制

### 来源优先级

1. **监管申报与技术/储量报告**：10-K/20-F、储量报告（SEC 或独立第三方评估）、技术报告。用于确认储量、递减率、单位成本和弃置义务。
2. **政府能源与许可数据**：美国用 EIA API（石油、天然气、电力、库存、产量）、BSEE、州级监管机构；全球用各国能源部门和许可数据库。
3. **国际机构与交易所**：IEA、OPEC、JODI 的供需平衡；交易所的期货曲线和基准价格。
4. **公司披露**：财报、投资者演示、运营更新、储量替代披露。
5. **商业数据库**：Rystad、Wood Mackenzie、S&P Commodity Insights、Argus、Kpler 可补充，但**必须标注模型/调查口径**。

### 公允机制

- **价格分层写清**：benchmark（WTI/Brent/HH/JKM）→ quality differential → location differential → hedge effect → realized price。每层都要有数据。
- **储量标注**：写明 proved developed / proved undeveloped / probable，以及评估使用的价格假设。高价格假设会虚增储量。
- **Forward curve 是市场锚，不是预测**：可作为一个情景，但基准情景应采用可解释的周期价格，并另做低价/高价压力测试。
- **反证优先写入**：例如"库存井位可支撑 10 年开发"必须绑定面积、品位/产能分级、井距和已实现的井产能曲线，而不是只引用公司口径。
- **区分周期与结构**：单位成本下降可能是通缩周期（油服价格下降），也可能是效率提升。必须用作业效率指标区分。
- **避免幸存者偏差**：peer set 需纳入高成本、高杠杆和资产质量下降的同业。

## 3. 能源价值驱动树

上游资源公司的价值可以拆成：

```text
资产 NAV =
  Σ 各资产（
      可采储量
      × （realized price − 单位现金成本 − 税费/royalty）
      × 产量曲线与递减率
      − 开发 capex
      − 弃置与环境负债
    ）折现
  + 未开发资源（风险折价后）
  + 中游/其他资产
  − 净债务
  − 公司层级费用

每股价值增长 =
  储量替代率 × 资产质量
  × 资本效率（单位产量投资额）
  − 股本稀释
  − 高价并购损耗
```

报告中至少回答：

- 维持当前产量需要多少 capex？剩余的自由现金流才是真正可分配的。
- 储量替代率是多少？替代的储量质量与被消耗的相比是更好还是更差？
- 单位完全成本（含维持 capex 和弃置）在成本曲线上处于什么分位？
- 当前 FCF 改善来自价格上涨还是运营改善？低价情景下还剩多少？
- 股东回报（分红+回购）在低价情景下是否可持续？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 适用环节 | 常见陷阱 |
|---|---|---|---|
| Production | 日产量（boe/d、mcf/d） | 上游 | **增长可能靠并购而非有机开发** |
| Reserve life (R/P) | 储量 / 年产量 | 上游 | 需区分 proved developed 与 undeveloped |
| Reserve replacement ratio | 新增储量 / 产量 | 上游 | 靠收购替代与靠钻探替代价值不同 |
| Decline rate | 自然递减率 | 上游、页岩 | 页岩递减陡峭，维持产量需持续投入 |
| Lifting cost | 单位操作成本 | 上游 | 不含维持 capex，不代表完全成本 |
| F&D cost | 单位发现与开发成本 | 上游 | 三年滚动值比单年更有意义 |
| Netback | 实现价 − 各项成本 | 上游 | 需说明扣除项范围 |
| Breakeven price | 项目/井盈亏平衡价 | 页岩、项目 | 半周期与全周期口径差异巨大 |
| 库存井位 | 剩余可钻井位数 | 页岩 | **"多年库存"需做面积、品位、井距折价** |
| Well productivity | 单井初产与 EUR | 页岩 | 加密钻井会导致井间干扰、产能下降 |
| D&C cost | 钻完井成本 | 页岩 | 服务成本周期波动大 |
| Reinvestment rate | 资本开支 / 经营现金流 | 上游 | 高再投资率意味着低自由现金流 |
| Utilization / throughput | 开工率 / 加工量 | 炼化 | 需结合检修计划 |
| Crack spread | 裂解价差 | 炼化 | **理论价差不等于实际利润** |
| Capture rate | 实际毛利 / 理论价差 | 炼化 | 反映真实经营能力 |
| Turnaround | 检修计划 | 炼化 | 检修年利润会显著下降 |
| Contracted volume / MVC | 已签约量 / 最低承运量 | 中游、LNG | 需看合同剩余期限与对手方信用 |
| Take-or-pay 占比 | 照付不议合同占比 | 中游、LNG | 现金流可见度核心 |
| Tariff escalator | 费率调整机制 | 中游 | 通胀联动是重要保护 |
| Day rate / 利用率 | 日费与船队利用率 | 油服 | 周期性极强 |
| Backlog / book-to-bill | 在手订单 | 油服 | 需看订单质量和取消条款 |
| Cash cost | 单位现金成本 | 煤炭 | 需与煤种和运距匹配 |
| 弃置义务（ARO） | 退役与环境负债 | 全环节 | 常被低估，且现金支出在远期 |
| 对冲覆盖率 | 已套保产量占比 | 上游 | 套保损益会掩盖基本面 |

必须优先披露的 8 个指标：产量与每股产量、储量与替代率、递减率、单位完全成本（含维持 capex）、realized price 桥、维持性 capex、净债务与低价覆盖、股东回报政策。

## 5. 财务模型结构

### 产量与收入模型

按资产/盆地分别建模：

1. **产量模型**：`期初产量 + 新井/新项目投产 − 自然递减 − 计划停产/检修 = 期末产量`。资本开支与维持产量直接联动。
2. **收入模型**：`volume × realized price`。realized price 从 benchmark ± quality differential ± location differential ± hedge 逐层建桥。
3. **炼化**：`炼化毛利代理 = 实际加工量 × 单位 crack spread × capture rate`；实际加工量由日处理产能、利用率与期间天数得到，已知加工量不再乘利用率，检修停机只扣一次。该结果是价差贡献，营业收入另用产品销量乘实现价格。
4. **中游/LNG**：合同现金流建模，含合同到期时间表、客户信用、吞吐量、费率 escalator 和扩建项目回报。LNG 另拆液化费、Henry Hub/油价 linkage、航运成本和目的地条款。
5. **油服**：`可收费设备天 × 日费率`，设备天由船舶/钻机数、期间天数与可收费利用率得到；含 backlog 转化和客户 capex 领先指标。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5 年显性预测，必须显式给出商品价格假设及其来源。
- 使用 forward curve 作为市场锚（一个情景），基准情景采用可解释的周期价格，另做低价/高价和差价压力测试。
- 页岩公司必须给出井位库存的分级（一级/二级/三级面积）和对应的盈亏平衡价。

### 成本、资本与负债模型

- **成本拆分**：现金操作成本、运输、税费/royalty、维护性 capex、增长性 capex、弃置支出和营运资本，逐项建模。
- **维持性 capex**：单独估算维持当前产量所需的资本开支。`维持经营现金流代理 = 经营现金流 − 维持性 capex`；总 FCF 仍扣全部 capex，增长预测需承担成长投入。这是能源公司最关键也最易被粉饰的数字。
- **对冲**：列出套保头寸、价格、期限和覆盖比例。套保损益必须与基础业务表现分开讨论。
- **弃置与环境负债（ARO）**：检查计提充分性、折现率假设和现金支出时间表。甲烷排放和碳成本若有监管要求，需进入成本。
- **净债务与流动性**：低价情景下的债务契约（covenant）测试、到期时间表和再融资风险。

### 稳态假设边界

- **不用峰值现货价资本化终值**。终值必须使用长期均衡价格，并说明依据（边际成本曲线、历史区间、供需平衡）。
- 若储量替代率低于 100%、库存井位质量下降、递减率上升，不能同时给产量增长和低维持 capex。
- 未开发资源必须按风险折价后计入 NAV，不得按已开发储量同等对待。
- 股东回报（分红+回购）必须用低价情景测试覆盖率，不能按高价情景承诺。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **资产 NAV**：上游主方法。逐资产建模产量、价格、成本、税、capex 和弃置，折现加总。
2. **反向 NAV / DCF**：由现价倒推市场隐含的长期商品价格、产量路径或资源价值，回答"市场已经 price in 了什么"。
3. **正常化 EV/DACF 或 EV/FCF**：使用中周期价格下的正常化现金流，而非当期。
4. **商品价格敏感性**：给出 NAV 和 FCF 对价格的弹性（每 $10/bbl 对应多少 NAV 变化）。

### 可选

- **分部 SOTP**：综合能源公司按上游、下游、化工、中游、交易分别估值。
- **中周期 EBITDA**：炼化使用跨周期平均裂解价差下的 EBITDA。
- **合同现金流 DCF**：中游/LNG 用已签约现金流折现，并单列未签约部分的风险。
- **重置价值**：极端低估时用资产重置成本设下限。

**储量价值必须扣除开发 capex、开发时间、税、royalty 和尾部弃置负债**——地下资源不等于股东价值。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 环节：上游、综合、炼化、中游、油服、煤炭，不可混装。
- 资源类型与盆地：页岩、常规、深水、油砂、LNG 的成本结构和递减特征不同。
- 油气比：原油为主与天然气为主的公司价格暴露完全不同。
- 成本曲线位置：低成本生产者与高成本生产者的周期韧性差异极大。
- 资产负债与对冲：净债务/EBITDA 水平和套保覆盖率。

剔除项必须说明：若某公司看似同业但资源类型、成本分位或油气比明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

财报后必须建立：**产量桥**、**realized price 桥**（基准/差价/套保）、**单位成本桥**、**capex 桥**和**净债务桥**。逐项解释相对基准商品价格的 earnings capture。

| 模块 | 必看问题 |
|---|---|
| 预期差 | 产量、实现价、单位成本、EBITDA、FCF 相对一致预期差在哪里？ |
| 产量桥 | 增量来自新井、新项目、并购还是递减放缓？每股产量是否增长？ |
| 价格桥 | 实现价相对基准的差价如何变化？套保贡献多少？ |
| 单位成本 | 成本下降来自效率、服务价格通缩还是产量摊薄？ |
| Earnings capture | 实际盈利相对基准价格的转化率是否恶化？ |
| Capex | 维持性与增长性 capex 各多少？维持产量的真实投入是否被低估？ |
| 储量与井位 | 储量替代率、井位库存质量、单井产能是否下降？ |
| 项目进度 | 大型项目（LNG、深水）成本和投产时点是否延期？ |
| 中游合同 | 合同到期、客户信用、费率调整是否变化？ |
| 资本回报 | 分红回购在低价情景下是否可持续？ |
| 电话会 | 对价格环境、服务成本、资源质量、资本纪律的措辞是否转弱？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易商品价格、资本纪律、资产质量还是股东回报？ |

财报后价格反应要扣除市场和商品价格影响：若公司上涨 6%，但同期油价上涨带动能源板块上涨 4%，公司特异反应约为 +2%。

## 8. 护城河与竞争判断

能源是同质化商品行业，护城河的本质是**成本曲线位置和资产寿命**。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 成本曲线分位 | 完全成本处于全球成本曲线低分位，周期低点仍盈利 | 高成本生产者，低价时现金流为负 |
| 资源质量与寿命 | 优质面积储量寿命长，递减率低 | 核心面积已开发，剩余为边际区块 |
| 库存深度 | 经济井位库存可支撑多年开发且已分级验证 | "多年库存"未做质量分级和井距折价 |
| 基础设施与物流 | 自有管道、码头、处理设施降低差价损失 | 依赖第三方运输，location differential 大 |
| 合同质量（中游/LNG） | 长期照付不议合同，对手方信用优良 | 合同即将到期或对手方信用恶化 |
| 资本纪律 | 历史上在高价时未盲目扩张或高价并购 | 顺周期扩张，在价格高点收购 |
| 运营执行 | 项目按预算按时交付，capture rate 稳定优于同业 | 项目反复超支延期 |
| 资产负债韧性 | 低杠杆，低价情景下仍可维持分红和投资 | 高杠杆，依赖高价维持契约 |

定性护城河必须与财务证据交叉：若声称"低成本生产者"，但完全成本（含维持 capex）高于同业中位数，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- 产量增长但**每股储量或每股 FCF 下降**——增长靠稀释换来。
- 维持性 capex 被包装成"增长性投资"，虚增可分配自由现金流。
- 用未风险化的资源量（而非储量）支撑 NAV。
- 在商品价格高位进行大额并购或回购，并同时加杠杆。
- 套保损益掩盖基础业务恶化，或套保比例在低价时反而下降。
- 弃置、环境和甲烷减排负债计提不足。
- 中游客户信用恶化或合同集中到期而未续签。
- 大型项目成本和投产时点反复延期。
- 储量评估使用的价格假设显著高于当前远期曲线。
- 页岩公司加密钻井导致单井产能下降，但仍按老曲线预测。

### 反证清单

每份能源报告至少列出 3 个能推翻主结论的证据阈值：

- 产量或每股产量连续 N 个季度下滑。
- 单位完全成本上升超过某阈值，或成本曲线分位下移。
- 储量替代率连续低于 100%。
- 关键项目超支超过预算某比例或延期超过某时长。
- 净债务/EBITDA 在低价情景下突破契约阈值。
- 低价情景下股东回报覆盖率低于 1。

### 常见误判

- **用当期高价利润套用中枢 P/E**，忽略商品价格周期。
- 把经营现金流当自由现金流，忽略维持产量所需的 capex。
- 把产量增长当价值创造，忽略每股口径和资本来源。
- 把资源量当储量，把储量当股东价值（忽略开发成本、税费和时间）。
- 把理论裂解价差当炼厂利润，忽略 capture rate。
- 把套保带来的稳定现金流当经营能力。
- 把中游的稳定 EBITDA 当无风险，忽略客户信用和合同到期。
- 用峰值价格资本化终值。
