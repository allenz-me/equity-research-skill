# 地产/REIT 行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于权益型 REIT（零售/办公/工业物流/数据中心/住宅/医疗/自储等）、抵押 REIT（mREIT）及开发商。**核心原则：净利润无意义，看 FFO/AFFO 与 NAV；杠杆与利率敏感是一级变量。**

## 1. 使用原则

- **净利润对 REIT 无意义**。折旧摊销是会计构造，而优质物业实际在增值。一律用 FFO/AFFO 和 NAV 作为分析基础。
- **权益 REIT 必须按物业类型分开**。各类型的租约久期、资本开支强度和周期驱动完全不同：
  - **数据中心** ≈ 科技资本开支周期，与 AI 需求高度相关。
  - **工业物流** ≈ 电商渗透率驱动。
  - **办公** ≈ 结构性受损（远程办公），需评估长期需求下移。
  - **零售** ≈ 分化（社区型抗跌，百货型受电商冲击）。
  - **住宅/自储** ≈ 短租约，通胀传导快。
  - **医疗** ≈ 人口老龄化 + 运营商信用风险。
- **mREIT 本质是利差杠杆基金**，用净息差 + 久期错配框架分析，**绝不与权益 REIT 混用倍数**。
- **开发商（尤其中资地产）**：看土储质量、去化率、融资渠道和债务结构。**流动性判断优先于估值判断**。
- 利率是 REIT 的一级变量：既影响 cap rate（估值分母），又影响融资成本（现金流）。必须做敏感性。

## 2. 信息来源与公允机制

### 来源优先级

1. **补充材料包（supplemental）**：**这是 REIT 研究的核心来源**。物业明细、租约到期表、同店拆分、债务明细、NOI 分解都在这里，而非主财报。
2. **10-K/年报与附注**：租约会计、资本化政策、关联交易、担保和承诺。
3. **行业与市场数据**：NAREIT 行业统计、Green Street（cap rate 的权威来源，多为付费）、CBRE/JLL/Cushman 的市场报告（空置率、新增供给、租金）。
4. **交易可比**：近期同类物业的大宗交易 cap rate，是 NAV 估值的直接输入。
5. **中资开发商另需**：预售监管资金政策、商票披露、信托与非标融资信息、地方土地出让数据。

### 公允机制

- **FFO/AFFO 口径必须对齐**：用 NAREIT 定义作为基准，公司自定义的调整项必须逐项列出。**AFFO 的调整项逐年膨胀是常见的粉饰手段**。
- **同店口径**：同店池（same-store pool）每年会变化，剔除的资产往往是表现差的。必须检查池子构成变化。
- **Cap rate 口径**：用 TTM NOI 还是远期 NOI，差异可达数十个基点。必须写明。
- **租金差口径**：新签与续租 spread 需说明是否为现金基础（cash spread）还是直线法（straight-line），后者会被免租期美化。
- **反证优先写入**：例如"租金增长强劲"必须绑定出租率、租金差、免租期和 TI（租户装修补贴）的变化，而不是只看直线法租金。
- **区分周期与结构**：办公空置率上升是周期还是远程办公的结构性冲击，判断完全不同。

## 3. REIT 价值驱动树

```text
每股 NAV = (Σ 各物业组合 NOI ÷ 市场 cap rate + 其他资产 − 净债务) ÷ 股数

AFFO = FFO − 经常性维护 capex − 直线租金调整 − 股权激励等

内生增长 =
  同店 NOI 增速（= 出租率变化 + 租金差 + 费用控制）
  + 开发/改造项目的增值收益
  + 收购的增值（收购 cap rate > 资金成本）
  − 股权融资摊薄
  − 到期债务再融资成本上升
```

报告中至少回答：

- 同店 NOI 增长来自出租率提升、租金上涨还是费用节约？可持续性如何？
- 新签和续租的租金差是正是负？免租期和 TI 补贴的趋势如何？
- 债务到期墙在哪几年？以当前利率再融资将增加多少利息支出？
- 增长是靠内生（同店 NOI）还是靠不断发股收购？后者在股价低于 NAV 时是价值毁灭。
- AFFO 派息率是多少？股息是否安全？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 适用类型 | 常见陷阱 |
|---|---|---|---|
| FFO | 净利润 + 折旧摊销 − 出售收益 | 权益 REIT | 各公司口径略异，用 NAREIT 定义对齐 |
| **AFFO / CAD** | FFO − 经常性维护 capex − 直线租金调整 | 权益 REIT | **维护 capex 低估是最常见的美化** |
| 同店 NOI 增速 | 剔除收并购的内生增长 | 权益 REIT | **"同店"池子每年变化，需检查构成** |
| 出租率 | 已租面积 / 可租面积 | 权益 REIT | 需区分已签约未起租（leased vs occupied） |
| 租金差（spread） | 新签/续租租金相对到期租金 | 权益 REIT | 免租期和 TI 补贴藏在表外 |
| 免租期 / TI | 租户激励 | 权益 REIT | 直线法会把激励平摊，掩盖真实现金租金 |
| Cap rate | NOI ÷ 物业价值 | 权益 REIT | **用 TTM 还是远期 NOI 差异大** |
| NAV / 每股 NAV | 物业价值 − 净债务 | 权益 REIT | 高度依赖 cap rate 假设 |
| P/NAV | 股价 / 每股 NAV | 权益 REIT | 需对照历史溢价/折价区间 |
| AFFO 派息率 | 股息 / AFFO | 权益 REIT | **> 90% 需警惕削减** |
| 净债务/EBITDA | 杠杆水平 | 全类型 | REIT 普遍高杠杆，需与同类比 |
| 固定利率占比 | 固定利率债务比例 | 全类型 | **浮动占比高 = 利率敏感放大** |
| 债务到期墙 | 各年到期金额 | 全类型 | 集中到期是流动性风险 |
| 加权平均债务成本 | 综合融资成本 | 全类型 | 与新发利率的差决定再融资冲击 |
| 加权平均租约期限（WALE） | 剩余租约年限 | 权益 REIT | 长租约抗跌但通胀传导慢 |
| 租户集中度 | 前十大租户占比 | 权益 REIT | 单一租户破产的冲击 |
| 开发管线 | 在建项目规模与收益率 | 权益 REIT | 开发收益率与 cap rate 的价差是增值来源 |
| 净息差 | 资产收益率 − 负债成本 | mREIT | 核心盈利指标 |
| 久期缺口 | 资产与负债久期差 | mREIT | 利率波动的放大器 |
| 去化率 | 已售/可售 | 开发商 | 决定现金回流速度 |
| 土储质量 | 一二线占比、成本 | 开发商 | 低线城市土储可能减值 |

必须优先披露的 8 个指标：FFO 与 AFFO（含调整项明细）、同店 NOI 增速、出租率与租金差、cap rate 与每股 NAV、AFFO 派息率、净债务/EBITDA 与固定利率占比、债务到期墙、租户集中度。

## 5. 财务模型结构

### 收入与 NOI 模型

按物业组合分别建模：

1. **同店 NOI**：`同店可出租面积 × 期均出租率 × 期间单位面积有效租金 + 其他物业收入 − 物业运营费用`。出租率变化用于解释增量，不能代替出租率水平；租金差仅作用于实际到期续租/新签面积，分物业类型和地区建模。
2. **非同店**：收购、开发交付、处置的贡献单列。
3. **开发管线**：在建项目按预计交付时点、稳定后 NOI 和开发收益率建模。**开发收益率与市场 cap rate 的价差是真实增值来源**。
4. **mREIT**：`生息资产 × 资产收益率 − 融资负债 × 负债成本`，加久期错配和提前还款（prepayment）假设。
5. **开发商**：`签约销售额 = 可售面积 × 去化率 × 单位面积售价`，或使用同口径的 `可售货值 × 去化率`，不能对货值再乘售价。按交付确认收入，按回款率与时间确认收款，再分别扣除土地、建安、税费及融资现金支出；现金流优先于利润。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5 年显性预测，必须包含债务到期再融资的利率假设。
- FFO 与 AFFO 分别预测，AFFO 需明确维护 capex 假设。
- 单列内生增长（同店）与外延增长（收购/开发）。

### 资本、负债与股息模型

- **AFFO 桥**：从 FFO 逐项扣除经常性维护 capex、直线租金调整、股权激励和租赁激励摊销。**逐年膨胀的"调整项"必须单独审视**。
- **债务到期墙**：列出各年到期金额、当前利率与市场新发利率的差，计算再融资对 AFFO 的冲击。
- **利率敏感性**：`平均计息债务金额 × 未对冲浮动利率占比 × 利率变动 × 适用年数 ≈ 利息支出变化`，另计固定债务到期再融资；同时 cap rate 上行会压缩 NAV。
- **股权融资**：REIT 依赖外部融资增长。**若股价低于 NAV 仍持续发股收购，属于价值毁灭**，必须识别。
- **股息可持续性**：AFFO 派息率、留存现金、债务契约对分红的限制。
- **开发商额外检查**：明股实债、表外合联营担保、商票逾期、预售监管资金可动用比例。

### 稳态假设边界

- 同店 NOI 长期增速不应显著高于通胀，除非有结构性供需失衡的证据（如数据中心、物流）。
- 若出租率下降、租金差转负、免租期延长，不能同时假设高同店 NOI 增长。
- Cap rate 假设必须与利率环境一致：无风险利率上行期，cap rate 压缩的假设需要极强理由。
- 办公类资产需评估结构性需求下移，不得简单假设回到疫情前水平。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **NAV（核心方法）**：`每股 NAV = [Σ(各物业组合 NOI ÷ 对应 cap rate) + 其他资产 − 净债务] ÷ 股数`。**cap rate 假设必须做 ±50bp 敏感性**，并对照 P/NAV 的历史溢价/折价区间。
2. **P/AFFO**：对照自身历史与同物业类型 REIT。同时检查 **AFFO 派息率 > 90% 时的股息削减风险**。
3. **股息贴现模型（DDM）**：适合租约长、增长稳定的类型（如 net lease）。
4. **利率情景**：给出利率上行/下行情景下 NAV 和 AFFO 的双重影响。

### 可选

- **DCF**：可用，但**现金流口径必须是 AFFO**。在 `scripts/dcf.py` 中直接把 fcf 填为 AFFO 路径。
- **重置成本**：新增供给受限的市场可用重置成本作为价值下限。
- **私募市场对标**：近期大宗交易 cap rate 是 NAV 的直接校准。
- **mREIT：P/B 框架** + 净息差与久期分析，不用 FFO。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- **物业类型**：办公、零售、物流、数据中心、住宅、医疗、自储，**绝不可混装**。
- 地区与市场：核心城市 vs 二线市场的 cap rate 和增长差异大。
- 租约结构：长租约（net lease）与短租约（住宅、自储）的通胀敏感度不同。
- 杠杆与利率敞口：固定利率占比、到期结构。
- 增长模式：内生驱动 vs 收购驱动。

剔除项必须说明：若某 REIT 看似同业但物业类型或租约结构明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

**补充材料包（supplemental）比主财报更重要**——物业明细、租约到期、同店拆分都在其中。

| 模块 | 必看问题 |
|---|---|
| 预期差 | FFO/AFFO、同店 NOI、出租率、指引相对一致预期差在哪里？ |
| 同店 NOI | 增长来自出租率、租金还是费用？同店池构成是否变化？ |
| 出租率 | 边际变化如何？已签约未起租（leased vs occupied）的差额多大？ |
| 租金差 | 新签和续租 spread 是正是负？现金基础还是直线法？ |
| 租户激励 | 免租期和 TI 补贴是否延长/增加？（真实租金可能在下降） |
| AFFO 质量 | AFFO 调整项是否膨胀？维护 capex 假设是否合理？ |
| 债务 | 本期再融资成本 vs 存量利率？到期墙是否临近？ |
| 利率敞口 | 浮动利率占比变化？对冲到期情况？ |
| 收购/处置 | 收购 cap rate 与资金成本的价差？是否在低于 NAV 时发股？ |
| 开发管线 | 项目交付进度、稳定收益率、超支情况？ |
| 股息政策 | AFFO 派息率？管理层对股息的措辞是否变化？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易利率、同店 NOI、资产价值还是股息安全性？ |

财报后价格反应要扣除市场和同业表现：若 REIT 上涨 6%，但 REIT 指数同日上涨 4%，公司特异反应约为 +2%。

## 8. 护城河与竞争判断

REIT 的护城河来自**位置稀缺性和供给约束**，不是管理能力。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 位置稀缺性 | 核心地段、进入壁垒高、新增供给受限 | 郊区或供给弹性大的市场 |
| 供给约束 | 分区管制、土地稀缺、建设周期长 | 新增供给持续涌入 |
| 租户质量 | 投资级租户、长租约、分散 | 租户信用弱或高度集中 |
| 租约结构 | 内嵌租金递增条款、triple-net 结构 | 租金固定或需频繁重新谈判 |
| 定价权 | 续租租金差持续为正且高于通胀 | 需靠免租期和 TI 才能维持出租率 |
| 资本成本优势 | 评级高、融资成本低于同业 | 高杠杆、评级承压、依赖高息债 |
| 开发能力 | 开发收益率显著高于收购 cap rate | 开发项目超支或收益率低于市场 |
| 规模与运营平台 | 规模带来运营费用率优势 | 规模不足，费用率高于同业 |

定性护城河必须与财务证据交叉：若声称"核心资产稀缺"，但出租率下滑、租金差转负，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- **AFFO 调整项逐年膨胀**，口径不断放宽。
- 经常性维护 capex 假设明显低于同类型 REIT 或历史水平。
- **资本化利息比例上升**，把融资成本转入资产。
- **频繁增发股票摊薄接盘收购**——增长靠发股而非内生，尤其在股价低于 NAV 时。
- 关联方物业交易定价缺乏独立评估。
- 出租率靠延长免租期和提高 TI 维持，现金租金实际下降。
- 同店池构成变化，剔除了表现差的资产。
- 债务集中到期且当前利率远高于存量利率。
- AFFO 派息率持续高于 90%，或用融资/处置资金维持股息。
- 办公类资产仍按疫情前需求假设估值。

**中资开发商另查**：明股实债、表外合联营担保、商票逾期、预售监管资金被挪用或不可动用。

### 反证清单

每份 REIT 报告至少列出 3 个能推翻主结论的证据阈值：

- 同店 NOI 增速跌破某阈值或转负。
- 出租率跌破某水平，或租金差连续为负。
- AFFO 派息率超过某比例。
- 净债务/EBITDA 超过契约阈值，或固定利率占比跌破某水平。
- 再融资成本相对存量利率上升超过某 bp。
- 市场 cap rate 上行超过某 bp（直接压缩 NAV）。

### 常见误判

- **用净利润或 P/E 分析 REIT**——折旧摊销使净利润严重失真。
- 用 FFO 而非 AFFO 判断股息安全性，忽略维护 capex。
- 忽略免租期和 TI，把直线法租金当真实现金租金。
- 把收购驱动的 FFO 增长当价值创造，忽略发股摊薄。
- 忽略 cap rate 对 NAV 的杠杆效应（NOI 不变时 cap rate 上行 50bp 可使 NAV 下跌两位数）。
- 把高股息率当低估，忽略派息率过高和削减风险。
- 对办公资产按周期性反弹假设，忽略结构性需求下移。
- 把 mREIT 当权益 REIT 用 FFO 倍数估值。
