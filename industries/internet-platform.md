# 互联网/平台行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于搜索、电商、社交、广告、本地生活、流媒体、共享经济等平台型公司。核心特征：网络效应 + 边际成本递减 + 多业务孵化，估值难点在于"成熟现金牛 + 烧钱期权"的混合体。若公司含云/基础设施分部，该分部单独建模（参考 `industries/saas.md`），不与广告业务共用倍数。

## 1. 使用原则

- **先分辨业务类型**，再选 KPI：
  - **广告平台**（搜索/信息流/社交）：用户时长 × 变现率（ad load、eCPM）、广告主 ROI、宏观广告周期敏感度。
  - **电商/市场**：GMV、take rate、履约成本率、品类 mix（高频低毛利 vs 低频高毛利）。
  - **订阅/流媒体**：订户净增、ARPU、流失率、内容成本摊销政策（现金支出与摊销的缺口）。
  - **本地生活/共享经济**：订单量、单均经济、骑手/司机供给成本、补贴强度。
  - **云/基础设施分部**：单独建模，参考 SaaS 附录。
- **多数平台是 SOTP 标的**：成熟业务用 DCF/倍数，新业务用期权定价或单位经济，**禁止用一个 P/E 打包**。
- 收入增长必须拆成**量与价**。广告只报收入不拆 impressions 与 eCPM，等于隐藏周期性。
- AI / cloud / 数据中心扩张期必须区分**维护性 capex 与成长性 capex**：前者是维持现有收入能力的成本，后者是未来收入产能。**不得只因 FCF margin 被成长性 capex 压低就机械下调质量判断。**
- SBC 是平台公司的真实成本。一律用 SBC 后的 FCF 和稀释后股本。

## 2. 信息来源与公允机制

### 来源优先级

1. **财报与 10-K 分部附注**：分部收入、经营利润、capex、用户指标定义。**监管反垄断诉讼文件常披露内部数据**，是高价值来源。
2. **平台自报运营数据**：MAU/DAU、GMV、订单量、订户数。**注意口径变更与"活跃"的定义**。
3. **第三方测量**：Sensor Tower、data.ai、Similarweb、eMarketer（广告份额）、尼尔森。必须标注样本方法和覆盖偏差。
4. **广告主/商家调研、渠道 checks**：只作线索，需与公司披露交叉验证。
5. **监管与政策原文**：隐私政策（如 ATT）、反垄断裁决、内容监管、平台责任立法。

### 公允机制

- **口径变更必须标注**：MAU、DAU、GMV、"活跃用户"的定义变更会造成假性增长。历史数据是否重述必须写明。
- **GMV 口径**：是否含退货、取消、自营与第三方、跨境、税费。不同口径的 GMV 不可比。
- **量价必须分离**：广告收入必须拆 impressions（量）与 eCPM（价）；电商必须拆 GMV 与 take rate。
- **反证优先写入**：例如"AI 提升广告效率"必须绑定 eCPM 趋势、广告主留存或转化率数据，而不是只引用管理层描述。
- **区分周期与结构**：广告收入下滑可能是宏观广告周期，也可能是份额流失或新格式蚕食。必须用份额和量价数据区分。
- **避免幸存者偏差**：peer set 需纳入已失去份额的平台和被新形态颠覆的公司。

## 3. 平台价值驱动树

按业务类型选择驱动树：

```text
广告收入 = 广告展示次数 × eCPM（每千次展示收入）÷ 1,000
电商价值 = GMV × take rate − 履约/补贴 − 获客成本
订阅价值 = 订户数 × ARPU × 留存期 − 内容/服务成本
本地生活 = 订单量 × 单均 GMV × take rate − 履约补贴

企业价值 =
  Σ 成熟业务（稳态利润 × 可持续性）
  + Σ 新业务（单位经济转正概率 × 规模上限）
  + 净现金与投资
  − SBC 稀释
  − 监管处罚与结构性风险（情景概率）
  − 成长性 capex 未兑现风险
```

报告中至少回答：

- 收入增长来自用户增长、时长增长、变现率提升还是价格？各贡献多少？
- 变现率还有多少提升空间？ad load 是否已接近用户体验上限？
- 新业务的单位经济是否有清晰的转正路径？还是靠 TAM 叙事支撑？
- 成长性 capex（尤其 AI/数据中心）的收入转化路径是什么？利用率和 ROIIC 如何？
- 监管风险是罚款级别，还是可能强制拆分或改变商业模式？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 适用业务 | 常见陷阱 |
|---|---|---|---|
| MAU / DAU | 月活/日活用户 | 全平台 | **口径变更是最常见的粉饰手段** |
| DAU/MAU | 用户黏性比 | 社交、内容 | 高比值代表高频使用 |
| 时长 | 人均使用时长 | 广告平台 | 时长增长若靠低质量内容会损害广告价值 |
| Ad load | 广告加载率 | 广告平台 | 提升 ad load 是一次性红利，有体验上限 |
| Impressions | 广告展示量 | 广告平台 | 量的增长需与价格分开 |
| eCPM / 单价 | 千次展示收入 | 广告平台 | 价格下跌常被展示量增长掩盖 |
| 广告主数量/集中度 | 活跃广告主与集中度 | 广告平台 | 大广告主流失风险 |
| GMV | 平台成交额 | 电商、本地生活 | **是否含退货取消需写明；容易注水** |
| Take rate | 平台收入 / GMV | 电商、本地生活 | 提升 take rate 可能损害商家留存 |
| 履约成本率 | 履约成本 / GMV 或收入 | 电商 | 决定电商真实盈利能力 |
| 单位经济（UE） | 单订单/单用户的贡献利润 | 新业务 | **不能用 TAM 代替 UE 论证** |
| 订户净增 | 新增 − 流失 | 订阅、流媒体 | 促销期订户质量差、流失率高 |
| ARPU | 每用户收入 | 全平台 | 需区分地区结构变化的影响 |
| Churn | 流失率 | 订阅 | 免费试用转化后的流失需单独看 |
| 内容成本与摊销 | 现金支出 vs 摊销 | 流媒体 | **现金与摊销的缺口是关键**；表外内容义务需查附注 |
| 补贴强度 | 补贴 / GMV 或订单 | 新业务、本地生活 | 补贴驱动的增长留存差 |
| 获客成本 | 营销费用 / 新增用户 | 全平台 | 需与用户生命周期价值对比 |
| SBC / revenue | 股权激励占比 | 全平台 | **禁止使用剔除 SBC 的 FCF 倍数** |
| 维护性 vs 成长性 capex | 资本开支拆分 | 有云/AI 业务 | 未拆分时必须写明并用区间处理 |
| RPO / backlog | 云分部在手合同 | 云分部 | 衡量成长性 capex 的消化速度 |
| ROIIC | 增量投入资本回报 | 全平台 | 验证再投资是否创造价值 |

必须优先披露的 8 个指标：用户规模与黏性、时长或频次、变现率（eCPM 或 take rate）量价拆分、GMV 口径、新业务单位经济、SBC/revenue、维护性与成长性 capex 拆分、分部经营利润率。

## 5. 财务模型结构

### 收入模型

按业务分部分别建模，禁止合并预测：

1. **广告**：`收入 = 广告展示次数 × eCPM ÷ 1,000`，eCPM 为每千次展示收入；展示次数再由用户数、期间人均展示机会、ad load 与填充率拆解，不能把使用时长直接当展示次数。按地区和垂直行业拆分需求。
2. **电商**：`GMV × take rate`，GMV 拆买家数 × 频次 × 客单价；自营与第三方分列。
3. **订阅/流媒体**：`期初订户 + 新增 − 流失 = 期末订户`；收入用 `期间平均付费订户 × 月度 ARPU × 期间月数`，已在订户路径中体现的流失不再乘一次流失系数。按地区分层（ARPU 差异巨大）。
4. **云分部**：参考 SaaS 附录，用 RPO/backlog 和消费增长驱动。
5. **新业务**：用单位经济 × 规模路径建模，明确转正时点和所需规模。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5 年显性预测，分部单列，不得只做合并收入 CAGR。
- 广告收入必须给出量（impressions）与价（eCPM）的分别预测。
- 单列有机增长与并购；无法拆分时写"未获取到拆分"并降低置信度。

### 成本、capex 与利润率模型

- **分部利润率**：各分部单独建模。成熟业务的高利润率不应被用来掩盖新业务的持续亏损。
- **履约与内容成本**：电商的履约成本率、流媒体的内容摊销政策必须单独讨论。**流媒体需对比内容现金支出与摊销费用的缺口**——缺口持续为负说明利润被摊销政策美化。
- **成长性 capex 桥**：当 AI 相关基础设施、训练/推理成本或数据中心投入显著时，必须给出：维护性 capex、成长性 capex、单位推理成本趋势、利用率、RPO/backlog 和新增收入的转化关系。
- **SBC**：同时进入稀释股本和真实经济成本讨论。Non-GAAP 利润率不能替代 SBC 后 FCF。
- **营运资本**：电商的应付账期、平台的商家结算周期会显著影响现金流，需单列。

### 稳态假设边界

- 广告变现率提升有上限：ad load 受用户体验约束，eCPM 受广告主 ROI 约束。**全球广告市场大致占 GDP 的 1–1.5%，份额有天花板**，反向 DCF 必须检验隐含份额的合理性。
- 若用户增长停滞、时长下降、eCPM 承压，不能同时给高收入增长和高利润率。
- 新业务不得默认全部成功。必须给出转正概率，或用情景加权。
- 成长性 capex 若持续投入但收入转化和利用率不改善，需下调 ROIIC 并重估投资价值。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **SOTP 为主框架**：核心业务三阶段 DCF；亏损新业务用「情景 × 单位经济」或对标私募估值（打折）；**净现金单列**。
2. **反向 DCF**：平台巨头尤其有用——由现价倒推隐含的广告市场份额、GMV 规模或用户变现水平，并**检验其相对市场天花板是否可能**。
3. **SBC 后 FCF 倍数**：按稀释后股本计算，禁止使用剔除 SBC 的口径。
4. **Owner earnings 桥**（AI/cloud capex 显著时）：`经营现金流 − 维护性 capex = 维护性 FCF`；成长性 capex 单独绑定收入转化、利用率、RPO/backlog、分部利润率和 ROIIC。若无法拆分，写"未获取到维护/成长 capex 拆分"，并用区间或情景处理。

### 可选

- **分部倍数法**：成熟广告业务用 EV/EBIT，云用 EV/Revenue，电商用 EV/GMV 或 EV/EBITDA。
- **期权定价**：早期新业务可用实物期权框架，但需说明假设的脆弱性。
- **用户价值法**：`每用户价值 × 用户数` 作为交叉参考，不作主估值。

**监管折价必须显式化**：反垄断罚款、强制拆分、商业模式限制用真实概率情景明确经营损失；匹配系统性风险的折现率仍适用，不重复加入同一事件损失溢价。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 变现模式：广告、佣金、订阅、交易，不可混装。
- 网络效应类型：跨边网络（市场）、同边网络（社交）、无网络效应（内容）。
- 增长阶段：成熟现金牛、高增长变现期、烧钱扩张期。
- 地区与监管：受隐私政策、反垄断和内容监管影响的程度。
- 资本强度：轻资产平台与重资产（数据中心、物流）平台不同。

剔除项必须说明：若某公司看似同业但变现模式或资本强度明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

| 模块 | 必看问题 |
|---|---|
| 预期差 | 分部收入、经营利润、EPS、capex 指引相对一致预期差在哪里？ |
| 广告量价 | 收入增长中 impressions 与 eCPM 各贡献多少？eCPM 是否同比下滑？ |
| 垂直需求 | 各广告主行业（电商/游戏/金融/汽车）景气度分化如何？ |
| 新格式冲击 | 短视频、AI 搜索等新格式对存量广告位的蚕食程度？ |
| 电商 | GMV 与收入是否背离？take rate 变化原因？履约成本率趋势？ |
| 订阅/内容 | 净增质量如何？内容现金支出与摊销的缺口是否扩大？ |
| 云分部 | 增速相对巨头同业当季如何？经营利润率爬坡？RPO/backlog 消化速度？ |
| Capex | 资本开支指引变化多大？维护性与成长性如何拆分？利用率如何？ |
| 新业务 | 亏损收窄路径是否兑现？单位经济是否改善？ |
| SBC | SBC/revenue 趋势？稀释是否被回购完全抵消？ |
| 资本配置 | 管理层对 capex、回购、新业务减亏的措辞是否变化？ |
| 监管 | 诉讼、罚款、政策变化对商业模式的实质影响？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易 AI 变现、广告周期、capex 回报还是监管结果？ |

财报后价格反应要扣除市场和同业表现：若公司上涨 9%，但互联网板块同日上涨 5%，公司特异反应约为 +4%。

## 8. 护城河与竞争判断

平台护城河的核心是**网络效应**，但网络效应有边界也会衰减。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 跨边网络效应 | 买卖双方互相吸引，规模优势自我强化 | 多归属（multi-homing）普遍，用户可同时用多个平台 |
| 同边网络效应 | 用户越多社交价值越高，迁移需集体行动 | 社交图谱可复制，年轻用户流向新平台 |
| 数据与算法飞轮 | 数据规模转化为可测量的推荐/广告效率优势 | 数据可替代，算法差距在缩小 |
| 生态与切换成本 | 账号、支付、内容、设备形成生态锁定 | 单点服务，切换成本低 |
| 变现效率 | eCPM 或 take rate 高于同业且稳定 | 变现率提升即引发用户或商家流失 |
| 供给侧壁垒 | 独家内容、独家商家、稀缺供给 | 供给方议价能力强，成本持续上升 |
| 分发入口 | 掌握操作系统、浏览器或默认入口 | 依赖第三方分发，受平台政策制约 |
| 再投资回报 | 新业务 ROIIC 高于资本成本 | 长期烧钱但单位经济未改善 |

财务验证：用**份额稳定性 + 定价权（eCPM/take rate 趋势）+ ROIIC** 三者交叉。若声称"强网络效应"，但份额下滑、eCPM 下降、新业务 ROIIC 为负，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- MAU/DAU/GMV 口径变更，且未重述历史数据。
- GMV 与收入的剪刀差持续扩大（GMV 增长但变现下降）。
- "其他收入"或未分部收入快速膨胀，掩盖主业疲弱。
- 广告收入增长完全靠 impressions，eCPM 持续下滑。
- Ad load 已接近或超过行业上限，但仍假设变现率继续提升。
- 新业务用 TAM 叙事替代单位经济论证，且亏损持续扩大。
- 流媒体内容现金支出显著高于摊销，且表外内容义务快速增长。
- 监管处罚常态化，或核心商业模式面临结构性限制。
- SBC 高企且回购仅能抵消稀释，股东未获真实回报。
- 创始人/高管持续大额套现，节奏与基本面背离。
- 成长性 capex 大幅增加但利用率、RPO 或收入转化无对应改善。

### 反证清单

每份平台报告至少列出 3 个能推翻主结论的证据阈值：

- DAU/MAU 或用户时长连续 N 个季度下滑。
- eCPM 或 take rate 跌破某阈值。
- GMV 与收入增速差超过某个百分点。
- 新业务单位经济未在承诺时点转正。
- 云/AI 分部利用率或 RPO 增速跌破阈值，成长性 capex 无法消化。
- 反垄断裁决要求剥离核心业务或改变默认分发。

### 常见误判

- 用单一 P/E 给多业务平台估值，掩盖新业务亏损或成熟业务衰退。
- 把 GMV 增长当收入增长，忽略 take rate 变化。
- 把用户增长当价值增长，忽略新增用户的变现能力（新兴市场 ARPU 极低）。
- 使用剔除 SBC 的 FCF 倍数，系统性高估价值。
- 把成长性 capex 压低的 FCF 当质量恶化，或反之把所有 capex 当增长投入。
- 用 TAM 论证新业务价值，忽略单位经济从未转正。
- 用任意 WACC 加点替代监管经营损失建模，或对已入情景的同一损失重复加点。
- 忽略流媒体内容摊销政策对利润的美化作用。
