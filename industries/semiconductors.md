# 半导体行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于芯片设计、晶圆代工、IDM、存储、设备、材料、EDA/IP、封装测试及半导体系统公司。先按价值链和产品类别拆分；不同环节不能共用同一组周期指标或估值倍数。若公司同时有系统、软件或服务业务，先拆分收入和毛利，再对各环节分别应用本附录。

## 1. 使用原则

- **先定位价值链环节**，再选 KPI 和估值方法。同一个"半导体"标签下，设备公司与存储公司的周期驱动几乎没有交集。
  - **Fabless / 加速器 / CPU**：产品性能、软件生态、系统价值量、design win、代工与先进封装供给。
  - **Foundry / IDM**：制程节点、良率、产能利用率、晶圆 ASP、资本强度和折旧周期。
  - **Memory**：bit shipment、bit growth、ASP、库存、供给纪律和单位成本，**不能只看收入同比**。
  - **Equipment / Materials / EDA / IP**：backlog、订单、客户 capex、服务收入、装机基数、出口管制和客户集中。
  - **OSAT / 测试**：先进封装占比、利用率、单机价值量、良率和客户认证。
- 半导体是**周期性行业**。任何增长结论必须同时说明当前处于库存周期、产能周期和价格周期的哪个位置。
- AI、汽车、工业、手机、PC 等终端周期不同；按终端、地区、客户和产品拆分，**不把行业总增速直接套到公司**。
- 收入增长必须拆成 units、ASP、产品 mix、份额和汇率的贡献。价格驱动的增长与份额驱动的增长价值完全不同。
- 地缘政治是这个行业的结构性变量，不是风险提示的脚注。出口管制、产业补贴和供应链区域化必须进入模型。

## 2. 信息来源与公允机制

### 来源优先级

1. **监管申报与公司披露**：10-K/10-Q/20-F/年报、财报演示、供应商与客户的原始披露。用于确认分部收入、客户集中度、采购承诺、库存和产能规划。
2. **行业统计机构**：WSTS/SIA 的销售、单位和 ASP 统计；SEMI/SEAJ 的设备与 fab 数据；各国海关及 USGS 的材料数据。
3. **监管与政策原文**：出口管制使用 BIS Entity List、欧盟、日本及各地监管机构原文，不引用二手转述。
4. **商业研究**：Gartner、Omdia、TechInsights、TrendForce、Counterpoint、IDC、Yole 可补充份额与价格，但**必须注明样本、口径和发布日期**。
5. **拆机、渠道与供应链消息**：只作线索；至少用公司、客户或产业数据交叉验证后才可写入报告。

### 公允机制

- **分母必须写清**：任何份额和 TAM 都要说明分母定义（按金额还是单位、含不含存储、含不含内部交易）。
- **口径警示**：WSTS 月度数据可能采用移动平均；订单可能重复、取消或跨期；公司自定义的 "AI revenue" 定义各不相同，首次出现时必须写明公司定义。
- **周期与结构分离**：收入增长必须回答是补库存、份额提升、内容量增加还是价格上涨。四者的持续性完全不同。
- **反证优先写入**：例如"AI 需求强劲"必须绑定订单、产能预订、客户 capex 指引或 HBM/先进封装配额，而不是只引用管理层描述。
- **避免幸存者偏差**：peer set 必须纳入周期高点公司、受压公司和已失去节点领先的公司。
- **三层库存验证**：公司库存天数、客户/渠道库存、行业 shipments/ASP 三者必须交叉印证，单看公司库存会严重滞后。

## 3. 半导体价值驱动树

半导体内在价值可以拆成：

```text
企业价值 =
  终端需求总量（按终端市场分别建模）
  × 单机/单系统内容量（content per unit）
  × 市场份额
  × ASP 与价格周期位置
  × 稳态毛利率（良率、mix、成本曲线）
  × 研发与资本强度的回报效率
  × 跨周期 ROIC
  ÷ 风险折现率（含地缘溢价）
  − 库存/产能错配损失
  − 客户与代工集中度风险
  − 出口管制与市场准入损失
```

报告中至少回答：

- 增长来自终端需求、内容量提升、份额获取、价格上涨，还是补库存？
- 技术领先是否已经体现为份额、ASP、毛利率或资本回报？如果没有，领先是否只是叙事？
- 当前处于库存周期的哪个位置？公司、客户和渠道三层库存是否一致？
- 资本开支的回报路径是什么？产能投放时点与需求时点是否匹配？
- 出口管制导致的收入损失是永久性的，还是会被其他地区/客户替代？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 适用环节 | 常见陷阱 |
|---|---|---|---|
| Units / shipments | 出货数量 | Fabless、IDM | 需与终端销量（sell-through）区分，渠道可囤货 |
| ASP | 平均售价 | 全环节 | mix 变化会掩盖真实定价；高端占比上升会推高 ASP |
| Content per unit | 单机半导体价值量 | Fabless | 内容量提升是长期结构性驱动，需与份额分开 |
| Design win | 设计中标 | Fabless | **预告的 design win 不等于已实现收入**，需看量产时点 |
| Market share | 份额（按金额或单位） | 全环节 | 分母定义不同结论可反转 |
| Wafer shipments | 晶圆出货量 | Foundry、IDM | 需结合节点 mix，先进节点单价差异极大 |
| Utilization | 产能利用率 | Foundry、IDM、OSAT | **满载不等于高回报**，取决于节点与定价 |
| Node mix | 制程节点结构 | Foundry | 先进节点占比决定毛利率和技术溢价 |
| Yield | 良率 | Foundry、IDM、OSAT | 早期节点良率爬坡直接决定盈利时点 |
| Wafer ASP | 单片晶圆售价 | Foundry | 客户结构与节点变化影响大 |
| Bit shipment / bit growth | 位元出货与增长 | Memory | 收入增长可能只来自价格，必须拆量价 |
| Cost per bit | 单位成本 | Memory | 制程迁移是长期降本主线 |
| 库存天数 | 存货 / 日均成本 | 全环节 | 需与客户和渠道库存合看 |
| Bookings / backlog | 订单与在手订单 | Equipment、材料 | **backlog 可取消、推迟或重复下单** |
| Book-to-bill | 订单出货比 | Equipment | 部分公司已停止披露，需用替代指标 |
| WFE | 全球晶圆厂设备支出 | Equipment | 行业总量指标，需按客户 capex 交叉验证 |
| Service / 装机基数 | 服务收入与在役设备数 | Equipment | 服务收入是周期缓冲，需单列 |
| RPO / ARR / royalty | 订阅与版税 | EDA/IP | **订阅指标与版税周期不可混在一起** |
| 先进封装收入占比 | CoWoS/HBM 等占比 | OSAT、Foundry | 普通封装与先进封装估值不可混用 |
| Capex / revenue | 资本强度 | Foundry、IDM、Memory | 需与折旧周期和产能投放时点匹配 |
| 跨周期 ROIC | 周期平均投入资本回报 | 重资产环节 | 单年 ROIC 无意义，必须跨周期 |
| 受限收入占比 | 出口管制影响的收入 | 全环节 | 需区分永久损失与可替代部分 |

必须优先披露的 8 个指标：units 与 ASP 拆分、产品/终端 mix、份额、毛利率桥、库存天数（三层）、capex 与折旧、客户集中度、出口受限收入占比。

## 5. 财务模型结构

### 收入模型

按环节选择驱动，避免单一收入增速外推：

1. **Fabless**：`终端销量 × 内容量 × 份额 × ASP`，按终端市场（AI/数据中心、手机、PC、汽车、工业）分别建模。
2. **Foundry / IDM**：代工收入用 `已交付晶圆数 × 每片晶圆 ASP`，按节点分层；晶圆产能乘利用率得到投片量（wafer starts），再按制造周期与库存桥接交付量，已知投片/交付量不再乘利用率。IDM 按实际销售产品使用 `芯片出货量 × 芯片 ASP`，不把晶圆数与芯片单价相乘。
3. **Memory**：`bit shipment × ASP`，同时建供需平衡表（供给增量 vs 需求增量）判断价格方向。
4. **Equipment**：`客户 capex × 份额 × 设备类型 mix` + 服务收入（装机基数 × 单机服务收入）。
5. **EDA/IP**：订阅收入（ARR/RPO 驱动）与版税收入（客户出货量 × 版税率）分开建模。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5 年显性预测，必须显式给出周期假设（价格周期、库存周期、capex 周期的拐点时点）。
- 单列量、价、mix、份额和汇率贡献；无法拆分时写"未获取到拆分"并降低置信度。
- 库存周期用**三层验证**：公司库存天数 + 客户/渠道库存 + 行业 shipments/ASP。

### 成本、资本与毛利率模型

- **毛利率桥**：至少拆价格、产品 mix、良率、代工/材料成本、折旧和一次性库存减值/回冲。短缺定价带来的毛利率不可外推。
- **Capex 与折旧**：做 5–10 年桥，明确产能投放时点、折旧年限和产能爬坡曲线。补贴（如 CHIPS Act）与客户预付款会扭曲 FCF，必须单列。
- **研发强度**：先进节点和大型芯片的研发投入是进入壁垒，也是固定成本。研发/收入比需与产品路线图节奏匹配。
- **净营运资本**：库存、应收、采购承诺（purchase commitment）三者在周期转向时会同时恶化，需一并建模。
- **采购承诺与产能预订**：长期协议（LTA）、产能预付款在需求下行时变成负债，必须从附注中提取。

### 稳态假设边界

- 重资产环节（Foundry/IDM/Memory）的 DCF **必须检查跨周期 ROIC**，不能用高点利润率做永续假设。
- 若库存天数上升、客户 capex 下修、价格进入下行周期，不能同时给高增长、高毛利率和低折现率。
- 存储行业不存在稳定的稳态利润率，必须用跨周期平均或供需平衡推导。
- 出口管制影响若判断为永久损失，必须直接下调 TAM 和终局份额，而不是只加风险溢价。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **反向 DCF**：由现价倒推隐含的终端需求、份额、ASP 路径和稳态毛利率，回答"市场已经 price in 了什么"。
2. **三情景 DCF**：情景必须覆盖终端需求、份额、ASP/价格周期、毛利率、出口限制、供给瓶颈和 capex 回报。**概率不能只由管理层指引决定**。
3. **跨周期倍数**：P/E、EV/EBITDA、EV/Sales 都必须用跨周期正常化盈利。**禁止以峰值利润套中枢倍数**——这是半导体估值最常见的致命错误。
4. **周期位置校准**：明确当前盈利相对跨周期均值的位置（峰值 X% 以上/以下），并说明理由。

### 可选

- **P/B 与重置价值**：Foundry/IDM 在周期底部可用，反映产能重置成本。
- **正常化盈利法**：周期底部先验证终端需求、份额、ASP、库存与产能退出，再从当前盈利桥接到可持续利润率；无恢复证据时历史均值只列条件情景。
- **SOTP**：多业务公司按设计、制造、网络、软件或服务分部估值；**净现金与战略投资单列，避免重复计入**。
- **产能价值法**：设备与材料公司可用装机基数 × 单机生命周期服务价值交叉验证。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- **价值链环节**：Fabless、Foundry、IDM、Memory、Equipment、EDA/IP、OSAT，**不可跨环节混装**。
- 终端市场暴露：AI/数据中心、手机、PC、汽车、工业、消费的占比结构。
- 周期位置：处于补库存、去库存、价格上行还是下行阶段。
- 资本强度：轻资产设计公司与重资产制造公司的估值框架不同。
- 地缘暴露：受出口管制影响程度、产能地理分布、客户地区结构。

剔除项必须说明：若某公司看似同业但资本强度、终端结构或周期位置明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

财报后必须建立四个桥：**收入桥**（units/ASP/mix）、**毛利率桥**（价格/良率/成本）、**库存桥**（公司/客户/渠道）、**供给桥**（产能/先进封装/HBM/设备）。

| 模块 | 必看问题 |
|---|---|
| 预期差 | 收入、毛利率、EPS、下季指引相对一致预期差在哪里？ |
| 收入拆分 | 增量来自 units、ASP、mix、份额还是汇率？来自哪个终端市场？ |
| 订单与消耗 | 订单与终端实际消耗是否一致？是真实需求还是补库存/双重下单？ |
| 库存 | 公司、客户、渠道三层库存方向是否一致？库存天数处于什么分位？ |
| 毛利率 | 变化来自价格、良率、mix、折旧还是库存减值/回冲？ |
| 产品路线图 | 下一代产品量产、良率爬坡和客户采用是否按计划？有无延迟？ |
| 供给 | 先进封装、HBM、代工产能是否成为瓶颈？配额如何分配？ |
| Capex | 资本开支与采购承诺是否领先真实需求？回报路径是否清晰？ |
| 地缘 | 出口管制影响是转移到其他客户/地区，还是永久消失？ |
| 指引 | 收入、毛利率、capex 指引是否改变长期模型和周期判断？ |
| 电话会 | 需求能见度、订单质量、价格环境、客户库存的措辞是否转弱？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易 AI 需求、库存拐点、价格周期还是 capex 回报？ |

财报后价格反应要扣除市场和同业表现：若公司上涨 10%，但半导体指数（如 SOX）同日上涨 6%，公司特异反应约为 +4%。

## 8. 护城河与竞争判断

半导体护城河不能只写"技术领先"。**技术领先必须能体现为份额、ASP、毛利率或资本回报**，否则只是研发支出。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 软件生态锁定 | 开发者工具链、编程模型形成迁移壁垒（如 CUDA） | 只有硬件性能优势，软件可替代 |
| 工艺学习曲线 | 先进节点良率爬坡速度持续领先，成本曲线更陡 | 节点跟随者，良率落后一代 |
| IP 与专利壁垒 | 核心 IP 组合形成交叉授权筹码和进入门槛 | IP 可绕开或已过期 |
| 认证与切换周期 | 汽车/工业/医疗认证周期长，切换成本极高 | 消费级产品，客户可快速切换 |
| 规模与采购议价 | 规模带来晶圆、材料、封装的成本优势 | 规模不足，产能议价能力弱 |
| 装机基数与服务 | 在役设备形成持续服务收入和客户黏性 | 一次性销售，无后续收入 |
| 客户共同设计 | 与头部客户深度联合开发，进入其路线图 | 标准品供应商，价格竞争 |
| 产能与配额控制 | 掌握稀缺产能（先进封装/HBM），可分配配额 | 依赖第三方产能，无优先权 |

定性护城河必须与财务证据交叉：若声称"技术领先"，但份额下滑、ASP 承压、毛利率低于同业，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- 库存与应收账款同时上升，且增速快于收入。
- Backlog 强劲但客户 capex 指引下修——订单可能是双重下单或将被取消。
- 毛利率改善主要靠短缺定价，而非成本下降或产品结构升级。
- 高额 capex 与产能利用率下降并存。
- 产品路线图反复延迟，或量产时点持续后移。
- 单一客户、单一代工厂或单一地区暴露过高且无替代方案。
- 公司自定义的 "AI 收入" 缺乏明确定义或口径反复变化。
- 在周期峰值利润水平上进行大额回购或高价并购。
- 采购承诺（LTA）与产能预付款规模大，但需求能见度下降。
- 存储公司在价格高点扩产，且同业同步扩产（供给纪律破坏）。

### 反证清单

每份半导体报告至少列出 3 个能推翻主结论的证据阈值：

- 份额在某终端市场连续 N 个季度下滑。
- 毛利率跌破某阈值且无法用 mix 或一次性因素解释。
- 库存天数超过历史某分位，或渠道库存显著高于公司库存趋势。
- 良率爬坡或新节点量产延迟超过某时长。
- 客户 capex 指引下修超过某幅度。
- 出口管制扩大到当前仍可销售的产品类别。

### 常见误判

- **用峰值利润套中枢倍数**——半导体估值的头号错误。周期高点的低 P/E 往往是最贵的时候。
- 把补库存需求当结构性增长，导致对下行周期毫无准备。
- 把 backlog 当已锁定收入，忽略取消和推迟条款。
- 把 design win 当收入，忽略量产时点、份额分配和最终销量。
- 把满产当高回报，忽略节点结构和定价水平。
- 把存储的收入增长当量增，实际全部来自价格。
- 把技术领先直接等同于投资价值，忽略是否转化为财务结果。
- 把出口管制影响简单加一个风险折价，而不调整 TAM 和终局份额。
