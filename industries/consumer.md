# 消费行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于品牌消费品、零售、餐饮、服饰、美妆、食品饮料、家居、耐用品和消费服务。先区分品牌商、制造商、渠道商、平台和门店网络；同店、销量和价格的经济含义不同，不可混用同一套 KPI 或估值倍数。

## 1. 使用原则

- **先分辨商业模式**：品牌商赚品牌溢价，零售商赚周转和规模，餐饮赚单店回报，平台赚 take rate。四者的价值驱动和估值框架不同。
- 消费研究的第一问题永远是：**增长来自销量还是价格？** 价格驱动的增长在通胀退潮后会消失，销量驱动的增长才反映真实需求。
- 区分周期消费（耐用品、可选消费）与非周期消费（食品饮料、日用品）。前者需跨周期正常化，后者重点验证定价权。
- **sell-in 不等于 sell-through**。向渠道压货可以短期做出收入，但会以未来的退货、折扣和渠道去库存偿还。
- 同店销售（comparable sales）的口径必须核实：是否含新店、关闭店、汇率、加盟店、线上渠道、退货。
- 毛利率改善必须区分是结构性（品牌力、mix 升级）还是暂时性（原料/运费低位、促销收缩）。

## 2. 信息来源与公允机制

### 来源优先级

1. **监管申报与公司经营数据**：10-K/10-Q/年报、门店明细、分部与地区披露、同店口径说明。
2. **政府消费/价格/库存数据**：美国用 Census Retail Sales/Inventories、BLS CPI/PPI/就业、BEA 消费支出；其他市场用当地统计机构。用于判断公司表现相对行业的位置。
3. **渠道与行业面板**：NIQ、Circana、Euromonitor、Kantar 的份额与价格数据；**必须说明覆盖范围、样本变化和线上线下偏差**。
4. **另类数据**：Similarweb、Sensor Tower、信用卡消费面板、客流数据。只作趋势线索，需与公司披露交叉验证。
5. **社交热度与舆情**：最低层级，只作早期线索，不得作为结论依据。

### 公允机制

- **口径必须记录**：公司自报的同店、GMV、会员数和订单口径，必须写明是否含新店、关闭店、汇率、加盟、退货、税费和第三方渠道。
- **量价必须分离**：任何收入增长结论都要拆成 volume、price、mix、FX、并购和新店贡献。只报"organic growth"不够。
- **公司 vs 行业**：份额变化必须对照政府品类数据或第三方面板，区分公司经营改善与行业周期。
- **反证优先写入**：例如"品牌力提升"必须绑定复购率、全价销售占比、市占提升或提价后的销量弹性，而不是只引用管理层描述。
- **避免幸存者偏差**：peer set 需纳入份额流失和正在关店的同业。
- **区分周期与结构**：需求疲弱可能是宏观周期，也可能是品牌老化或渠道错配。必须用份额、复购和价格带迁移证据判断。

## 3. 消费价值驱动树

按商业模式选择驱动树：

```text
品牌/品类收入 = 销量 × 净价格 × mix × 渠道覆盖
门店收入     = 门店数 × 单店销售（客流 × 转化率 × 客单价）
平台收入     = 活跃用户 × 频次 × 客单价 × take rate

企业价值 =
  当前收入基数
  × 长期销量增长（人口、渗透、品类扩张）
  × 定价权（提价后销量弹性）
  × 稳态毛利率（mix、采购、损耗）
  × 门店/渠道单位经济
  × 费用杠杆（人工、租金、广告、配送）
  ÷ 风险折现率
  − 维护性 capex 与租赁负债
  − 库存与营运资本占用
```

报告中至少回答：

- 增长来自销量、价格、mix、新店还是并购？各贡献多少？
- 提价之后销量弹性如何？消费者是否向低价带或竞品迁移？
- 单店/单客户的经济模型是否健康？新店回报是否高于资本成本？
- 库存与需求是否匹配？折扣率趋势如何？
- 毛利率改善是结构性的还是原料/运费周期给的？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| Volume / units | 销量 | 真实需求 | 被价格增长掩盖的销量下滑是核心风险 |
| Net price | 净价（扣促销、退货） | 真实定价 | 标价上涨可能伴随净价下跌 |
| Price/mix | 价格与结构贡献 | 增长质量 | mix 升级与真实提价需分开 |
| Comparable sales | 同店销售增长 | 存量经营质量 | **口径可排除弱店以美化** |
| Traffic | 客流/交易笔数 | 需求强度 | 客流下降+客单价上升可能是涨价掩盖需求疲软 |
| Transactions / AOV | 交易数 / 客单价 | 消费行为 | AOV 上升可能来自品类结构而非消费升级 |
| New stores / closures | 开关店 | 网络扩张 | 关店可粉饰同店；新店可蚕食老店 |
| Sales per sqft | 坪效 | 门店效率 | 需按业态和地区分层 |
| Four-wall margin | 门店层面利润率 | 单店经济性 | 需扣除分摊前的真实门店成本 |
| 成熟曲线 | 新店达到成熟销售的时长 | 开店价值 | 成熟期假设过短会高估开店回报 |
| Sell-in / sell-through | 出货 / 终端销售 | 渠道健康 | **背离是压货的直接证据** |
| Inventory turns | 存货周转 | 运营效率 | 周转下降常先于折扣 |
| Markdown rate | 折扣率 | 定价健康 | 折扣上升说明产品或库存出问题 |
| Return rate | 退货率 | 产品与渠道质量 | 线上业务退货率显著更高 |
| Repeat / retention | 复购率 | 品牌黏性 | 会员数增长不等于复购改善 |
| Market share | 市场份额 | 竞争地位 | 需说明分母（品类、地区、渠道） |
| DTC 占比 | 直营渠道占比 | 渠道控制与毛利 | DTC 毛利高但费用率也高 |
| Ad spend / revenue | 广告投入率 | 品牌再投资 | 短期削减可抬利润但透支品牌 |
| Occupancy / labor cost | 租金与人工成本率 | 成本结构 | 最低工资和租约续签是刚性上升项 |
| 加盟商回报 | 加盟店单店利润 | 体系健康 | 加盟商亏损会导致关店和体系收缩 |

必须优先披露的 8 个指标：销量与净价拆分、同店销售（含口径）、客流、sell-in vs sell-through、库存周转与折扣率、毛利率桥、复购/留存、单店或单客户经济。

## 5. 财务模型结构

### 收入模型

按模式选择驱动，**收入桥必须拆 volume/traffic、price、mix、FX、并购和新店**：

1. **品牌模型**：按品类/地区/渠道建模，含市占、价格带和新品贡献；**sell-in 与 sell-through 分开**。
2. **门店模型**：含开店、关店、成熟曲线、同店、单位经济、租赁和维护 capex。加盟模式另拆 royalties、加盟商健康度和坏账。
3. **平台模型**：活跃用户 × 频次 × 客单价 × take rate，含补贴对 GMV 的贡献。
4. **耐用品模型**：需区分新增需求与替换需求，替换周期决定长期基线。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5 年显性预测，门店公司必须给出开店节奏、成熟曲线和蚕食假设。
- 单列有机增长与并购影响；无法拆分时写"未获取到拆分"并降低置信度。
- 周期消费必须做跨周期销量正常化，不得用周期高点外推。

### 成本、库存与利润率模型

- **毛利率桥**：拆价格、原料/运费、产品/渠道 mix、促销折扣、损耗和汇率。原料与运费的周期性红利不可外推为结构性改善。
- **费用桥**：拆人工、租金、广告、配送和总部费用。最低工资、租约续签是刚性上升项。
- **营运资本**：关注库存、应收、应付和供应商融资（reverse factoring）。**FCF 改善若来自压库存或拉长应付账期，必须判断可持续性。**
- **广告与再投资**：广告费削减可短期抬升利润，但会透支未来品牌力。需检查广告/收入比的多年趋势。
- **租赁**：租赁负债与租金口径必须一致，EV/EBITDAR 与 EV/EBITDA 不可混用。

### 稳态假设边界

- 优质品牌可长期维持高于同业的毛利率，但必须由复购、全价销售占比和市占支撑。
- 若客流下滑、折扣率上升、库存周转恶化，不能同时给高增长、高毛利率和低折现率。
- 门店公司的白空间（可开店数）假设必须对照人口密度、现有覆盖和蚕食率，不能简单线性外推。
- 加盟体系若加盟商单店回报低于其资本成本，开店计划不可持续。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **反向 DCF**：由现价倒推隐含的销量增长、定价能力、稳态利润率和开店节奏。
2. **三情景 DCF**：bear/base/bull 分别设置销量、价格、毛利率和门店回报；概率和为 1。
3. **正常化 P/E / EV-EBITDA / EV-FCF**：周期消费必须用跨周期正常化盈利。
4. **单位经济估值**：门店公司必须给出成熟门店价值 × 门店数 + 未来开店 NPV 的交叉验证。

### 可选

- **SOTP**：多品牌集团、多业态零售商按品牌或业态分别估值。
- **重置/资产价值**：拥有大量自有物业的零售商可用物业价值设下限。
- **品牌价值法**：仅作交叉参考，不作主估值。

**高增长门店公司不能只按当前 EBITDA 估值**——必须把白空间、开店速度、成熟曲线、蚕食效应和维护性 capex 写入模型。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 商业模式：品牌商、零售商、餐饮、平台，不可混装。
- 品类与价格带：奢侈、高端、大众、折扣的周期性和毛利结构不同。
- 渠道结构：DTC 为主、批发为主、加盟为主。
- 增长阶段：高速开店期、成熟同店驱动、收缩转型期。
- 地理与消费者：发达市场 vs 新兴市场的渗透率和竞争强度。

剔除项必须说明：若某公司看似同业但价格带、渠道或增长阶段明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

财报后必须建立：**收入量价/mix 桥**、**同店桥**、**毛利率桥**、**库存与 markdown 桥**、**门店网络桥**和**指引桥**。

| 模块 | 必看问题 |
|---|---|
| 预期差 | 收入、同店、毛利率、EPS、指引相对一致预期差在哪里？ |
| 量价拆分 | 增长来自销量还是价格？销量是否为负？ |
| 同店 | 同店增长来自客流还是客单价？口径是否有变化？ |
| 渠道 | sell-in 与 sell-through 是否背离？渠道库存水平如何？ |
| 库存 | 库存增速是否高于销售增速？折扣率是否上升？ |
| 毛利率 | 变化来自价格、原料、mix、促销还是汇率？哪部分可持续？ |
| 门店 | 新店是否带来增量还是蚕食老店？关店是否粉饰了同店？ |
| 消费者行为 | 是否出现向低价带迁移、降级消费或减少购买频次？ |
| 费用 | 广告是否被削减以保利润？人工租金压力如何？ |
| 指引 | 收入、利润率、开店指引是否改变长期模型？ |
| 电话会 | 对需求、促销环境、消费者健康、渠道库存的措辞是否转弱？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易需求复苏、利润率修复、库存去化还是份额变化？ |

必须对照政府品类数据和竞争者披露，**区分公司份额变化与行业周期**。

财报后价格反应要扣除市场和同业表现：若公司上涨 8%，但消费板块指数同日上涨 4%，公司特异反应约为 +4%。

## 8. 护城河与竞争判断

消费行业护城河不能只写"品牌知名度高"。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 定价权 | 多次提价后销量未显著下滑，市占稳定 | 提价即失份额，或需靠促销回补 |
| 复购与忠诚 | 高复购率、会员消费占比高且客单价上升 | 会员数增长但复购率下降 |
| 分销壁垒 | 货架位、渠道深度、独家合作难以复制 | 依赖单一渠道或平台，议价能力弱 |
| 规模采购 | 采购成本显著低于同业，且随规模持续改善 | 规模大但毛利率不优于同业 |
| 门店/位置资产 | 优质点位长期锁定，租金成本低于市价 | 租约集中到期，续租成本大幅上升 |
| 产品创新 | 新品持续贡献增量收入且成功率稳定 | 新品命中率低，靠单一爆款 |
| 心智占有 | 品类无提示第一提及率高，广告效率高 | 需持续高广告投入维持份额 |
| 成本结构优势 | 供应链或自有产能带来结构性成本优势 | 成本优势来自暂时的原料周期 |

定性护城河必须与财务证据交叉：若声称"强品牌定价权"，但折扣率上升、全价销售占比下降、市占流失，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- 收入增长完全由价格驱动，销量持续下滑。
- sell-in 显著强于 sell-through，渠道库存累积。
- 库存增速和折扣率同时上升。
- 同店口径调整，排除大量弱店或新增线上渠道。
- 会员数、GMV 增长但不转化为收入和经营现金流。
- 频繁收购品牌以维持增长，有机增长持续放缓。
- "调整后利润"长期剔除门店关闭、重组等经常性发生的费用。
- 加盟商单店回报恶化，加盟商关店率上升。
- 短期削减广告投入抬高利润率。
- FCF 改善主要来自拉长应付账期或供应链融资。
- 客流持续下降但用提价维持收入。

### 反证清单

每份消费报告至少列出 3 个能推翻主结论的证据阈值：

- 销量连续 N 个季度负增长。
- 同店销售或客流跌破某阈值。
- 库存增速超过销售增速某个百分点，或周转天数超过某阈值。
- 折扣率/markdown 超过历史某分位。
- 复购率或会员消费占比下降超过某幅度。
- 新店回报或加盟商单店利润低于资本成本。

### 常见误判

- **把价格驱动的收入增长当需求强劲**，忽略销量已在下滑。
- 把同店增长当经营改善，忽略是关闭弱店后的幸存者效应。
- 把 sell-in 增长当终端热销，忽略渠道压货。
- 把原料/运费下行带来的毛利率改善当结构性能力。
- 把 GMV 或会员增长当价值创造，忽略变现和现金流。
- 把开店速度当增长确定性，忽略蚕食和成熟曲线拉长。
- 把削减广告后的利润率改善当经营杠杆。
- 对高增长门店公司直接用当前 EBITDA 倍数，忽略维护性 capex 和门店老化。
