# 保险行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于财产险、寿险、健康险、再保险、保险经纪和综合保险集团。先按险种拆分；承保风险、资产负债久期和资本制度不同，不能用单一"保费增长"判断质量。若集团同时有大额资管或银行业务，先按分部拆分利润与资本占用，再只对保险部分使用本附录。

## 1. 使用原则

- 先确定险种结构：财产险、寿险/年金、健康险、再保险、经纪的经济模型完全不同，**不得混用同一套 KPI 或估值倍数**。
- 保险研究的核心不是保费增速，而是**承保是否盈利、准备金是否充足、资本是否可分配**。保费增长在定价不足时是价值毁灭。
- 区分承保利润与投资收益。靠投资端弥补承保亏损的模式在利率下行或信用事件中会同时失效。
- 会计口径差异极大：IFRS 17 与 US GAAP（LDTI）、法定报表与集团报表、EV 与账面价值。跨市场横比前先桥接。
- 所有"利润改善"结论必须先回答：来自当期承保、往年准备金释放、投资收益，还是精算假设变更？
- 准备金是估计值，不是事实。任何盈利质量判断必须建立在准备金发展三角上。

## 2. 信息来源与公允机制

### 来源优先级

1. **法定监管报表与偿付能力报告**：美国用州监管/NAIC statutory statements、RBC 与 IRIS；欧盟用 SFCR/Solvency II；中国用国家金融监督管理总局及公司偿付能力报告；香港用 HKIA。用于确认法定资本、准备金充足性和可分配性。
2. **公司会计报表与精算披露**：年报、EV 报告、CSM 滚动表、准备金发展三角、敏感性分析。
3. **监管与行业数据**：行业保费统计、费率监管备案、巨灾模型机构（如 RMS/Verisk）公开信息、行业损失估计。
4. **电话会文字稿**：跟踪管理层对费率周期、准备金充足性、巨灾预算、再保成本和资本返还的措辞变化。
5. **同业披露与第三方**：用于建立 peer set 和合理区间；卖方研究只作补充，不得替代一手披露。

**RBC / 偿付能力充足率是监管干预工具，不是跨公司单独排名指标**——不同资本制度下的数值不可直接横比。

### 公允机制

- **口径优先**：combined ratio 是否含巨灾、是否含往年发展、是净额还是毛额，各家不同。首次出现时写明定义，未披露则写"未获取到公司定义"。
- **当期与往年分离**：承保利润必须拆分当年事故年（current accident year）与往年准备金发展（prior-year development）。只看总 combined ratio 会严重误导。
- **承保与投资并列**：任何"ROE 改善"结论必须同时说明承保利润率、投资收益率和资本杠杆各贡献多少。
- **反证优先写入**：例如"定价周期向好"必须绑定 rate change、retention、新单 loss ratio，而不是只引用管理层描述。
- **避免幸存者偏差**：peer set 必须纳入承保纪律好的、周期受压的和出过准备金问题的同业。
- **区分周期与结构**：combined ratio 改善可能是硬市场周期，也可能是风险选择能力提升。必须用费率、暴露、损失趋势和同业对比判断。

## 3. 保险价值驱动树

保险内在价值可以拆成：

```text
权益价值 =
  调整后净资产（P&C）或 内含价值 EV（寿险）
  + 未来新业务价值（VNB × 增长与持续期）
  × 承保盈利能力（跨周期 combined ratio 或 MLR）
  × 浮存金规模与成本优势
  × 投资组合风险调整后收益
  × 资本效率与可分配性
  − 准备金不足风险（尾部）
  − 巨灾与集中度暴露
  − 监管资本约束与假设变更风险
```

报告中至少回答：

- 承保是否独立盈利（combined ratio < 100 或 MLR 可持续）？还是靠投资端补贴？
- 浮存金的成本是正是负？规模能否随业务增长？
- 准备金发展是持续有利、中性还是不利？连续多年有利释放是否已经透支？
- 投资收益提升是否以信用下沉、久期错配或流动性牺牲换取？
- 集团层面的资本能否上移到控股公司并真实分配给股东？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 适用险种 | 常见陷阱 |
|---|---|---|---|
| GWP / NWP | 毛/净已签保费 | P&C、再保 | 毛净差反映再保依赖度，需分列 |
| Earned premium | 已赚保费 | P&C、健康 | 与已签保费的时滞在增长期会扭曲比率 |
| Loss ratio | 赔付 / 已赚保费 | P&C、再保 | 需拆当年事故年与往年发展 |
| Expense ratio | 费用 / 已赚保费 | P&C、再保 | 佣金与管理费需分列 |
| Combined ratio | loss ratio + expense ratio | P&C、再保 | **低于 100 才是承保盈利**；低值可能来自往年释放 |
| Prior-year development | 往年准备金调整 | P&C、再保 | 连续有利释放可能透支未来缓冲 |
| Cat loss ratio | 巨灾损失 / 已赚保费 | P&C、再保 | 单年无灾不代表可持续，需用多年均值正常化 |
| Rate change | 续保费率变动 | P&C、再保 | 与 exposure growth 混淆是常见错误 |
| Retention | 续保率 | P&C、经纪 | 高留存若靠降价则是负面信号 |
| APE | 年化保费等值 | 寿险 | 销售规模指标，不等于价值 |
| VNB / NBV | 新业务价值 | 寿险 | 高度依赖假设（贴现率、退保、死亡率） |
| VNB margin | VNB / APE | 寿险 | 产品结构变化影响大 |
| CSM | 合同服务边际（IFRS 17） | 寿险 | 假设变更可推高 CSM 而无真实现金流改善 |
| EV | 内含价值 | 寿险 | 必须审计假设与敏感性，非审计 EV 可信度低 |
| Lapse / surrender rate | 退保率 | 寿险 | 利率上行期退保激增会强制变现资产 |
| Spread | 投资收益率 − 保证成本 | 寿险、年金 | 保证利率是刚性负债，利差可转负 |
| Membership | 参保会员数 | 健康险 | 会员结构（商业/政府）利润率差异大 |
| MLR | 医疗赔付 / 保费 | 健康险 | 受风险调整、季节性和政策影响 |
| Organic growth | 剔除并购的收入增长 | 经纪 | 并购驱动增长需单独还原 |
| FCF conversion | FCF / EBITDA | 经纪 | 调整后 EBITDA 常剔除经常性费用 |
| 偿付能力充足率 | 法定资本 / 最低要求 | 全险种 | 集团与法定实体口径不同，可转移性需单独判断 |
| ROE / ROTCE | 净利润 / 权益 | 全险种 | 需正常化巨灾与准备金发展 |

必须优先披露的 8 个指标（按险种选取）：combined ratio（当年 vs 往年拆分）、rate change、准备金发展、巨灾损失、VNB/CSM（寿险）、MLR（健康）、投资组合结构与久期、偿付能力充足率。

## 5. 财务模型结构

### 承保与收入模型

按险种选择驱动：

1. **P&C**：`暴露单位 × 费率 = 已签保费` → 已赚保费 → 分当年事故年 loss ratio 与往年发展 → 加费用率 → combined ratio。
2. **寿险**：`APE × VNB margin = VNB`；存量用 CSM 滚动表（新增、释放、假设变更、利息增值）与 EV 变动分析。
3. **健康险**：`会员数 × 人均保费 = 保费收入`；成本端用 `医疗成本趋势 × 利用率 × 单价`。
4. **再保险**：按合约类型（比例/超赔）建模，含限额、附着点、恢复条款和续保定价周期。
5. **经纪**：`佣金率 × 承保保费 + 费用收入`，分有机增长与并购。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5 年显性预测，巨灾损失用多年均值而非当期实际值。
- P&C 必须做事故年/承保年三角、频率/严重度分解、准备金发展和再保可收回款；区分当年承保与往年释放。
- 寿险必须做资产负债久期匹配、保证利率、利差、退保和再投资收益率；检查会计准则（LDTI/IFRS 17）变化的影响。

### 投资、准备金与资本模型

- **投资组合**：按信用评级、久期、流动性、商业地产/另类资产和未实现损益拆分。**收益率提升可能是以信用下沉或流动性牺牲换取的**，必须单独判断。
- **久期匹配**：寿险负债久期长，资产负债缺口在利率变动时直接冲击经济价值。缺口必须量化。
- **准备金充足性**：用发展三角判断历史准备金估计的偏差方向和幅度；连续有利发展需警惕缓冲耗尽。
- **再保险**：检查对手方集中度、抵押安排、合同条款、限额/附着点和续保价格趋势。再保成本上升会直接压缩净留存利润。
- **资本桥**：拆经营盈利、市场变动、模型/监管变化、分红回购和并购；同时看集团与法定实体的资本可转移性。

### 稳态假设边界

- 优质 P&C 可长期维持 combined ratio 低于 100，但必须由风险选择、定价纪律和费用效率支持，不能靠持续的往年释放。
- 若准备金持续不利发展、巨灾暴露上升、再保成本恶化，不能同时给低 combined ratio、高增长和高分红。
- 寿险的高 VNB 增长若依赖激进假设（高贴现率、低退保率），必须做敏感性并下调置信度。
- 投资收益率假设不得高于当前组合的再投资收益率加合理利差，且需与信用风险暴露一致。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **P&C：P/B 或 P/TBV 对应正常化 ROE**，加股利折现/残余收益。巨灾损失和准备金释放必须按周期正常化。
2. **寿险：P/EV 与 VNB 倍数**。`权益价值 ≈ 调整后 EV + VNB × 新业务倍数`。必须审计 EV 假设、敏感性、资本成本与可分配现金。
3. **健康险：正常化 P/E 或 P/FCF** + 会员/费率/医疗成本三情景。
4. **反向估值**：至少推导现价隐含的 combined ratio、正常化 ROE、VNB 增长或 medical cost trend，回答"市场已经 price in 了什么"。

### 可选

- **SOTP**：综合保险集团同时有 P&C、寿险、健康、资管时使用，各分部给不同资本占用和倍数。
- **经纪：EV/EBITDA 或 EV/FCF** 可用（经纪是轻资本服务业，不承担承保风险），但并购、股权激励和杠杆需还原。
- **清算/调整净资产**：严重折价时用扣除准备金缺口、未实现投资损失和商誉后的调整净资产设下限。

**不能把账面价值折价自动等同低估**——若正常化 ROE 低于权益成本，折价是合理的。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 险种结构：P&C 商业险、P&C 个人险、寿险、健康、再保、经纪，不可混装。
- 风险偏好：长尾险（责任、工伤）与短尾险（车险、财产）的准备金不确定性差异极大。
- 地理与监管：所处资本制度（Solvency II / RBC / C-ROSS）、费率监管强度、巨灾暴露地区。
- 周期位置：硬市场/软市场、费率上行/下行阶段。
- 资本状态：偿付能力富余程度与资本返还能力。

剔除项必须说明：若某公司看似同业但险种结构、久期特征或资本制度明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

财报模式必须回答"这份财报改变了什么"，而不是只列 beat/miss。

| 模块 | 必看问题 |
|---|---|
| 预期差 | 保费、combined ratio、投资收益、EPS、EV/VNB 相对一致预期和指引差在哪里？ |
| 承保利润桥 | 当年事故年 loss ratio 与往年准备金发展各贡献多少？剔除释放后承保是否仍盈利？ |
| 保费量价桥 | 增长来自费率、暴露增长、新客户还是并购？费率是否覆盖损失趋势？ |
| 巨灾与正常化 | 本期巨灾损失相对全年预算和多年均值处于什么位置？ |
| 准备金 | 发展三角是否显示某事故年持续恶化？管理层是否调整了假设？ |
| 寿险专项 | VNB、CSM、EV 变动来自新业务、假设变更、市场波动还是运营偏差？ |
| 健康险专项 | MLR 变化来自利用率、单价、风险调整还是会员结构？ |
| 投资 | 收益率提升是否伴随信用下沉、久期拉长或流动性下降？未实现损益变化多大？ |
| 资本 | 偿付能力变化是经营、市场还是模型驱动？法定实体能否上移分红？ |
| 指引 | combined ratio、巨灾预算、VNB 增长或资本返还指引是否改变长期模型？ |
| 电话会 | 费率周期、准备金充足性、再保成本、竞争强度的措辞是否转弱？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易费率周期、准备金风险、投资收益还是资本返还？ |

财报后价格反应要扣除市场和同业表现：若公司上涨 7%，但保险股指数同日上涨 4%，公司特异反应约为 +3%。

## 8. 护城河与竞争判断

保险是同质化商品行业，护城河不能只写"品牌好"。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 承保纪律 | 软市场主动收缩保费、跨周期 combined ratio 稳定优于同业 | 市场软时仍追求份额增长 |
| 数据与定价能力 | 独有数据、定价模型使同类风险 loss ratio 持续更低 | 定价靠行业费率表，无差异化 |
| 分销控制 | 直销、专属代理或深度嵌入渠道，获客成本低且稳定 | 依赖第三方经纪，议价能力弱 |
| 浮存金成本 | 长期浮存金成本为负或极低，且规模可增长 | 浮存金成本高于无风险利率 |
| 规模与再保议价 | 规模带来再保成本优势和费用率优势 | 规模大但费用率不优于同业 |
| 风险选择 | 特定细分市场（专业险种）有信息优势 | 全险种铺开但无一细分领先 |
| 资本韧性 | 巨灾/信用事件后仍能承保扩张（逆周期能力） | 事件后被迫收缩或增发 |

定性护城河必须与财务证据交叉：若声称"承保纪律优秀"，但当年事故年 loss ratio 高于同业、靠往年释放维持利润，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- 准备金持续不利发展，尤其集中在长尾险种（责任险、工伤、医疗事故）。
- 保费增长显著快于资本增长与定价改善，暗示承销放松。
- combined ratio 低于 100 但完全依赖往年释放，当年事故年实际亏损。
- 投资组合中高收益/非流动/另类资产占比快速上升。
- 寿险退保率和保证成本同时上升，尤其在利率快速上行期。
- 再保成本上升、附着点抬高或限额收紧，而公司未相应调整定价或留存。
- 集团资本比率健康但法定实体资本不可分配（trapped capital）。
- 频繁调整精算假设，且方向总是有利于当期利润。
- 灾害模型和气候暴露披露不足，或未更新至最新巨灾模型版本。
- 健康险 MLR 持续上升但费率申请受监管限制。

### 反证清单

每份保险报告至少列出 3 个能推翻主结论的证据阈值：

- 当年事故年 combined ratio（剔除往年发展）突破某阈值。
- 准备金发展由有利转为不利，或某事故年连续 N 期恶化。
- 退保率 / MLR 超过阈值。
- 偿付能力充足率跌破管理层目标区间。
- 投资组合未实现损失超过权益的某个比例。
- 再保成本上升幅度超过费率上涨幅度。

### 常见误判

- 把低 combined ratio 当承保能力强，忽略其中往年释放的贡献。
- 把单年无巨灾的高利润当可持续，未做多年正常化。
- 把保费高增长当经营改善，忽略可能是软市场抢份额。
- 把 EV 或 CSM 增长当价值创造，忽略假设变更的贡献。
- 把高投资收益率当能力，忽略信用下沉和久期风险。
- 把账面价值折价当低估，忽略正常化 ROE 低于权益成本。
- 把集团偿付能力充足当股东可得，忽略法定实体资本的转移限制。
