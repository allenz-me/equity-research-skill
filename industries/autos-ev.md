# 汽车/EV 行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于整车（OEM）、EV 新势力、零部件、经销商、电池链整车侧。特征：重资产低毛利强周期 + 电动化/智能化重构价值链。**传统框架与成长框架必须分开使用，再做对账**。

## 1. 使用原则

- **先分辨公司类型**，框架完全不同：
  - **传统 OEM**：周期价值股框架——中周期盈利、产能利用率、净现金。**金融子公司必须拆开**：工业实体与金融实体分别估值。
  - **EV 纯玩家**：成长框架——单车经济（ASP − BOM − 制造费用）、爬产斜率、现金 runway。盈利前公司用反向 DCF + 情景。
  - **零部件**：客户/平台绑定、单车价值量（CPV）提升逻辑（电动化受益还是受损）、年降压力。
  - **经销商**：新车毛利、售后服务、金融保险渗透率、库存周转。
- **智能驾驶/软件收入是期权性资产**，必须单独定价，**给概率不给确定性**。不得把未兑现的软件收入计入基准情景。
- 汽车是重资产强周期行业。任何盈利判断必须回答**盈亏平衡销量**是多少，以及当前销量相对该点的位置。
- **批发（wholesale）与零售（retail）口径必须分离**。批零剪刀差扩大是压库的直接证据。
- 单车毛利必须**剔除监管积分收入**后计算，否则会系统性高估制造能力。

## 2. 信息来源与公允机制

### 来源优先级

1. **各国上险量/注册数据**：中国交强险、欧洲 ACEA、美国注册数据。**这些优于公司自报交付量**，因为反映真实终端销售而非渠道出货。
2. **监管申报与公司披露**：10-K/10-Q/年报、月度或季度交付公告、产能与工厂披露、金融子公司单独报表。
3. **行业协会与政府数据**：各国汽车工业协会产销数据、补贴政策原文、排放法规与积分制度。
4. **终端价格监测**：经销商折扣、终端成交价、库存系数。价格战期间是关键高频指标。
5. **供应链与渠道调研**：电池、芯片供应，只作线索，需交叉验证。

### 公允机制

- **交付口径写明**：批发 vs 零售、是否含出口、是否含租赁车队、是否含未交付的已生产车辆。
- **单车毛利口径**：必须写明是否剔除监管积分（如中国双积分、美国 ZEV credits、欧盟 CO2 pooling）、是否含运费、是否含保修计提。
- **量价必须分离**：收入增长拆销量、ASP、车型 mix、地区 mix 和汇率。
- **反证优先写入**：例如"需求强劲"必须绑定上险量、订单/交付周期、终端折扣和库存天数，而不是只引用管理层描述。
- **区分周期与结构**：销量下滑可能是行业周期，也可能是产品竞争力下降。必须用份额和终端价格证据区分。
- **避免幸存者偏差**：peer set 需纳入份额流失的传统 OEM 和已出局的 EV 新势力。

## 3. 汽车价值驱动树

```text
整车价值 =
  销量 × (ASP − 单车成本) × 周期调整
  + 售后/零部件业务
  + 金融子公司价值（单独估值）
  + 软件/自动驾驶期权（概率加权）
  − 产能过剩与固定成本负担
  − 残值、召回与保修负债
  − 电动化转型资本开支

单车经济 = ASP − 材料成本(BOM) − 直接人工 − 制造费用分摊 − 运费与保修
盈亏平衡销量 = 固定成本 / 单车贡献毛利
```

报告中至少回答：

- 剔除监管积分后的真实单车毛利是多少？趋势如何？
- 盈亏平衡销量是多少？当前销量相对该点的位置和安全边际？
- 销量增长来自新车型、降价还是渠道压库？
- 电池成本（$/kWh）路径如何？技术路线是否有成本或性能劣势？
- 现金能支撑多少个季度（EV 新势力必答）？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 适用类型 | 常见陷阱 |
|---|---|---|---|
| 销量 / 交付 | 分地区分车型 | OEM、EV | **批发 vs 零售口径必须分清** |
| 上险量 / 注册量 | 终端真实销售 | OEM、EV | 优于公司自报交付 |
| 批零剪刀差 | 批发量 − 零售量 | OEM | **扩大即压库** |
| 渠道库存天数 | 经销商库存 / 日均销量 | OEM、经销商 | 高库存预示后续降价 |
| ASP | 平均售价 | OEM、EV | 车型 mix 变化会掩盖真实降价 |
| 单车毛利 | (ASP − 单车成本) | OEM、EV | **必须剔除监管积分后计算** |
| 监管积分收入 | ZEV/双积分/CO2 池收入 | EV、OEM | 常被计入毛利美化利润率 |
| 单车成本 / BOM | 材料清单成本 | EV | 电池占比最高，需单列 |
| 电池成本 $/kWh | 电芯与 pack 成本 | EV | 原材料联动定价存在滞后 |
| 产能利用率 | 实际产量 / 设计产能 | OEM、EV | 低利用率导致固定成本摊薄不足 |
| 盈亏平衡销量 | 固定成本 / 单车贡献 | OEM、EV | **重资产行业的核心指标** |
| 订单 / 交付周期 | 在手订单与等待时长 | EV | **可退订金的订单容易注水** |
| 终端折扣 | 实际成交相对指导价 | OEM、EV | 价格战的直接读数 |
| CPV（单车价值量） | 零部件在单车中的价值 | 零部件 | 电动化对不同部件是增是减 |
| 年降 | 年度降价要求 | 零部件 | 通常 3–5%/年，压缩毛利 |
| ICE 依赖收入占比 | 燃油车相关收入 | 零部件 | 终值折价的关键因子 |
| 金融渗透率 | 金融方案渗透比例 | OEM 金融 | 促销性贴息可能藏在金融子公司 |
| 残值风险 | 租赁车残值假设 | OEM 金融 | EV 残值下跌是重大风险 |
| 坏账率 | 金融子公司信用损失 | OEM 金融 | 经济下行时快速上升 |
| 现金 runway | 现金 / 季度净烧钱 | EV 新势力 | **盈利前公司的第一指标** |
| 研发资本化率 | 资本化研发 / 总研发 | 全类型 | 激进资本化美化当期利润 |

必须优先披露的 8 个指标：销量（批发/零售分列）、上险量、剔积分单车毛利、盈亏平衡销量、渠道库存天数、终端折扣、电池成本趋势、现金 runway（EV）。

## 5. 财务模型结构

### 收入与单车经济模型

1. **销量模型**：按地区 × 车型建模，区分批发与零售，显式给出渠道库存变化。
2. **ASP 模型**：`指导价 − 终端折扣 × mix 调整`，价格战期间必须逐季更新。
3. **单车成本**：拆 BOM（电池、芯片、其他）、直接人工、制造费用分摊、运费和保修计提。
4. **零部件**：`客户平台销量 × CPV × 份额`，扣除年降。
5. **金融子公司**：单独建资产负债表——生息资产、利差、渗透率、残值和坏账，**不得与工业实体合并**。
6. **软件/自动驾驶**：按渗透率 × 单价 × 概率建模，单列并标注为期权价值。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5 年显性预测，显式给出产能爬坡曲线和盈亏平衡时点（EV 公司）。
- 单车毛利必须逐季给出，且剔除监管积分。
- 传统 OEM 必须做跨周期销量正常化，不得用周期高点外推。

### 成本、产能与现金模型

- **固定成本与盈亏平衡**：明确固定成本规模，计算盈亏平衡销量。新厂爬坡期的亏损**不得归为"一次性"**——爬坡是常态化经营的一部分。
- **电池成本路径**：按技术路线（LFP/三元/固态）给出 $/kWh 趋势，并说明原材料价格联动的滞后期。
- **产能与利用率**：产能过剩会显著恶化单位成本，需将利用率与单车成本联动。
- **营运资本**：**应付账款周期异常拉长等于拿供应商当融资**，必须单独识别并在现金流质量中扣除。
- **现金 runway**（EV 新势力必做）：`可用现金 / 季度净烧钱率`，并说明下一轮融资的时点与稀释幅度。
- **保修与召回**：计提是否充分，历史召回频率和单次成本。

### 稳态假设边界

- 传统 OEM 的终值使用有证据的可持续利润率，区分产品结构变化、竞争压力与周期恢复，不机械套历史均值或高点。
- EV 公司若销量低于盈亏平衡点，不能同时假设快速降本、维持 ASP 和无稀释融资。
- 软件/自动驾驶收入的稳态渗透率必须有概率约束，不得默认全量兑现。
- 零部件公司的终值需按 ICE 依赖收入占比做折价。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **传统 OEM**：经恢复审查的工业盈利 × 有来源的匹配倍数，金融子公司单独估值；明确工业盈利是否剔除现金收益，避免净现金重复计价。EV/Sales 需额外解释可持续利润率与资本需求。
2. **EV 成长期**：反向 DCF 用于现价诊断——由现价倒推隐含的销量 × 单车利润，并**对照全球汽车行业总利润池的物理上限**检验合理性。
3. **三情景 DCF**：覆盖销量、ASP/价格战、单车成本、产能利用率和融资稀释。
4. **零部件**：EV/EBITDA + 订单簿覆盖；**电动化敞口（ICE 依赖收入占比）作为终值折价因子**。

### 可选

- **SOTP**：工业实体 + 金融子公司 + 软件期权 + 其他投资分别估值。
- **单车经济法**：`稳态销量 × 稳态单车净利 × 中枢 P/E` 作为交叉验证。
- **重置价值**：极端低估时用产能重置成本设下限。

**残值、召回和价格战风险必须用情景概率处理，不做平均化**——这些是尾部风险，平均化会掩盖破产可能。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 类型：传统 OEM、EV 纯玩家、零部件、经销商，不可混装。
- 价格带与品牌定位：豪华、主流、经济型的毛利结构差异巨大。
- 电动化阶段：ICE 为主、转型中、纯电。
- 地区：中国、欧洲、北美的竞争强度、补贴和法规不同。
- 盈利状态：已盈利、接近盈亏平衡、深度亏损，估值框架不同。

剔除项必须说明：若某公司看似同业但盈利状态或电动化阶段明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

| 模块 | 必看问题 |
|---|---|
| 预期差 | 交付量、ASP、单车毛利、EPS、指引相对一致预期差在哪里？ |
| 销量质量 | 批发与零售是否背离？渠道库存天数变化？上险量印证如何？ |
| 单车毛利 | **剔除积分后的环比变化**？降本来自电池、规模还是设计优化？ |
| 价格行动 | 本期是否降价？终端折扣幅度？对后续毛利的影响？ |
| 产能爬坡 | 新工厂/新车型爬坡是否按计划？利用率与单位成本？ |
| 盈亏平衡 | 当前销量距盈亏平衡点多远？何时可达？ |
| FCF | **成长期公司现金比利润重要一个量级**——烧钱率与 runway 变化？ |
| 金融子公司 | 渗透率、残值假设、坏账率是否恶化？是否在补贴销售？ |
| 软件收入 | 是否有实际递延收入确认？渗透率与定价？ |
| 指引 | 交付、毛利率、capex 指引是否改变长期模型？ |
| 电话会 | 对需求、价格战、订单、产能、融资的措辞是否转弱？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易交付量、单车毛利、价格战还是自动驾驶进展？ |

**月度销量必须高频跟踪**，并配合终端折扣数据监测价格战强度。

财报后价格反应要扣除市场和同业表现：若公司上涨 10%，但汽车板块同日上涨 5%，公司特异反应约为 +5%。

## 8. 护城河与竞争判断

汽车是重资产、低毛利、高竞争行业，护城河稀缺。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 品牌与定价权 | 长期溢价定价，终端折扣显著低于同业 | 依赖折扣促销维持销量 |
| 成本结构 | 单车成本结构性低于同业，且可持续 | 成本优势来自补贴或暂时的原材料价格 |
| 规模与平台 | 平台化摊薄研发和制造成本 | 车型分散，平台复用率低 |
| 电池与三电技术 | 自研电池或深度绑定，$/kWh 领先 | 依赖外购电池，无议价能力 |
| 软件与数据 | 车队数据规模形成自动驾驶迭代优势，且已变现 | 软件只是叙事，无收入验证 |
| 渠道与服务网络 | 直营/经销网络覆盖广，售后利润稳定 | 网络不足或经销商亏损 |
| 供应链掌控 | 关键零部件自制或长协锁定 | 芯片/电池受制于人 |
| 转型执行力 | 电动化转型按计划推进且未损害现金流 | 转型投入巨大但份额未提升 |

定性护城河必须与财务证据交叉：若声称"品牌溢价"，但终端折扣扩大、剔积分单车毛利低于同业，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- **批零剪刀差扩大**（批发远高于零售），渠道库存天数上升。
- **应付账款周期异常拉长**——把供应商当融资来源。
- 单车毛利依赖监管积分收入，剔除后接近或低于零。
- 研发资本化比例激进上升，美化当期利润。
- 新厂爬坡亏损被反复归类为"一次性"费用。
- 订单数字亮眼但订金可全额退还，且交付周期在缩短。
- 金融子公司渗透率快速上升，可能在用贴息补贴销售。
- EV 残值假设未随二手车价格下跌而下调。
- 创始人或大股东股权质押比例高。
- 现金 runway 不足 4 个季度但未披露融资计划。
- 频繁降价但销量未相应增长（需求弹性失效）。

### 反证清单

每份汽车报告至少列出 3 个能推翻主结论的证据阈值：

- 上险量连续 N 个月同比下滑，或市场份额跌破某阈值。
- 剔积分单车毛利跌破某阈值或转负。
- 渠道库存天数超过某水平。
- 终端折扣幅度超过某比例。
- 产能利用率低于盈亏平衡所需水平。
- 现金 runway 低于 N 个季度且融资环境恶化。

### 常见误判

- **用 EV/Sales 给周期性 OEM 估值**——重资产低毛利行业该指标毫无意义。
- 把含监管积分的毛利率当制造能力。
- 把批发交付当终端需求，忽略渠道压库。
- 把订单量当锁定需求，忽略可退订金。
- 把工业实体与金融子公司合并估值，掩盖金融端风险。
- 把自动驾驶/软件收入计入基准情景，而非期权价值。
- 忽略盈亏平衡销量，对固定成本杠杆的破坏力估计不足。
- 对成长期 EV 公司只看利润不看现金，忽略融资稀释。

### 盈亏平衡测算（必备）

| 项目 | 数值 | 说明 |
