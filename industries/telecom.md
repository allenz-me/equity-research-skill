# 电信行业深度研究附录

> 适用范围：完整研究执行本附录的整套表格；专题和直接回答仅选相关 KPI 与模型。历史分位仅在样本可核验时报告，否则写区间或资料缺口。增长持续、正常化盈利与恢复均服从 [研究证据审查](../references/research-review.md)，未通过的乐观路径仅列 conditional；方法清单不构成数量要求，反向 DCF 仅作定价诊断；未被 `dcf.py` 支持的行业模型须另行复算。

适用于移动/固网运营商、铁塔、卫星通信。特征：重资本 + 强监管 + 寡头竞争 + 高股息。**价值几乎全部取决于三件事：竞争理性度、资本开支纪律、股息可持续性。**

## 1. 使用原则

- **电信是本地市场生意**。必须按国别/市场分别分析竞争格局：**3 家理性竞争与 4 家价格战的估值天差地别**。跨国集团一律做 SOTP。
- **对增长叙事默认怀疑**。5G、FTTH、物联网、边缘计算等"新周期"叙事在历史上**多数未转化为 ROIC 改善**——资本开支上去了，ARPU 没上去。要求 ARPU 与 capex 回报的实证证据，而非技术前景描述。
- **铁塔/基础设施分部单独估值**：长期合约、CPI 联动、现金流稳定，应给显著高于运营业务的倍数。
- **FCF 和股息覆盖是核心**，不是 EBITDA。电信的 EBITDA 与 FCF 之间隔着巨额 capex 和频谱支出。
- **频谱费用是隐性资本开支**，必须计入现金流，不能只在附注里提一句。
- 会计准则（IFRS 16 租赁）会显著抬高 EBITDA。跨期、跨公司比较必须用租赁调整后（after-lease, aL）口径。

## 2. 信息来源与公允机制

### 来源优先级

1. **监管机构统计**：FCC（美国）、Ofcom（英国）、工信部（中国）、各国 NRA。提供用户数、市场份额、投诉率、频谱持有和拍卖结果——**这是判断竞争格局最客观的来源**。
2. **公司 KPI 包**：运营商披露通常非常详尽（分后付费/预付费、ARPU、churn、capex 明细）。
3. **行业数据**：GSMA、Ericsson Mobility Report、各国宽带渗透统计。
4. **频谱拍卖文件**：拍卖规则、结果、支付时间表和续费条款。
5. **竞争对手披露**：同市场竞对的定价与促销行为是判断竞争理性度的直接证据。

### 公允机制

- **用户口径必须写明**：后付费与预付费、物联网连接数、批发（MVNO）用户是否计入。**物联网卡和预付费可以轻易冲量，掩盖真实用户流失**。
- **ARPU 口径**：是否含终端销售、是否含批发收入、是否为服务 ARPU。**服务收入（剔除终端）增速才是真实经营指标**。
- **EBITDA 口径**：必须写明是否为租赁调整后（aL）。IFRS 16 把经营租赁移出费用，人为抬高 EBITDA。
- **反证优先写入**：例如"5G 带动 ARPU 提升"必须绑定分档套餐渗透率、实际服务 ARPU 变化和 capex 回报，而不是只引用技术叙事。
- **区分周期与结构**：ARPU 下滑可能是促销周期，也可能是竞争格局恶化。必须用竞对定价和份额数据区分。
- **避免幸存者偏差**：peer set 需纳入价格战市场中的运营商，不能只选寡头理性市场的公司。

## 3. 电信价值驱动树

```text
运营商价值 =
  用户数 × ARPU × EBITDA margin(aL)
  − 维持性 capex − 扩张性 capex
  − 频谱费用（拍卖与续费）
  − 利息与租赁支付
  = 可分配自由现金流

企业价值 =
  可分配 FCF × 可持续性
  × 竞争格局稳定性（参与者数量与理性度）
  + 铁塔/基础设施分部价值（单独倍数）
  − 净债务（含频谱分期与租赁）
  − 监管与频谱续费风险
```

报告中至少回答：

- 该市场有几个参与者？竞争是理性的还是价格战？是否有新进入者或并购获批的可能？
- 服务收入（剔终端）增速是多少？ARPU 变化来自价格、套餐结构还是促销？
- Capex/收入处于周期什么位置？5G/FTTH 投资高峰是否已过？
- 股息 ÷ FCF（含频谱支出）的覆盖率是多少？股息是否靠举债维持？
- 铁塔资产是否已分拆或可分拆？分拆价值多少？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| 后付费净增 | 后付费用户净增加 | **用户质量核心指标** | 预付费/物联网卡冲量掩盖后付费流失 |
| Churn（流失率） | 月度用户流失比例 | 竞争强度与黏性 | 需区分自愿与非自愿流失 |
| ARPU | 每用户平均收入 | 变现能力 | 捆绑套餐会在业务间重分配，扭曲单项 ARPU |
| 服务收入增速 | 剔除终端销售的收入 | **真实经营指标** | 终端销售波动会掩盖服务收入下滑 |
| EBITDA margin (aL) | 租赁调整后利润率 | 盈利能力 | **IFRS 16 会人为抬高未调整的 EBITDA** |
| Capex / 收入 | 资本强度 | 周期位置 | "维持性 capex"口径各家不同 |
| 维持性 vs 扩张性 capex | 资本开支拆分 | 真实 FCF | 扩张性 capex 需绑定回报证据 |
| **FCF** | EBITDA − capex − 频谱 − 利息 − 税 | 股息基础 | 常被 EBITDA 掩盖 |
| **股息覆盖率** | FCF / 股息 | 股息安全性 | **< 100% 即靠举债分红** |
| 净债务/EBITDA | 杠杆 | 评级与股息空间 | **必须含频谱分期与租赁负债** |
| 频谱持有与到期 | 频段、带宽、许可到期 | 长期经营权 | 续费成本可能极高 |
| 频谱拍卖计划 | 已知的拍卖时间与预估支出 | 隐性 capex | 必须进入现金流预测 |
| 5G/FTTH 覆盖率 | 网络覆盖比例 | 竞争地位 | 覆盖不等于变现 |
| 融合套餐渗透率 | 移动+宽带捆绑比例 | 黏性 | 捆绑降低 churn 但也降低单项 ARPU |
| 批发/MVNO 收入 | 网络批发收入 | 产能利用 | 可能培养自身竞争者 |
| 铁塔数量与租户比 | 塔均租户数 | 铁塔资产价值 | 租户比是铁塔估值核心 |
| 市场份额 | 收入或用户份额 | 竞争地位 | 需按后付费口径看 |
| 参与者数量 | 市场运营商数量 | **估值的最大单一变量** | 4→3 合并通常显著提升行业回报 |

必须优先披露的 8 个指标：后付费净增与 churn、服务收入增速、ARPU、EBITDA margin (aL)、capex/收入、FCF 与股息覆盖率、含频谱与租赁的净债务/EBITDA、市场参与者数量与份额。

## 5. 财务模型结构

### 收入模型

**按市场分别建模**，跨国集团不得合并预测：

1. **移动**：`用户数（后付费/预付费分列）× ARPU`，后付费按净增与 churn 滚动。
2. **固网/宽带**：`家庭覆盖数 × 渗透率 × ARPU`，FTTH 升级带来的 ARPU 提升需实证。
3. **企业/批发**：合同收入，含 MVNO 批发和企业专线。
4. **终端销售**：单列，**不计入服务收入增速**。
5. **铁塔/基础设施**：`塔数 × 塔均租户 × 单租户租金`，含 CPI 联动条款。

最低预测要求：

- 至少 3 年历史、8 个季度历史；首次覆盖财报模式同样适用。
- 未来 5–10 年显性预测（需覆盖一个完整 capex 周期）。
- 服务收入与终端收入必须分列。
- ARPU 变化必须拆解为价格、套餐结构和促销的贡献。

### 资本开支、频谱与现金流模型

- **Capex 周期**：明确当前处于投资高峰、平台期还是下行期。**5G/FTTH 高峰后的 capex 下降是 FCF 改善的主要来源**，但需验证是真下降还是延后。
- **维持性 vs 扩张性 capex**：扩张性投入必须绑定 ARPU 提升、份额提升或成本节约的证据，否则视为价值毁灭。
- **频谱**：把**已知的拍卖计划、支付时间表和许可续费**全部计入现金流。频谱是电信最容易被漏掉的巨额支出。
- **FCF 桥**：`EBITDA(aL) → 减 capex → 减频谱 → 减利息 → 减税 → 减租赁支付 = 可分配 FCF`。
- **净债务口径**：**必须包含频谱分期付款和租赁负债**。塔资产售后回租会形成表外负担，需还原。
- **股息可持续性**：股息 / 可分配 FCF。低于 100% 意味着靠举债或资产处置维持分红。

### 稳态假设边界

- **不得在 capex 低谷年直接把 FCF 永续化**。终值必须用整个 capex 周期的平均资本强度。
- 若市场存在价格战或新进入者，不能同时假设 ARPU 稳定和 margin 提升。
- 5G/新技术带来的 ARPU 提升假设必须有分档套餐渗透率的实证支撑。
- 频谱续费和未来拍卖的支出必须计入终值前的现金流，不得假设为零。

## 6. 估值方法

### 适用方法（按问题和商业模式选用，不要求全部执行）

1. **EV/EBITDA (aL) + FCF yield 为主**。租赁调整后口径是跨公司可比的前提。
2. **DCF，显性期覆盖一个完整 capex 周期（7–10 年）**，**避免在 capex 低谷年直接永续化 FCF**。
3. **股息贴现（DDM）**：适合成熟市场龙头，但必须先验证股息覆盖率。
4. **竞争格局情景**：并购获批、新进入者、频谱拍卖结果用**情景概率**处理。**这是电信估值最大的单一变量**——4 家变 3 家通常能显著提升全行业回报。

### 可选

- **SOTP**：跨国集团按国别市场分部估值；铁塔/基础设施分部单独给较高倍数。
- **铁塔独立估值**：`塔数 × 单塔价值` 或 EV/EBITDA（铁塔行业倍数显著高于运营商）。
- **重置成本**：网络重置成本作为极端低估时的参考。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- **市场竞争格局**：3 家理性市场与 4 家以上价格战市场，**绝不可混装**。
- 业务结构：纯移动、融合（移动+固网）、含铁塔资产。
- 市场成熟度：渗透率饱和的成熟市场 vs 仍在增长的新兴市场。
- Capex 周期位置：5G 投资高峰中 vs 高峰已过。
- 杠杆与股息政策：高派息成熟运营商 vs 去杠杆中的运营商。

剔除项必须说明：若某公司看似同业但市场竞争格局或 capex 周期位置明显不同，不应强行放入同一倍数表。

## 7. 财报模式重点

| 模块 | 必看问题 |
|---|---|
| 预期差 | 服务收入、EBITDA(aL)、FCF、用户净增、指引相对一致预期差在哪里？ |
| 用户质量 | **后付费净增与 churn** 如何？预付费和物联网是否在冲量掩盖后付费流失？ |
| ARPU | 环比变化来自价格、套餐升级还是促销？融合捆绑的影响？ |
| 服务收入 | **剔除终端后的服务收入增速**是多少？与总收入增速差异多大？ |
| 竞争行为 | 竞对是否发起价格战？促销强度如何？是否有新进入者？ |
| EBITDA 质量 | 增长是真实经营改善，还是 IFRS 16/资本化带来的会计效应？ |
| Capex | capex 指引变化？维持性与扩张性拆分？周期位置是否改变？ |
| 频谱 | 是否有新的拍卖计划、支付义务或续费风险？ |
| FCF 与股息 | FCF 覆盖股息的比例？管理层对股息政策的措辞是否变化？ |
| 杠杆 | 含频谱和租赁的净债务/EBITDA 是否恶化？评级压力？ |
| 铁塔/资产处置 | 是否有分拆、售后回租计划？对价与后续租金义务？ |
| 市场交易方向 | 未来 1–3 个月市场更可能交易竞争格局变化、capex 拐点、股息安全还是并购？ |

财报后价格反应要扣除市场和同业表现：若公司上涨 5%，但电信板块同日上涨 3%，公司特异反应约为 +2%。

## 8. 护城河与竞争判断

电信的护城河来自**牌照稀缺、网络覆盖和市场结构**，而市场结构往往比公司能力更重要。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| **市场结构** | 3 家或更少参与者，历史上竞争理性 | 4 家以上，或有激进新进入者 |
| 频谱资产 | 持有优质低频段（覆盖优势）和充足带宽 | 频谱不足或即将到期且续费成本高 |
| 网络覆盖与质量 | 覆盖和网速持续领先，第三方测试验证 | 覆盖落后，需大额追赶投资 |
| 融合能力 | 移动+宽带+电视捆绑，churn 显著低于同业 | 单一业务，易被融合套餐抢夺 |
| 规模与成本 | 单用户网络成本显著低于同业 | 规模不足，capex 摊薄不够 |
| 基础设施资产 | 自有铁塔、光纤、数据中心，可变现或降低成本 | 已全部售后回租，租金成为刚性负担 |
| 企业与批发业务 | 高黏性企业客户和批发合同 | 纯消费者业务，价格敏感 |
| 监管关系 | 监管稳定，并购与频谱政策可预期 | 监管频繁干预定价或强制批发 |

定性判断必须与财务证据交叉：若声称"网络领先"，但后付费净增为负、ARPU 下滑，必须解释矛盾。

## 9. 红旗、反证与常见误判

### 红旗

- **靠终端补贴买用户增长**，服务收入不增反降。
- 后付费净增为负，但用预付费或物联网连接数掩盖。
- **EBITDA 增长全部来自会计因素**（IFRS 16 租赁重分类、成本资本化）。
- **股息覆盖率低于 100% 且同时加杠杆**——借钱分红。
- 频谱许可到期续费风险未充分披露，或续费成本远高于预期。
- Capex 大幅削减以维持 FCF，但网络质量指标同步下滑（透支未来）。
- 塔资产售后回租换取一次性现金，但形成长期刚性租金负担。
- 新进入者获得频谱或监管批准，但公司仍假设竞争格局不变。
- 5G/FTTH 投资多年但 ARPU 与 ROIC 无改善。
- 净债务口径不含频谱分期或租赁负债，低估真实杠杆。

### 反证清单

每份电信报告至少列出 3 个能推翻主结论的证据阈值：

- 后付费净增连续 N 个季度为负。
- 服务收入（剔终端）增速跌破某阈值或转负。
- ARPU 同比下滑超过某幅度。
- FCF 股息覆盖率跌破 100%。
- 含频谱与租赁的净债务/EBITDA 超过某阈值。
- 市场出现新进入者或并购被否决，竞争格局恶化。

### 常见误判

- **用 EBITDA 估值而忽略巨额 capex 和频谱支出**——电信的 EBITDA 与 FCF 差距极大。
- 在 capex 低谷年把 FCF 永续化，系统性高估。
- 忽略 IFRS 16 对 EBITDA 的抬升，跨期或跨公司比较失真。
- 把总收入增速当经营改善，忽略终端销售的波动。
- 把用户总数增长当质量改善，忽略后付费流失。
- 相信 5G/新技术叙事会带来 ARPU 提升，而无实证支撑。
- 忽略频谱续费和拍卖义务，高估长期自由现金流。
- 用高股息率判断低估，忽略覆盖率不足和削减风险。
- 忽视市场参与者数量——这是电信回报的最大决定因素。
