# 预期差投资（Expectations Investing）

研究涉及市场定价或投资动作时，区分市场隐含要求与自己的可验证预期。单一事实问答无需为了填表建立完整投资论点。

## 1. 三步框架

**解读市场预期**：适用时用反向 DCF 解出现价要求的 FCFF、稳态营收和增长；用显式权益成本的 PVGO 展示零增长盈利价值与现价之差。两者属于价格诊断，不是支持买入的独立估值证据。隐含预期依赖模型假设，不是唯一可观测的市场共识；可核验的一致预期可作为另一参照。

**建立自己的预期**：按 `base-rates.md` 选择行业、规模、商业模式与订单可见度等可比条件。只有取得可复算样本时才写历史分位；否则写同行区间、定性参照及数据缺口。增长持续与盈利恢复均按 `research-review.md` 提供业务、现金流、竞争证据和量化桥，不因高增长自动下调，也不因历史高盈利自动恢复。

**陈述分歧与验证路径**：写明“市场隐含 X；我预期 Y；依据 Z；在 W 时点用该指标验证”。若提出短期交易判断，再单独说明未来 1–3 个月可能先被定价的变量及上行/下行证伪条件；不把长期估值直接当成短期股价预测。

## 2. 预期差 Gap 表

完整投资报告使用下表；专题分析仅保留与问题相关的行，直接回答可用文字表达。

| 关键驱动 | 市场隐含或可核验共识 | 我的预期 | 可比参照 / 数据质量 | 分歧依据与共享假设 | 验证信号与时点 |
|---|---|---|---|---|---|
| 营收增长 | | | | | |
| 可持续利润率 | | | | | |
| 再投资与增量回报 | | | | | |
| 终值或恢复路径 | | | | | |

未取得参照时写“未获取到”，不得填造精确分位。无法识别市场隐含预期时给条件判断，不声称已证明市场误价。

## 3. 投资动作前的独立观点检验

1. 与市场的主要分歧是什么，是否有可核验的市场参照？
2. 分歧为什么可能存在，公司证据能否支持自己的判断？
3. 最早能在何时、通过什么数据发现自己错了？

证据不足时不把条件性乐观情景提升为买入结论。缺失信息及下一步验证应明确列出；短答和专题同样遵守，具体硬门槛见 `research-review.md`。

## 4. 与其他模块的关系

正向 DCF、EPV、EVA 可能共享同一利润预测，结果接近不增加独立证据数量；记录共享驱动、敏感性和外部证据来源。反向 DCF 单列为诊断，不参与综合价值加权。估值标签按 `valuation-methods.md` 第 9 节复核；预期差与价值标签不一致时先核对口径、再投资和现金权益桥，不凭单个增长指标强行判定矛盾。财报更新保留原预测和时间戳，对实际、旧预期及新预期分别对账。
