# 财报质量核查（Forensic Accounting）

目的：在估值之前先回答一个更基本的问题——**这份利润是不是真的**。本模块产出一个「财报可信度等级（A/B/C/D）」，直接接入 `valuation-methods.md` 第 9 节的否决项：等级 C 动作最高只到"观望"，等级 D 一律"规避"并在第一章显式警示。

范围：完整研究或依赖整体盈利可信度的估值/买入判断执行完整核查；专题与直接回答只执行相关项目，不因打开本文件自动扩大研究范围。

执行纪律：检查器支持的实际年度指标由 `scripts/check_research_output.py --financials` 复核（列名及期间要求见第 7 节）。本季、半年和 TTM 的质量变化仍须按相关口径人工核查；脚本跳过年度模型不免除财报事件要求的本季/TTM 核查。无法取数的项目写"未获取到"，不许凭印象打分。

## 1. 应计质量（Accruals，Sloan 异象）

盈利 = 现金 + 应计。应计占比越高，盈利质量越低、未来回报越差（Sloan 1996）。

- **总应计比率 = (净利润 − 经营现金流) ÷ 平均总资产**。经验参考：< 0（现金利润超过账面利润）为优；0–5% 正常；**> 10% 红旗**。
- **现金转化率 = CFO ÷ 净利润**，看 3–5 年趋势。长期 < 80% 且持续下滑必须解释；利润增长而现金转化恶化是核心风险，不是附注。
- 应计的分解：应收、存货、应付、递延的变化各贡献多少；一次性大额应计（如收购）单列，不污染趋势。

## 2. Beneish M-Score（盈余操纵风险筛查）

八变量模型，比较本年（t）与上年（t-1）：

```text
M = −4.84 + 0.92·DSRI + 0.528·GMI + 0.404·AQI + 0.892·SGI
    + 0.115·DEPI − 0.172·SGAI + 4.679·TATA − 0.327·LVGI
```

| 变量 | 含义 | 计算 | 危险方向 |
|---|---|---|---|
| DSRI | 应收/收入指数 | (应收t/收入t)÷(应收t-1/收入t-1) | ↑ 提前确认收入 |
| GMI | 毛利率指数 | 毛利率t-1 ÷ 毛利率t | ↑ 毛利率恶化诱发操纵 |
| AQI | 资产质量指数 | 非流动非PP&E资产占比之比 | ↑ 费用资本化 |
| SGI | 收入增长指数 | 收入t ÷ 收入t-1 | ↑ 高增长公司动机更强 |
| DEPI | 折旧率指数 | 折旧率t-1 ÷ 折旧率t | ↑ 放慢折旧 |
| SGAI | 费用率指数 | SGA率t ÷ SGA率t-1 | ↑ 效率恶化 |
| TATA | 总应计/总资产 | (净利润−CFO)÷总资产 | ↑ 权重最大项 |
| LVGI | 杠杆指数 | 杠杆t ÷ 杠杆t-1 | ↑ 违约压力 |

判读：**M > −1.78 → 落入"可能操纵"区**（原模型阈值）。这不是定罪，是把该公司移入"逐项手工核查"名单。金融股不适用（资产负债结构不同），改用第 6 节行业替代项。

AQI = `[1 − (流动资产t + PP&E t) / 总资产t] ÷ [1 − (流动资产t−1 + PP&E t−1) / 总资产t−1]`。前期相关资产占比为零时，不论本期占比为零还是正数，原公式都不可计算，**不得把 AQI 填成 1 或输出正常 M-Score**。其他指标的零分母、缺失输入同样明确记为不可计算（P2）；很小但非零的分母保留计算结果并人工核查。非有限输入、单位换算溢出或计算产生 Inf/NaN 是 P1 校验错误，不得解释成“未越限”。不可计算本身不证明盈余操纵，须解释原因并补充适用的人工核查。

## 3. 收入确认红旗

- **DSO 背离**：应收增速持续 > 收入增速（DSO 连续 2 年以上抬升）→ 渠道塞货 / 放宽信用 / 提前确认。
- **递延收入 / 合同负债背离**（订阅类致命项）：收入加速而递延收入减速甚至下降 → 增长在透支未来。
- 长期合同（POC 法）、bill-and-hold、经销商压货、与关联方的循环交易、季末突击发货（Q4 占比异常）。
- 重述历史、更换收入确认政策、分部重划导致不可比 → 一律建桥，桥不平就是红旗。

## 4. 费用资本化与利润平滑

- 资本化开发支出 / 软件 / 客户获取成本占比及其趋势；**capex 长期 > 2× 折旧摊销**而资产周转率没有相应提升 → 可能把费用藏进资产负债表。
- 存货细分：原材料 vs 产成品增速背离（产成品堆积 = 需求恶化的领先指标）。
- 减值的节奏：牛市不减、换 CEO 集中"洗大澡"（big bath）；准备金（坏账/保修/退货）计提率是否逆周期波动（利润平滑工具）。
- "非经常性损益"连续 3 年以上出现 → 重分类为经常性，直接调整常态化盈利。

## 5. 结构与治理信号（非量化，但权重高）

- 审计师：非四大/频繁更换/审计费异常低、内控重大缺陷（SOX 302/404）、非标意见。
- 人事：CFO/审计委员会主席突然离职；财报发布推迟。
- 监管：SEC comment letter / 交易所问询函的主题与频率；做空报告的核心指控与公司回应质量。
- 关联交易：定价公允性、体外循环（供应商/客户与实控人关联）；A股另查股权质押比例与资金占用（见 `markets-cn-hk.md`）。
- 激励结构：以调整后指标（尤其剔除 SBC 的 Non-GAAP EPS）为考核基准 → 操纵动机内建。

## 6. 行业替代项

金融/保险不用应计与 M-Score，改查：贷款分类迁徙与重组贷款、拨备覆盖率逆周期变化、金融资产三级（Level 3）占比、准备金释放对利润的贡献（保险）、再保险安排。REIT 查 AFFO 调整项与资本化利息。能源查储量重述与 DD&A 口径。

## 7. 检查器接入（列名约定）

```sh
python3 scripts/check_research_output.py --financials financials.csv --industry saas
```

数值单元格必须完整可解析，不从夹杂文字的字符串抽取数字：

- 支持普通小数、科学计数法、规范千分位及会计括号负数，例如 `1.2e-5`、`"1,200.5"`、`(100)`（等于 −100）；含逗号的 CSV 单元格须加引号。`%` 换算为小数；`倍` / `x` 表示比率本身。
- 金额和股数支持 `千/万/亿/万亿` 与 `k/m/b`（不区分大小写，分别乘 10³/10⁶/10⁹）。中文缩放单位后可加 `元` 或 `股`；金额还接受 `$`、`¥`、`￥` 前缀。`1.2亿` 为 120,000,000，`6000万` 为 60,000,000，`1.2万股` 为 12,000 股。币种必须事先统一；符号不执行汇率换算。金额列不接受股数或百分比，股数列不接受货币或百分比，比率列不接受金额/股数/缩放单位。
- 全部采用裸数时，沿用输入文件声明的统一计量口径（例如金额与股数均用百万），脚本不猜测隐藏的表头单位。如果使用显式缩放后缀，应先把整表统一为基本货币单位和实际股数；此时裸数也表示基本单位，`1.2亿` 与裸数 `120` 不代表同额。EPS 使用同一币种的每股金额。不要把按“百万”表示的裸数与已经换成基本单位的值混算。
- 仅空白、`-`、`—`、`NA/N/A`、`未获取到`、`not obtained`、`not available` 作为缺失值。`约100`、`1.2亿元人民币` 等未支持格式、错误千分位、`1e309`、Inf/NaN 或单位换算溢出报 P1，并列出数据行号、列名与原值；受影响单元格不参与计算。未识别为数值的备注等文本列不按数值解析。关键运算产生非有限结果也报 P1，不能凭空缺失或判为正常。

CSV 的 `period`（或 `期间`）必须明确频率与财年：年度为 `2025` / `FY2025`，独立季度为 `2025Q1` 至 `2025Q4`，独立半年为 `2025H1` / `2025H2`。也接受 `Q1 2025`、`H1 2025`、`2025年第一季度` 和 `2025年上半年`。标签是同一公司的可比财年编号；财年变更、并购口径变化和其他不可比期间应先另行对账，不能仅靠改标签视为可比。`H2` 必须是独立下半年，不能填全年累计数。

- 不要求按行排序。同比按同频率、同季度/半年槽位的上一年匹配；`revenue_qoq` 只接受相邻独立季度。年度、季度和半年可放同一文件，但不会互作比较基数。
- `Q1`、裸日期、TTM、累计九个月等未支持标签不猜测频率。未知期间、缺少准确比较期、零基数等会明确提示对应增速未复核；重复期间报 P1。同比/环比列留空表示未提供待核数值。
- `actual` 或 `data_type` 可填 `true/actual/实际` 与 `false/forecast/预测`（也支持 1/0）。省略该列表示全部为实际数据；含预测的文件必须逐行标注，预测不能当已实现数据参与质量筛查。标记无效的行会提示未覆盖。
- 通用财报质量筛查仅使用实际年度数据：M-Score、应收/递延趋势使用最新实际年度及其上一年度；现金转化下降趋势要求连续三年。缺期不跨年拼接，季度/半年不擅自年化，混合频率和预测行的排除会在输出中说明。季度、半年、TTM 的适用质量检查另留人工复核记录。

自动计算使用以下列；缺少相应列时该模块不运行，不能称为完成全套核查：

- 必需（应计比率）：`net_income`、`cfo`、`total_assets`
- `total_assets` 是期末资产；应计分母优先使用 `average_total_assets`（或 `平均总资产`），否则用相邻实际年度的期末资产平均值。没有可用平均数时不拿单一期末值代替。
- M-Score 另需：`revenue`、`receivables`、`gross_profit`、`ppe`、`current_assets`、`depreciation`、`sga`、`total_liabilities`
- DSO/递延背离另需：`receivables`、`deferred_revenue`（可选）

传入 `--industry banks` / `insurance` 时不运行这些通用筛查，须按第 6 节人工核查行业替代项。与报告一起检查时，脚本也读取其“行业附录 / Industry appendix”声明，并与命令行行业合并；`--industry auto` 可据此识别。仅当全部已声明行业都是银行/保险才整表豁免；混合金融与非金融业务保留适用性提示及通用筛查结果，须拆分适用业务复核，不能把合并报表结果直接作为各业务的质量结论。

**错误与经营风险分开处理。** JSON 输出的 `category: validation` 表示输入、计算、结构、证据错误或未覆盖提示；P0/P1 仍令检查失败，`--strict` 时 P2 也失败。`category: business_risk` 表示由所给实际数据计算出的风险信号，保留 P1/P2 等级，但本身在默认和 strict 模式下均不导致失败。发现真实红旗后应记录逐项核查、可信度评级及相应动作约束，无需篡改数据以消除红旗。退出码为 0 只说明没有相应级别的校验错误，**不表示风险已人工核查、来源已验证或投资结论已获认可**。

## 8. 财报可信度评级（预注册）

| 等级 | 判定标准 | 对结论的强制作用 |
|---|---|---|
| A | 无红旗；现金转化 ≥ 90%；应计 < 5%；治理干净 | 无限制 |
| B | 1–2 项轻度红旗（如单年应计偏高）且有合理解释 | 无限制，但列入监控指标 |
| C | M-Score 越限、DSO/递延持续背离、经常性"非经常"、治理红旗 1 项严重 | **动作最高"观望"**，报告第一章须警示 |
| D | 多项严重红旗叠加 / 涉嫌造假证据 / 审计非标 | **规避**，估值章节改为"估值在可信度恢复前无意义" |

评级和逐项证据写入报告第五章"财报质量"小节；等级 C/D 时禁止用"估值便宜"对冲——便宜是造假最常见的伪装。
