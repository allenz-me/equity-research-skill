# 估值方法

目标：选择能够回答当前问题、适配商业模式和资料质量的估值方法，给出可复算的条件区间。不规定方法数量；DCF、EPV、EVA 若共享同一恢复假设，仅是同一判断的不同表达。反向 DCF 用于诊断现价，不计为独立支持买入的证据。

原则：
- 显式列出关键假设、共享驱动和证据来源。按 `base-rates.md` 使用条件可比组；没有可核验数据集不填写精确分位数。
- 脚本支持的计算用 `scripts/dcf.py` 和 JSON 留档。SOTP、NAV、rNPV、FCFE、权益剩余收益或复杂再投资路径等未支持方法，用独立脚本或带公式工作簿留档，并记录输入、来源、公式与输出；不得声称计算器已实现。
- 折现率按现金流口径匹配 WACC 或 CoE，见 `cost-of-capital.md`。真实概率情景可以与系统性风险溢价并存，避免同一损失重复调整。
- 增长持续和盈利恢复执行 `research-review.md` 的对称证据门槛；未通过的乐观路径仅列 conditional，不进入决策估值权重或买入依据。
- 财报可信度 C/D 时，可信度问题优先于便宜程度。可靠区间形成后才使用第 9 节的标签和动作规则。
- **普通股有限责任**：DCF、EPV（含成长值）、EVA 将原始权益保留为 `raw_equity`（企业口径为 `EV − net_debt`），同时记录 `equity_shortfall = max(−raw_equity, 0)`；用于每股价值和决策的 `equity = max(raw_equity, 0)`。情景与蒙特卡洛必须先逐情景/逐次模拟处理有限责任，再计算加权价值、分布及仓位，不能先平均负权益再归零。蒙特卡洛另保留归零次数、最低原始权益和平均缺口供诊断。归零仅是有限责任的简化下限处理，不估计破产成本、清算/重整回收或股权期权价值；涉及这些因素时另建困境估值模型，不把负残值当成股东补款义务，也不把归零称为完整破产估值。`run_position` 拒绝外部传入的负每股价值。

## 1. 相对估值（可比公司 + 历史区间 + 合理倍数）

常用倍数按公司类型选择：P/E（盈利稳定）、EV/EBITDA（重资产/资本结构差异大）、P/S（未盈利成长）、PEG（粗略）、EV/ARR（订阅）、P/B–ROE（金融）。

做法：
1. 公司自身可核验的历史倍数区间，说明观察期间、周期与口径；只有样本可复算时才报告分位数。
2. 3–6 家**可比公司**同一倍数对比（A股/港股对照系见 `markets-cn-hk.md` 第 6 节）。
3. **合理倍数（warranted multiple）纪律**：不许直接抄同业中位数。倍数是增长 g、回报 ROIC、风险 r 的函数——权益口径下可用合理 P/E ≈ (1 − g/增量权益回报率)/(CoE − g)，并说明再投资、杠杆与分配假设；企业口径使用匹配的企业指标与 WACC。先算公司基本面对应的合理倍数，再与市场给的倍数比较；差额要么是市场错（机会），要么是你没看到的风险（警报），显式归因。
4. 倍数与指标口径匹配：P/E × EPS 得每股价值；EV 倍数先得企业价值，减净债务后再除股数。

| 倍数 | 当前 | 自身历史中枢 | 可比中位 | 合理倍数（算式） | 选用 | 隐含每股价值 |
|---|---|---|---|---|---|---|

## 2. 绝对估值：DCF（正向）+ 终值纪律

显性预测期和衰减期按业务可见度选择，不为满足固定年数外推。脚本的线性增速衰减是一种简化输入方式，不代表行业必然均值回归；结构性路径可直接输入逐年 FCFF。

关键假设：收入与 FCFF 利润率、再投资、WACC、永续增长、净债务和稀释。输入是企业自由现金流，`cashflow_basis` 仅支持 `FCFF`；FCFE 另建补充模型。`net_debt` 已扣除一次可用过剩现金，权益桥为 `equity = EV − net_debt`。

**股本约定**：计算器采用预测末期股数除整体权益价值的简化约定，`shares_end = shares × (1 + annual_dilution)^(显性期年数 + 衰减期年数)`；终值不再另加无期限稀释。此约定不是逐年每股现金流模型，应在报告中披露；相同完整现金流和稀释路径不得因显性/衰减划分不同而改变结果。需要逐年稀释或回购现金流时另建可复算模型，避免重复计算 SBC 或回购成本。

**终值合理性三查**：
1. 将隐含退出倍数与口径匹配的成熟同业、长期增长和再投资需求对照，差异给出依据。
2. 报告终值占比及敏感性；终值高度主导时降低结论置信度，不凭固定占比断言模型错误。
3. 验证稳态利润率、增长与 ROIIC 是否相容。零超额回报是保守对照；有业务和竞争证据时允许论证更长优势期，并展示优势衰退的后果，不机械截断结构性增长。

执行：假设 JSON → `scripts/dcf.py --config`；使用 DCF 时展示 WACC、g 及最关键经营驱动的敏感性。缺少证据的上行路径依 `research-review.md` 标为 conditional。

## 3. 三要素估值法：资产重置 · EPV · franchise 成长（Graham–Greenwald）

**资产价值**：按可回收性、经营必要性和负债优先级逐项估计，并给出处置或重置依据。资产价值不是所有公司的股价底线，不套用无来源的固定折扣率。

**EPV**：`EPV = 可持续常态化盈利 / 匹配资本成本`，为零增长估计。`earnings_basis: NOPAT` 使用 WACC 得企业价值，再减已扣现金的 `net_debt`；`NET_INCOME`（或 `NI`）使用 CoE 直接得权益价值，不再减净债务。`coc` 必填，不继承未经匹配的顶层利率；`excess_cash` 已弃用，不能重复加回。

常态化从当前可持续盈利出发，剔除有证据的一次性项目并展示收入、利润率、税和资本需求桥。NOPAT 未扣 capex，**不得直接把 growth capex 加回 NOPAT**。从现金流估计零增长盈利能力时，分别说明折旧、维护性 capex、成长性 capex 和营运资本调整；维护支出无法可靠拆分时给区间及限制。

默认最近两个可比报告期利润各同比下滑至少 20%，或出现转亏、亏损扩大、结构性恶化时，按 `research-review.md` 触发恢复审查。只有客户、份额、定价、利润率及现金资本需求的可追溯证据与桥接通过后，较高恢复盈利才可进入决策估值；否则当前可持续水平用于决策，历史峰值仅作为 conditional 情景。EPV/调整后资本关系可帮助讨论竞争优势，但不能单凭一个比值证明护城河。

**成长价值**：`E × (1 − g/ROIIC) / (coc − g)` 仅在再投资关系和口径成立、`g < coc`、`ROIIC > 0`、再投资率 `g/ROIIC ∈ [0,1]` 时使用。ROIIC 低于资本成本时增长可能减值；不把成长值强制排在 EPV 上方。参数或证据无效就不给成长值，不再使用 `EPV × (1+g)` 兜底。权益口径必须使用相应增量权益回报，不混入企业 ROIIC。

## 4. 反向 DCF + PVGO 分解——市场定价诊断

反向 DCF 问"**现价假设了什么**"，在估值问题中用于诊断市场定价（完整方法论见 `expectations-investing.md`）。

- `reverse` 块：由现价解出稳态所需 FCF → 按稳态利润率档换算所需营收与隐含 CAGR。
- `pvgo` 块：`现价 = E/r（零增长价值） + PVGO`，`E` 为每股权益盈利，`pvgo.r` 必须显式填入匹配权益成本，不能回退到 WACC；输出**现价中为未来增长付费的百分比**。PVGO 占比 >50% 的标的，报告必须回答"这些增长从哪来、谁买单"。
- 呈现：把隐含要求翻译成参照系（使用有来源的同行条件样本；无数据时不写历史成功比例）。结论句式："市场不是在给 × 定价，而是在给 × 定价"。
- 产出**预期差 Gap 表**（骨架见 `expectations-investing.md` 第 2 节），完整报告置于第一章；专题仅呈现相关驱动。

## 5. 情景加权公允价值 + 蒙特卡洛

**情景分析**：需要估值决策时对关键不确定性建立内部自洽的下行、基准和上行路径；方法或资料不适用时说明限制，不为数量凑模型。真实世界概率须有依据，决策情景概率和为 1；证据强度不机械映射为 25% 或其他概率下限，股价反应也不替代经营证据。

`role: decision`（默认）情景用于概率加权和仓位计算；`role: conditional` 仅展示条件成立时的结果，不进入加权分母、综合决策估值或仓位。未通过增长持续/盈利恢复门槛的乐观路径必须属于后者。证据改变后说明概率调整或维持的理由，并测试不利概率组合是否改变结论。

**蒙特卡洛（可选加强，结果分布很宽或路径依赖强时）**：`montecarlo` 块给关键驱动设分布（增速：正态截断；利润率：三角；WACC：均匀窄带），N≥2000 次模拟，输出公允价值 P10/P25/P50/P75/P90、**P(模型内在价值 < 现价)**与期望值。这不是客观亏损概率；蒙特卡洛不替代经营情景与证据门槛（相关性设定不透明时反而伪精确），作为分布形状的补充证据。

**市场再定价提示**：情景价值回答"最终值多少钱"，不自动回答"市场接下来先交易什么"。当最新财报或事件刚改变核心变量时，须另写未来 1–3 个月市场交易方向：市场更可能先交易收入/订单加速、利润率、capex 回报、监管风险、回购变化，还是估值均值回归。该判断进入第一章决策三分法，不改变内在价值标签，但会影响动作节奏。

## 6. EVA / 剩余收益（经济利润）——护城河的另一把尺

`EVA_t = NOPAT_t − WACC × 投入资本_{t-1}`；`价值 = 当前投入资本 + Σ 未来 EVA 折现`。

为什么值得单独做：把价值拆成"存量资本 + 超额回报"，直接暴露两个 DCF 里看不见的问题——
1. **公司现在到底赚不赚超过资本成本的钱**（EVA 连年为负的"增长股"是价值粉碎机）；
2. **增长的价值来源**：`内生增长 g = 再投资率 RR × ROIIC`——想要 10% 增长、ROIIC 只有 12%，意味着要再投 83% 的利润，FCF 所剩无几。DCF 里增速和利润率是两个自由参数，EVA 框架强迫它们自洽。

执行：JSON `eva` 块使用企业 NOPAT、期初投入资本和 WACC；`earnings_basis` 仅支持 `NOPAT`。每年先用当年 NOPAT 减 **期初**资本费，再根据期末再投资更新资本，不能先重算当期资本再收费。

简化模型从衰减期之后的终值首年进入零超额回报稳态：`NOPAT_(n+1) = WACC × IC_n`，此后 NOPAT 和投入资本保持不变，EVA 为零；显式期最后一年仍可能有 EVA，不会把末年仍增长的利润延长却漏算所需投资。输出的企业价值等于初始投入资本加未来 EVA 现值，再减净债务得权益。持续超额回报、复杂投入资本序列或银行保险的权益剩余收益需独立补充模型，不能声称当前脚本支持。DCF 与 EVA 共用预测时，可用 `FCFF_t = NOPAT_t − (IC_t − IC_{t−1})` 核对经济口径；一致不是新增一份独立证据。

## 7. 其他适用方法

- **SOTP**：多业务公司分部加总，减净债与总部成本；分歧可能来自分部假设、资本配置、债务和控股折价，需归因；分部差异影响结论时使用。
- **Morningstar 公允价值**：第三方锚，标日期/星级/不确定性；区分分析师 FV 与量化评级。
- **行业特定**：NAV（矿业/航运/地产）、rNPV（医药管线）、P/EV（保险）、P/AFFO（REIT）、中周期盈利法（周期股，需证明周期与盈利恢复，展示利润率、税、股数及资本开支桥；不能机械使用历史带宽中点，也不能峰值盈利乘峰值倍数）。

## 9. 结论标定与仓位思维（预注册，不得临场发挥）

**估值标签**（综合区间 [L, H]，现价 P，±15% 缓冲带）：

| 条件 | 标签 |
|---|---|
| P < 0.50L | 显著低估 |
| 0.50L ≤ P < 0.85L | 低估 |
| 0.85L ≤ P ≤ 1.15H | 合理 |
| 1.15H < P ≤ 1.50H | 高估 |
| P > 1.50H | 显著高估 |

**动作矩阵**（标签 × 不确定性；不确定性优先 Morningstar 评级，缺失自评并写依据）：

| 标签 \ 不确定性 | 低 / 中 | 高 / 极高 |
|---|---|---|
| 显著低估 | 买入 | 分批买入（P < 0.70L 方可首建） |
| 低估 | 买入/分批买入 | 小仓位试探或等待 |
| 合理 | 观望（持有者持有） | 观望 |
| 高估 | 减持/规避 | 规避 |
| 显著高估 | 规避，持有者减持 | 同左；默认不建议做空 |

**否决项（一票降级）**：增长持续或盈利恢复未通过 `research-review.md` 门槛的条件性路径不得支撑买入；治理红旗 ≥2 项严重级或**财报可信度 C** → 动作最高"观望"；**可信度 D** → 规避；护城河"无"且标签高估 → 直接规避。双重上市按 `markets-cn-hk.md` 分市场标定。

**动作节奏修正**：动作矩阵给出价值纪律下的默认动作；若未来 1–3 个月市场交易方向与价值标签相反（如内在价值"合理/偏贵"，但财报后再定价方向"偏上"），不得简单写"观望"了事。必须明确是"等待回调"、"持有不追"、"突破/回调触发复核"或"小仓位跟踪"，并给触发条件。

**仓位思维（`position` 块，给动作配量级）**：
- 期望收益 `EV = Σ p_i × (V_i/P − 1)`（只用 decision 情景的每股价值与概率）。
- **不对称比 = 上行空间 ÷ 下行空间**（牛情景涨幅 ÷ 熊情景跌幅）；<1.5 的"低估"多半不值得建仓。
- Kelly-lite 参考仓位 = ¼ × Kelly 分数（脚本按两点近似计算），仅作量级参考、上限 15%，**不构成配置建议**——报告只说"该赔率结构支持 小/中/标准 仓位"。
- 亏损概率 P(loss)（蒙特卡洛可得）与最大可容忍下行一并呈现。

**一致性要求**：报告内重复出现的标签、动作、预期差方向必须与本规则可复算地一致；`dcf.py` 在给定 range_low/range_high 时自动输出标签建议，`check_research_output.py` 复核报告文本一致性。
